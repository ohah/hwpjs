# 지원 범위와 제한

현재 public 소스 지원과 npm 배포·실제 UI 동작·문서별 저장 검증은 서로 다른 상태입니다. 이 사이트의 타입 검사와 정적 빌드는 제품의 Native/브라우저 E2E를 대신하지 않습니다.

| 영역            | 현재 안내 범위                                                                                        | 제한                                                                                                                                          |
| --------------- | ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 문서            | HWP5 · HWPX 열기/편집/현재 형식 저장, `createDocument()`의 새 문서 생성                               | 새 문서는 기본 HWPX이며 HWP5도 명시 가능. 생성기를 제공하는 runtime factory 필요. HWP3 제외; 모든 버전·암호·문서 특성 보장 아님               |
| 텍스트          | display 선택, 지원 범위의 splice                                                                      | 보호/필드/개체/unknown/clipped 대상 제한                                                                                                      |
| 서식            | size/bold/italic, 밑줄, 취소선, 문단 정렬 typed 명령                                                  | 지원 원본 소유자의 커서 입력 서식도 확장했습니다. 생성 셀·복합 제어 등 owner 제한이 남으며 모든 글자/문단 속성 지원은 아닙니다                |
| 검색            | 현재 snapshot의 literal 검색·통계                                                                     | 정규식·전체 문서 순회·모두 바꾸기 transaction 보장 없음                                                                                       |
| 표·셀           | 지원 셀 내부의 텍스트/서식, 본문 caret의 typed 표 삽입, 생성 표와 지원 원본 단순 표의 행·열 삽입/삭제 | 현재 owner·참조·capability·관측 자원과 격자 제한을 확인해야 함. 범용 표/셀 주소 체계·모든 병합/분할·중첩 표 편집 지원 아님                    |
| 필드·개체·media | 일부 엔진/저수준 기능                                                                                 | typed 공개 생성/조회/편집 전체로 안내하지 않음                                                                                                |
| Canvas          | 공통 웹 호스트의 제한된 표시·직접 입력                                                                | 완전한 한글 조판·인쇄·페이지 이미지 export 아님                                                                                               |
| 저장·HTML       | `save()`의 현재 형식 bytes 저장, 별도 `toHtml(bytes, { wasm, ... })`의 의미 기반 HTML 변환            | 무손실 일반 보장·임의 형식 변환·PDF export 아님. HTML은 명시 WASM과 이미지/출력 정책을 따르며 원본 페이지 배치·인쇄·시각 동치를 보장하지 않음 |
| RN              | TypeScript provider/transport 기반                                                                    | Native 아티팩트·기기 E2E까지 experimental                                                                                                     |

## 조판과 저장

텍스트나 서식을 바꾸면 원본 줄/페이지 조판 정보와 달라질 수 있습니다. 화면이 보이거나 저장 파일이 생겼다는 사실만으로 원본 한글과 레이아웃이 같다고 판단하지 않습니다. `layoutRequiresReflow`와 오류를 확인하고 앱에서 명확히 안내하세요.

## 호스트의 책임

파일 선택/다운로드·OS clipboard·권한·DOM/Canvas·입력/IME·인쇄 UI는 호스트가 담당합니다. 순수 core에 DOM 의존성을 추가하거나 과거 WebHwpCtrl 액션 이름을 그대로 사용할 수 있다고 가정하지 않습니다. 웹 데모의 리본 버튼은 연결 가능성과 문서별 capability를 표시하는 별도 앱입니다.

## 실행 중인 데모

[전체화면 Canvas 데모](../playground.mdx)는 이 문서 사이트에서 직접 실행됩니다. 브라우저 안에서 파일을 처리하며, 지원하지 않는 명령은 데모에 표시되는 기능 안내를 확인하세요.

[로드맵](../roadmap.md)은 다음 단계의 범위이며 이미 제공하는 기능의 증거가 아닙니다.

## HWPX 새 문단의 기본 서식

현재 main과 웹 데모에서는 Enter로 만든 HWPX 본문 문단에도 굵게·기울임·크기·정렬을 같은 편집 세션에서 적용할 수 있습니다. 원본 템플릿의 구역 설정을 미지원 인라인 컨트롤로 잘못 거부하던 저장 오류를 수정했습니다. 별도 저장·재열기는 필요하지 않습니다. 모든 문서의 개체·서식·조판 완료를 뜻하지 않으며 npm 게시는 별도입니다.

## HWP5 새 문단의 확장 서식

현재 main의 Core는 같은 세션에서 생성된 최상위 HWP5 본문의 비어 있지 않은 선택에 밑줄·취소선·글자색·언어 하나의 글꼴 이름 변경을 제공합니다. 현재 문단 참조와 소유권을 검증하고 적용합니다. 빈 선택의 다음 입력 서식, 생성 셀·글상자·각주와 atomic patch는 이 범위에 포함하지 않습니다. [선택 API](../api/selection.md#hwp5-생성-본문의-확장-서식)를 참고하세요.

## HWP5 새 문단의 일괄 서식

현재 main은 같은 세션의 HWP5 생성 본문에 결합 글자·문단 patch와 문단 스타일 기준 초기화를 제공합니다. 한 요청은 한 이력이며 현재 참조와 Native binding을 검증합니다. [결합 서식 API](../api/selection.md#hwp5-생성-본문의-결합-서식과-초기화)를 참고하세요. 확장 다음 입력 서식·전체 바꾸기·다른 생성 owner의 일괄 편집 완료를 뜻하지 않습니다.

HWPX의 최상위 생성 본문은 같은 세션에서 서식 조회·글자/문단 결합 적용·문단 스타일 기준 초기화를 지원합니다. 생성된 중첩 문단과 전체 캐럿 다음 입력 서식, 모든 개체·조판 동치는 이 범위와 별개입니다.

## 새 차트·수식

현재 소스는 HWPX 첫 구역의 일반 본문 커서에 새 차트와 수식을 삽입할 수 있습니다. HWPX 차트는 막대/꺾은선/영역/원형의 2D/3D, 도넛/보조 원형/방사형/분산형/버블/주가/표면형을 제공합니다. 빈 본문과 차트 뒤 Enter로 만든 빈 문단을 지원하며 기존 개체가 섞인 문단, 셀, 선택 영역은 제외합니다. 혼합 차트, 차트의 임의 서식과 조판 편집, 수식 크기 자동 계산은 후속 범위입니다. [데모 사용법](./demo.md#새-차트수식-만들기)과 [API](../api/editor.md#새-hwpx-차트수식-생성)를 확인하세요. 3D 차트는 2D Canvas 기반 근사 표시이며 한컴의 3D 조판과 시각 동치를 보장하지 않습니다.

HWP5는 편집 가능한 일반 본문 커서에서 기본 2D 세로 묶은 막대 차트의 생성, Canvas 표시, 실행 취소/다시 실행, 저장 후 재열기를 확인했습니다. 생성 창에서 **기본 막대 차트 (외부 호환 미검증)**을 직접 선택해야 합니다. 다른 차트 종류와 임의 스타일 및 조판 편집은 이 생성 범위가 아닙니다. 검증한 격리 소스의 기존 HWP5 차트 값과 범주 편집은 [별도 사용법과 제한](./demo.md#hwp5-기존-차트-데이터-편집)을 따르며, 소유권이 확인된 own 표준 2D 세로 묶은 막대만 대상으로 합니다. [HWP5 차트 예제와 생성 순서](./demo.md#hwp5-새-차트-만들기)를 참고하세요. 이 소스와 격리 데모 검증은 npm 게시나 공개 배포 완료를 뜻하지 않으며 외부 한글 프로그램의 전체 상호운용은 별도 검증 대상입니다.

HWP5는 일반 본문 커서에서 새 수식을 삽입할 수 있습니다. 새 문서에 분수를 삽입한 뒤 실행 취소·다시 실행과 저장·재열기를 확인했습니다. 기본 저장에서 재조판 안내가 나오면 줄 배치 변경에 명시적으로 동의해야 저장됩니다. [HWP5 수식 생성 예제](./demo.md#hwp5-새-수식-만들기)를 참고하세요.

## 개체 속성

Canvas에서 실제로 선택되어 선택 테두리가 표시된 차트·그림·글상자는 Canvas에 초점을 둔 상태에서 **P**를 눌러 현재 개체의 속성을 엽니다. 글상자는 테두리로 선택하며 내부의 `p` 입력은 텍스트로 유지합니다. 선택 없는 일반 본문이나 다른 입력칸에 적용되는 전역 단축키가 아닙니다. HWP5 글상자는 회전·그룹이 없는 독립 개체의 확인된 테두리 관측에 한정합니다.

속성 창의 기본 정보 조회와 크기/위치 편집은 별도입니다. 지원되는 HWPX 차트와 글상자, HWP5 글상자의 크기/위치 편집은 아래 [최신 소스의 개체 편집](#최신-소스의-수식-표시와-개체-편집)과 [편집 API](../api/editor.md#object-geometry)의 대상 조건을 따릅니다. HWP5 차트의 크기/위치는 조회용이며 데이터 편집은 위의 별도 지원 범위를 따릅니다. 활성화된 차트 데이터 편집 버튼은 현재 차트에 연결되고, 그림 크기 편집도 기존 지원 조건을 따릅니다. 그림 회전/자르기와 그룹/회전 개체의 범용 속성 편집은 이 범위에 포함되지 않습니다. [데모 동작](./demo.md#선택한-개체의-속성)을 확인하세요.

## 최신 소스의 수식 표시와 개체 편집

HWP5 원본 수식은 현재 문단의 실제 앵커에 연결해 공통 Canvas 수식 표시기로 그립니다. 모든 수식 문법·글꼴·원본 조판의 동치를 보장하지 않으며 새 HWP5 수식 생성과는 다른 기능입니다. 예제 문서의 `latex.hwp`에서 표시를 확인할 수 있습니다.

원본 셀에서 서식 입력 후 undo/redo와 문단 끝의 추가 입력, 저장·다시 열기를 검사했습니다. 지원하는 HWPX 차트·글상자와 HWP5 글상자의 크기·위치도 현재 Native 값을 기준으로 편집합니다. [편집 API](../api/editor.md#object-geometry)는 상태가 바뀌면 다시 조회해야 합니다. 이 소스 지원과 npm 게시·전체 형식 지원은 구분합니다.
