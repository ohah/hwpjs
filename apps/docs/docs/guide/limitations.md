# 지원 범위와 제한

현재 public 소스 지원과 npm 배포·실제 UI 동작·문서별 저장 검증은 서로 다른 상태입니다. 이 사이트의 타입 검사와 정적 빌드는 제품의 Native/브라우저 E2E를 대신하지 않습니다.

| 영역 | 현재 안내 범위 | 제한 |
| --- | --- | --- |
| 문서 | HWP5 · HWPX 열기/편집/현재 형식 저장 | HWP3 제외; 모든 버전·암호·문서 특성 보장 아님 |
| 텍스트 | display 선택, 지원 범위의 splice | 보호/필드/개체/unknown/clipped 대상 제한 |
| 서식 | size/bold/italic, 밑줄, 문단 정렬 typed 명령 | 모든 글자/문단 속성 public 완료 아님 |
| 검색 | 현재 snapshot의 literal 검색·통계 | 정규식·전체 문서 순회·모두 바꾸기 transaction 보장 없음 |
| 표·셀 | 지원 셀 내부의 텍스트/서식 경로 | typed 표 주소·생성·행열 조작 API 전체 미제공 |
| 필드·개체·media | 일부 엔진/저수준 기능 | typed 공개 생성/조회/편집 전체로 안내하지 않음 |
| Canvas | 공통 웹 호스트의 제한된 표시·직접 입력 | 완전한 한글 조판·인쇄·페이지 이미지 export 아님 |
| 저장 | 현재 형식 bytes | 무손실 일반 보장·임의 형식 변환·PDF/HTML export 아님 |
| RN | TypeScript provider/transport 기반 | Native 아티팩트·기기 E2E까지 experimental |

## 조판과 저장

텍스트나 서식을 바꾸면 원본 줄/페이지 조판 정보와 달라질 수 있습니다. 화면이 보이거나 저장 파일이 생겼다는 사실만으로 원본 한글과 레이아웃이 같다고 판단하지 않습니다. `layoutRequiresReflow`와 오류를 확인하고 앱에서 명확히 안내하세요.

## 호스트의 책임

파일 선택/다운로드·OS clipboard·권한·DOM/Canvas·입력/IME·인쇄 UI는 호스트가 담당합니다. 순수 core에 DOM 의존성을 추가하거나 과거 WebHwpCtrl 액션 이름을 그대로 사용할 수 있다고 가정하지 않습니다. 웹 데모의 리본 버튼은 연결 가능성과 문서별 capability를 표시하는 별도 앱입니다.

## 실행 중인 데모

[전체화면 Canvas 데모](../playground.mdx)는 이 문서 사이트에서 직접 실행됩니다. 브라우저 안에서 파일을 처리하며, 지원하지 않는 명령은 데모에 표시되는 기능 안내를 확인하세요.

[로드맵](../roadmap.md)은 다음 단계의 범위이며 이미 제공하는 기능의 증거가 아닙니다.
