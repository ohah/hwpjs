두 예제에는 사용 안내와 편집할 개체가 들어 있습니다. 적용한 뒤 실행 취소·다시 실행을 해 보고, **파일 → 저장하기**로 내려받은 파일을 다시 열어 결과를 확인할 수 있습니다. 직접 작성한 예제이며 개인정보를 포함하지 않습니다.

현재는 문서 안에 있는 HWPX 차트 데이터와 수식을 편집하는 예제입니다. 새 차트·수식 삽입과 HWP5 차트 데이터 편집의 지원을 뜻하지 않습니다.

## 표에서 셀 블록 선택하기

Canvas 데모에서 HWP5 또는 HWPX 표의 셀 안을 클릭한 뒤 아래 기본 단축키를 사용하세요. 셀이 선택되면 배경에 선택 표시가 나타납니다.

| 입력                           | 동작                                                                                                                                                                                                |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **F5 한 번**                   | 현재 셀 하나를 선택합니다. 방향키를 누르면 선택 범위를 늘리지 않고 인접한 셀로 옮깁니다.                                                                                                            |
| **F5 두 번** 또는 **Shift+F5** | 확장 모드로 들어갑니다. 한 셀이 선택된 상태에서 **F3**을 눌러도 확장 모드로 들어갑니다. 방향키로 시작 셀에서 현재 셀까지의 직사각형을 선택합니다. 직사각형에 걸치는 병합 셀은 셀 전체를 포함합니다. |
| **F5 세 번**                   | 현재 표의 모든 셀을 선택합니다. 확장 모드에서 F5를 한 번 더 눌러도 같은 동작을 합니다.                                                                                                              |
| **Esc** 또는 **Enter**         | 셀 블록을 해제하고 마지막 활성 셀에 커서를 둡니다.                                                                                                                                                  |

키를 누른 채로 유지해도 선택 단계가 연속으로 넘어가지 않습니다. 지원되는 셀에서는 커서를 둔 상태에서 문맥 메뉴를 열고 **셀 블록 설정**을 선택해 시작할 수도 있습니다. 키보드로 문맥 메뉴를 열려면 **Shift+F10**을 누르세요. 단축키는 데모의 **단축키 설정**에서 변경할 수 있습니다.

셀 블록은 현재 Canvas에서 전체 구조를 확인할 수 있는 HWP5·HWPX 표에 적용됩니다. 파일에서 연 원본 표와 데모에서 새로 만든 표가 해당됩니다. 본문, 일부만 표시된 표, 잘린 셀, 입력 반영이나 한글 조합이 진행 중인 상태에서는 선택을 시작할 수 없습니다. 표 메뉴나 표의 문맥 메뉴로 이동하면 현재 셀 블록이 유지됩니다. 그 밖으로 포커스를 옮기면 셀 블록이 해제됩니다.

블록 상태에서 **Delete**나 **Backspace**를 눌러도 셀 내용은 유지됩니다.

### HWPX 셀 합치기

저장된 HWPX 표에서 인접한 셀을 직사각형으로 선택하고 **표 → 셀 합치기** 또는 우클릭 메뉴의 **셀 합치기**를 선택하세요. 선택한 셀의 문단을 왼쪽 위 셀에 행 순서대로 모읍니다. 실행 취소와 다시 실행을 사용할 수 있습니다.

이미 병합된 셀, 보호된 영역, 중첩 표나 개체가 포함된 영역에는 합치기를 제공하지 않습니다. 생성한 표는 저장하고 다시 연 뒤 시도할 수 있습니다. HWP5 셀 합치기와 셀 너비·높이 균등화는 별도 범위입니다.
