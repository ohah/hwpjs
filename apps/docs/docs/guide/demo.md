# HWP 샘플과 데모

이전에 공개 문서에서 제공하던 `noori.hwp` 샘플을 같은 다운로드 경로로 유지합니다.

<a href="__HWPJS_DOCS_BASE__demo/noori.hwp" download>noori.hwp 다운로드</a>

이 문서는 샘플 파일의 접근을 보존합니다. 구 Rust 기반 `@ohah/hwpjs` 변환 UI와 JSON/Markdown/HTML 변환기를 현재 API로 계승하거나 새 사이트에서 실행하는 것은 아닙니다. 현재 API는 [Runtime 설정](./runtime.md)과 [편집·저장 예제](./editing.md)를 참고하세요.

## 현재 Canvas 데모

[Canvas 웹 미리보기 열기](https://macstudio.tailed42f2.ts.net:10000/web/preview/index.html)

이 주소는 **Tailscale tailnet에 접근할 수 있는 사용자만** 사용할 수 있습니다. GitHub Pages 방문자가 별도 네트워크 연결 없이 사용할 수 있는 공개 편집기로 안내하지 않습니다. 문서 사이트와 별도로 운영되므로 사용 가능 상태와 지원 기능도 실행 중인 데모에서 확인하세요.

샘플을 다운로드한 다음 데모의 파일 열기로 직접 선택할 수 있습니다. 이 문서 페이지는 파일을 자동 업로드하거나 변환하지 않습니다. Canvas 표시와 저장 결과가 원본 한글의 모든 조판과 같다는 보장은 하지 않습니다.

[HWPX 샘플](./demo-hwpx.md)도 제공합니다. [지원 범위와 제한](./limitations.md)을 함께 확인하세요.
