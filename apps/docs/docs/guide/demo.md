차트 데이터 편집과 수식 편집 예제에는 사용 안내와 편집할 개체가 들어 있습니다. 적용한 뒤 실행 취소/다시 실행을 해 보고, **파일 > 저장하기**로 내려받은 파일을 다시 열어 결과를 확인할 수 있습니다. HWP5 차트 예제는 직접 생성해 저장한 차트의 표시를 확인하는 파일입니다. 검증한 최신 격리 소스는 지원 조건을 만족하는 HWP5 차트의 값과 기존 범주 이름도 편집합니다. 아래의 별도 순서와 제한을 확인하세요. 직접 작성한 예제이며 개인정보를 포함하지 않습니다.

차트 데이터 편집과 수식 편집 파일은 기존 개체 편집 예제입니다. 새 개체는 아래 순서로 만들 수 있습니다.

## 새 차트·수식 만들기

1. **파일 → 새문서**에서 HWPX 문서를 만듭니다.
2. **입력 → 차트**를 열고 종류와 옵션을 선택한 뒤 범주·계열 이름과 숫자를 입력합니다. 범주와 계열을 추가하거나 삭제할 수 있습니다.
3. 너비·높이를 mm로 입력하고 **차트 만들기**를 누릅니다. 분산형·버블은 X·Y를 직접 입력하고 버블은 크기도 지정합니다. 주가형은 HLC/OHLC 역할 순서와 고가·저가 범위를 확인합니다.
4. 다른 빈 본문 문단에 커서를 놓고 **입력 → 수식**을 선택합니다. 예를 들어 `x over y`를 입력한 뒤 **수식 삽입**을 누릅니다.
5. 실행 취소·다시 실행을 확인하고 **파일 → 저장하기**로 내려받은 문서를 다시 엽니다. 생성한 개체는 도구 메뉴의 기존 차트 데이터·수식 편집에서도 수정할 수 있습니다.

위 HWPX 순서는 첫 구역의 일반 본문에서 선택 영역 없이 커서를 둔 상태가 대상입니다. 차트 뒤에서 Enter로 만든 빈 본문도 사용할 수 있습니다. 셀 안, 기존 개체가 섞인 문단과 혼합 차트는 후속 범위입니다. 수식 크기는 자동으로 계산하지 않으며 창에서 지정합니다. 현재 소스 기준이며 npm 게시와 공개 배포 완료를 뜻하지 않습니다.

[헤드리스 생성 API](../api/editor.md#새-hwpx-차트수식-생성)에서도 같은 기능을 호출할 수 있습니다.

HWP5 문서는 아래 [새 수식 만들기](#hwp5-새-수식-만들기) 순서를 따르세요.

## HWP5 새 수식 만들기

예제 `hwp5-equation-create.hwp`는 앱에서 직접 생성·저장한 `x over y` 분수 한 개입니다. 파일 안에는 별도 안내문을 추가하지 않았습니다.

1. **파일 → 새 문서**에서 문서 형식을 **HWP5**로 선택하고 **만들기**를 누릅니다.
2. 일반 본문을 클릭하고 **입력 → 수식**에서 `x over y`를 입력한 뒤 **수식 삽입**을 누릅니다.
3. 분수 표시를 확인합니다. **실행 취소** 한 번으로 수식이 없어지고 **다시 실행** 한 번으로 복원됩니다.
4. **파일 → 저장하기**를 누릅니다. 검증한 새 수식 문서는 기본 저장이 `LayoutReflowRequired`로 거부됐습니다. 안내를 확인하고 **줄 배치가 달라질 수 있는 HWP 저장 허용**을 직접 선택한 뒤 다시 저장합니다.
5. 내려받은 파일을 로컬 파일 선택으로 다시 열어 분수 표시를 확인합니다.

새 수식 생성과 명시적 줄 배치 변경 동의를 사용한 저장·재열기까지 확인한 범위입니다. 기존 HWP5 수식 편집, 수식 크기 자동 계산, 원본 한글 프로그램과의 조판 동치 또는 기본 저장 성공을 뜻하지 않습니다.

## HWP5 새 차트 만들기

1. 예제는 **파일 > 예제 문서... > [기능 예제] HWP5 차트 생성과 미리보기**에서 선택하거나 위의 `hwp5-chart-create.hwp`를 내려받아 엽니다. 한국어 안내와 10/20/40 막대를 확인할 수 있습니다.
2. 새 차트는 **파일 > 새 문서**에서 문서 형식을 **HWP5**로 선택하고 **만들기**를 누릅니다. 일반 본문을 클릭해 글을 입력한 뒤 선택 영역 없이 커서를 둡니다.
3. **입력 > 차트**를 열고 **HWP5 차트 생성 방식**에서 **기본 막대 차트** 또는 **기본 선 차트**를 직접 선택합니다. 두 형식 모두 외부 한글 프로그램 호환은 미검증입니다. 범주/계열 이름과 숫자를 입력하고 너비/높이를 mm로 지정합니다.
4. **미리보기**로 확인하고 **차트 만들기**를 누릅니다. Canvas의 차트 표시와 실행 취소/다시 실행을 확인합니다.
5. **파일 > 저장하기**로 내려받습니다. 재조판 안내가 나오면 내용을 확인하고 **줄 배치가 달라질 수 있는 HWP 저장 허용**을 직접 선택한 뒤 다시 저장합니다. 내려받은 파일을 Canvas 편집기에서 다시 열어 차트를 확인합니다.

HWP5 생성은 현재 기본 2D 세로 묶은 막대, 2D 표준 꺾은선과 지원되는 일반 본문 커서에 한정합니다. 다른 차트 종류, 셀과 선택 영역, 혼합 차트와 임의 스타일/조판 편집은 포함하지 않습니다. 기존 HWP5 차트 데이터 편집은 아래의 별도 제한을 따릅니다. 예제의 재열기와 표시를 확인한 범위이며 외부 한글 프로그램의 전체 상호운용이나 npm 게시/공개 배포 완료를 뜻하지 않습니다.

## HWP5 기존 차트 데이터 편집

기존 데이터 편집 예제는 별도 파일 **[기능 예제] HWP5 차트 데이터 편집**입니다. 앱의 새 문서에서 만든 합성 차트를 편집·저장한 파일이며 본문에는 `H5_CHART_522A`라는 합성 표지가 있습니다. 처음 값은 10/73/40, 두 번째 범주 이름은 `항목 2-N9`입니다. 차트를 선택하고 **개체 속성 → 기존 차트 데이터 편집**을 열어 지원되는 숫자와 범주를 변경합니다. 위의 생성·미리보기 예제와 이 편집 예제는 구분합니다.

검증한 격리 소스는 소유권이 확인된 own 표준 2D 세로 묶은 막대 차트의 숫자 값과 기존 범주 이름을 수정합니다. 읽어서 보이는 모든 HWP5 차트가 편집 대상은 아니며 npm 게시본이나 공개 배포 상태와는 구분합니다. 위의 공개 `hwp5-chart-create.hwp`는 생성과 미리보기 예제이며 그 파일 자체의 데이터 편집을 검증한 예제가 아닙니다. in-process Reader에는 실제 Worker painter가 없어 편집이 비활성화될 수 있으므로 Worker에서 버튼의 현재 활성 여부를 확인하세요.

1. 실제 Worker를 사용하는 편집기에서 위의 **HWP5 새 차트 만들기** 순서로 지원하는 2D 차트를 만들고 저장한 파일을 다시 엽니다. Canvas의 차트를 더블클릭합니다.
2. **HWP5 차트 속성**에서 활성화된 **차트 데이터 편집**을 누릅니다. 버튼이 없거나 거부되면 표시된 차트를 임의 주소로 편집하지 않습니다.
3. grid의 숫자 또는 범주 셀을 선택하고 **선택한 차트 값**을 수정합니다. 여러 셀의 초안을 모아 **변경 일괄 적용**을 한 번 누르면 한 이력으로 반영됩니다. 계열 이름, 계열 수와 범주 수를 바꾸는 기능은 아닙니다.
4. **실행 취소**와 **다시 실행**으로 원래 값과 바뀐 화면을 확인합니다.
5. **파일 > 저장하기**를 누릅니다. 기본 저장이 `LayoutReflowRequired`로 거부되면 안내를 읽고 **줄 배치가 달라질 수 있는 HWP 저장 허용**을 직접 선택한 뒤 저장합니다. 이 동의는 기존 배치를 재계산하지 않으며 레이아웃 경고를 없애는 옵션이 아닙니다.
6. 내려받은 실제 파일을 다시 열고 차트 화면과 데이터 grid의 값을 확인합니다.

실제 검증에서는 `20 -> 73`과 `항목 2 -> 항목 2-N9`를 한 번에 적용하고 undo/redo, 저장과 fresh reopen을 확인했습니다. 임의 스타일, 다른 차트 종류와 크기/위치 편집은 이 범위에 포함하지 않습니다. 숫자와 범주의 한도 및 세부 검증은 [차트 편집 계약](https://github.com/ohah/hwpjs/blob/main/docs/hwp5-chart-literal-edit.md)을 따릅니다.

## 각주·미주 넣기

1. HWPX 문서의 본문에 커서를 둡니다.
2. 도구 모음에서 **각주** 또는 **미주**를 선택합니다.
3. **주석 본문**에 내용을 입력하고 **넣기**를 누릅니다. 삽입에 성공하면 주석 본문에서 입력을 이어갈 수 있습니다.
4. **파일 → 저장하기**로 문서를 내려받은 뒤 다시 엽니다.

각주나 미주를 방금 삽입했다면 실행 취소로 삽입과 번호 변경을 함께 되돌릴 수 있습니다.

## 표에서 셀 블록 선택하기

Canvas 데모에서 HWP5 또는 HWPX 표의 셀 안을 클릭한 뒤 아래 기본 단축키를 사용하세요. 셀이 선택되면 배경에 선택 표시가 나타납니다.

| 입력                           | 동작                                                                                                                                                                                                |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **F5 한 번**                   | 현재 셀 하나를 선택합니다. 방향키를 누르면 선택 범위를 늘리지 않고 인접한 셀로 옮깁니다.                                                                                                            |
| **F5 두 번** 또는 **Shift+F5** | 확장 모드로 들어갑니다. 한 셀이 선택된 상태에서 **F3**을 눌러도 확장 모드로 들어갑니다. 방향키로 시작 셀에서 현재 셀까지의 직사각형을 선택합니다. 직사각형에 걸치는 병합 셀은 셀 전체를 포함합니다. |
| **F5 세 번**                   | 현재 표의 모든 셀을 선택합니다. 확장 모드에서 F5를 한 번 더 눌러도 같은 동작을 합니다.                                                                                                              |
| **Esc** 또는 **Enter**         | 셀 블록을 해제하고 마지막 활성 셀에 커서를 둡니다.                                                                                                                                                  |

키를 누른 채로 유지해도 선택 단계가 연속으로 넘어가지 않습니다. 지원되는 셀에서는 커서를 둔 상태에서 문맥 메뉴를 열고 **셀 블록 설정**을 선택해 시작할 수도 있습니다. 키보드로 문맥 메뉴를 열려면 **Shift+F10**을 누르세요. 단축키는 데모의 **단축키 설정**에서 변경할 수 있습니다.

셀 블록은 현재 Canvas에서 전체 구조를 확인할 수 있는 HWP5·HWPX 표에 적용됩니다. 파일에서 연 원본 표와 데모에서 새로 만든 표가 해당됩니다. 본문, 일부만 표시된 표, 잘린 셀, 입력 반영이나 한글 조합이 진행 중인 상태에서는 선택을 시작할 수 없습니다. 표 메뉴나 표의 문맥 메뉴로 이동하면 현재 셀 블록이 유지됩니다. 그 밖으로 포커스를 옮기면 셀 블록이 해제됩니다.

블록 상태에서 **Delete**나 **Backspace**를 눌러도 셀 내용은 유지됩니다.

### HWPX 셀 합치기

저장된 HWPX 표에서 인접한 셀을 직사각형으로 선택하고 **표 → 셀 합치기** 또는 우클릭 메뉴의 **셀 합치기**를 선택하세요. 선택한 셀의 문단을 왼쪽 위 셀에 행 순서대로 모읍니다. 실행 취소와 다시 실행을 사용할 수 있습니다.

이미 병합된 셀, 보호된 영역, 중첩 표나 개체가 포함된 영역에는 합치기를 제공하지 않습니다. 생성한 표는 저장하고 다시 연 뒤 시도할 수 있습니다. HWP5 셀 합치기와 셀 너비·높이 균등화는 별도 범위입니다.

동작 참고 [한컴 WebHwp 단축키 일람](https://webhwpctrl.cloud.hancom.com/webhwpctrl/js/rights/shortcut/shortcut.htm) · [한컴 셀 블록 도움말](https://help.hancom.com/hoffice100/ko-KR/Hwp/table/table%28cell%29.htm)

## 개체 더블클릭

지원되는 차트와 그림을 더블클릭하면 개체 속성 창이 열립니다. 지원되는 HWPX와 HWP5 차트의 데이터 편집 버튼은 클릭한 차트에 연결됩니다. HWP5는 위의 [기존 차트 데이터 편집](#hwp5-기존-차트-데이터-편집) 조건을 만족할 때만 버튼을 제공합니다. 그림은 지원 조건에서 크기를 바꿀 수 있습니다. 글상자는 테두리 더블클릭으로 정보를 보고 내부 더블클릭으로 텍스트를 편집합니다. 지원되는 HWPX 차트/글상자와 HWP5 글상자의 크기/위치 편집은 [현재 개체 편집 범위](./limitations.md#최신-소스의-수식-표시와-개체-편집)를 따르며 그룹/회전 개체의 범용 편집을 뜻하지 않습니다. [상세 경계](https://github.com/ohah/hwpjs/blob/main/docs/canvas-object-activation.md)를 참고하세요.

### 선택한 개체의 속성

Canvas에서 차트나 그림을 한 번 클릭하고 선택 테두리가 표시되면, Canvas에 초점을 둔 상태에서 **P**를 눌러 현재 선택한 개체의 **개체 속성**을 엽니다. 글상자는 내부가 아닌 테두리를 클릭해 선택합니다. HWP5는 회전·그룹이 없는 독립 글상자에서 확인된 테두리의 정보 조회를 제공합니다.

**P**는 실제로 선택된 개체에서만 동작합니다. 일반 본문이나 글상자 내부에서 입력하는 `p`는 텍스트이며, 다른 입력칸까지 가로채는 전역 단축키가 아닙니다. 글상자 내부를 클릭하면 기존 커서로 계속 입력할 수 있습니다.

개체의 기본 정보 조회와 크기/위치 편집은 별도입니다. HWP5 차트의 크기/위치는 조회용입니다. 지원되는 HWPX와 HWP5 차트의 값은 속성 창의 데이터 편집 버튼이 활성화된 경우 수정할 수 있으며 HWP5는 위의 별도 범위를 따릅니다. 지원되는 HWPX 차트/글상자와 HWP5 글상자의 크기/위치 편집은 [편집 API](../api/editor.md#object-geometry)의 조건을 따릅니다. 그림 크기 편집도 지원 조건을 충족한 그림에 한하며 그룹/회전 개체의 범용 속성 편집을 뜻하지 않습니다.

## 새 그림 삽입

이 순서는 최신 개발 후보의 제품 연결을 설명합니다. 실제 브라우저 저장 검증과 공개 배포 완료를 뜻하지 않습니다. 이 격리 후보는 예제 목록에 **[기능 예제] 빈 HWP5 · 그림 삽입 준비**와 **[기능 예제] 빈 HWPX · 그림 삽입 준비**를 등록합니다. 파일에는 본문 텍스트나 그림이 없습니다. 공개 사이트 반영 전에는 **파일 → 새문서**에서 시작하세요.

| 빈 본문 예제        | 다운로드                                                                                                  |
| ------------------- | --------------------------------------------------------------------------------------------------------- |
| HWP5 그림 삽입 준비 | <a href="__HWPJS_DOCS_BASE__editor/fixtures/image-insert-blank.hwp" download>image-insert-blank.hwp</a>   |
| HWPX 그림 삽입 준비 | <a href="__HWPJS_DOCS_BASE__editor/fixtures/image-insert-blank.hwpx" download>image-insert-blank.hwpx</a> |

두 파일은616f SDK의 정상 새 문서 생성과 기본 저장으로 생산했습니다. 반복 생성 바이트 일치, 새 SDK 세션 재열기·기본 저장, 독립 raw 검사와 CLI 읽기를 확인했습니다. 그림을 삽입한 뒤의 브라우저 저장·재열기 성공을 뜻하지 않습니다.

1. 새 문서에서 HWP5 또는 HWPX를 선택하고 일반 본문의 빈 줄에 커서를 놓습니다. 선택 영역을 해제하고 글자 조합이 끝날 때까지 기다립니다.
2. **입력 → 그림**에서 PNG 또는 JPEG 파일을 선택합니다. 파일은8MiB 이하여야 하며 실제 형식과 읽을 수 있는 이미지인지 확인합니다. 셀·캡션·글상자에는 새 그림을 넣지 않습니다.
3. 너비·높이를 mm로 확인합니다. 처음 제안하는 크기는96px/inch와 원본 비율을 기준으로 최대150×150mm 안에 맞춘 값입니다. 용지 폭 자동 적합은 아닙니다.2:1 그림이라면25.4×12.7mm를 입력하는 예가 가능합니다. 비율 유지 설정도 확인하세요.
4. **그림 삽입**을 누릅니다. 파일 선택 중 커서나 문서가 바뀌면 창을 닫고 새로 선택합니다. 적용 뒤 실행 취소·다시 실행을 확인합니다. 결과를 다시 확인하라는 안내가 나오면 같은 그림을 곧바로 재삽입하지 마세요.
5. **파일 → 저장하기**로 현재 형식의 사본을 저장하고 다시 열어 그림·크기·앵커를 확인합니다. HWP5에서 조판 갱신 오류가 나면 기본 저장은 차단된 상태입니다. 편집된 문서를 보존할 필요가 있을 때만 **줄 배치가 달라질 수 있는 HWP 저장 허용**을 직접 선택하세요. 이 선택은 한글의 재조판과 같은 화면·쪽 위치를 보장하지 않습니다. 새 빈 baseline 저장에 이 동의를 켜지 않습니다.

현재 HWP5는 필드 없는 구역의 일반 최상위 본문 문단에 제한됩니다. 같은 문단에 이미 그림·차트 등 제어 개체가 있으면 다른 적합한 본문 문단을 사용해야 합니다. HWPX도 Native에서 소유권을 확인한 본문 대상만 받습니다. 읽기 전용·부분 문서·보호 영역·구형 엔진에서는 삽입을 제공하지 않습니다. [API 크기·대상 범위](../api/editor.md#그림-신규-삽입)와 [저장 제한](./limitations.md#그림-삽입과-hwp5-저장)을 함께 확인하세요.

## 선택한 그림의 파일 교체

1. **파일 → 예제 문서**에서 **HWP5 그림 크기 조절** 또는 **HWPX 그림 크기 조절**을 엽니다.
2. 그림을 더블클릭해 **개체 속성**을 열고 **이미지 파일 교체**에서 PNG 또는 JPEG 파일을 고릅니다.
3. 이미지 교체 후 **실행 취소**와 **다시 실행**으로 원본과 새 그림을 확인합니다. 문서를 저장한 뒤 다시 열어 새 그림을 확인합니다.

교체는 선택한 그림의 소유권을 확인할 수 있는 경우에 제공됩니다. 기존 개체의 크기·위치·자르기를 유지하므로 원본과 비율이 다른 이미지를 쓰면 기존 틀 기준으로 표시됩니다.

## 새로 만든 표의 셀 속성

빈 HWP5 또는 HWPX 예제의 본문에서 표를 만든 뒤, 바꿀 셀을 클릭하고 **표/셀 속성**을 엽니다. **셀 너비**와 **셀 높이**는 mm 또는 pt로 입력할 수 있습니다. 단색 배경과 바깥 테두리를 바꾸려면 해당 필드에 값을 입력하고 **확인**을 누르세요. 배경과 테두리 색은 6자리 RGB로 입력합니다.

생성 셀의 **채우기**에서 **채우기 없음**을 선택하면 배경을 지웁니다. **변경하지 않음**은 현재 배경을 유지합니다. 채우기 없음 상태에서는 색 입력이 비활성화되며, 함께 바꾸지 않은 셀 크기와 바깥 테두리는 유지됩니다.

한 번 확인한 변경은 실행 취소 한 단계로 기록됩니다. 기존 문서에 들어 있던 표는 현재 셀에서 선택할 수 있는 속성에 따라 다른 편집 창이 열립니다.

## 글상자의 바깥 여백

HWPX 문서에서 지원되는 본문 글상자의 테두리를 더블클릭해 **개체 속성**을 엽니다. **바깥 여백**에 mm 값을 입력하고 **바깥 여백 적용**을 누릅니다. 사각형 어울림에서는 네 방향을 편집할 수 있습니다. 위아래 배치에서는 위쪽과 아래쪽 입력만 열리며 좌우 값은 유지됩니다. 배치·크기·위치도 바꾸려면 한 항목을 적용한 뒤 속성 창을 다시 열어 다음 항목을 변경합니다. [SDK 조회와 적용](../api/editor.md#hwpx-글상자의-바깥-여백)
