# HWPX 샘플과 데모

이전에 공개 문서에서 제공하던 `noori.hwpx` 샘플을 같은 다운로드 경로로 유지합니다.

<a href="__HWPJS_DOCS_BASE__demo/noori.hwpx" download>noori.hwpx 다운로드</a>

이 페이지는 구 Rust/WASI 기반 변환 UI를 재사용하지 않습니다. 현재 `@hwpjs/core`는 명시적으로 주입한 Runtime으로 문서를 열고 지원되는 선택·명령과 현재 형식 저장을 제공합니다. [설치](./installation.md), [Runtime 설정](./runtime.md), [편집·저장](./editing.md)에서 현재 사용법을 확인하세요.

## 현재 Canvas 데모

[Canvas 웹 미리보기 열기](https://macstudio.tailed42f2.ts.net:10000/web/preview/index.html)

이 데모는 **Tailscale tailnet 접근이 필요**합니다. GitHub Pages에서 누구나 바로 실행할 수 있는 공개 편집기가 아닙니다. 샘플을 다운로드한 뒤, 접근 가능한 데모의 파일 열기에서 직접 선택하세요. 이 문서 사이트는 샘플을 자동 전송하거나 별도 업로드 서비스를 제공하지 않습니다.

HWPX의 ZIP/XML 형식 지원과 전체 문서·개체·조판의 완전한 지원은 다릅니다. [지원 범위](./limitations.md)를 확인하고, HWP 샘플이 필요하면 [noori.hwp 안내](./demo.md)를 사용하세요.
