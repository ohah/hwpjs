# 원본 표 여러 셀 세로 정렬

HWP5·HWPX 원본 표에서 두 개 이상의 셀을 범위로 선택한 뒤 표/셀 속성을 열면 위쪽, 가운데, 아래쪽을 지정할 수 있다. 선택한 셀의 값이 서로 다르면 ‘여러 값’으로 표시한다. 이 창에서 확인을 누르면 전체 범위가 한 번에 반영된다. 바뀔 값이 없으면 이력을 추가하지 않는다.

캔버스의 닫힌 사각형 선택을 현재 문서의 표, 셀 목록, 문단 소유권과 대조한다. 병합 셀의 전체 span이 범위에 들어오면 물리 셀 하나로 처리한다. 중복 소유자, 누락된 칸, 잘린 관측, 보호된 셀, 현재 선택이나 이력이 바뀐 요청은 거부한다. 조회와 적용은 한 번 쓸 수 있는 Native 관측으로 연결된다.

HWP5는 선택된 LIST_HEADER의 세로 정렬 비트를 갱신한다. 저장 시 조판 갱신이 필요한 경우 기존 조판 확인 절차를 따른다. HWPX는 선택된 subList의 속성을 갱신하고 해당 셀의 무효화가 필요한 줄 배치 캐시를 정리한다. 저장 대상과 겹치는 중첩 표가 있으면 편집 범위를 확정할 수 없어 거부한다. 두 형식 모두 다른 셀과 기존 편집 내용을 보존하며 한 번의 실행 취소로 직전 상태를 복원한다.

검증 명령은 [개발·검증 명령](development-commands.md#원본-표-여러-셀-세로-정렬)에 있다.
