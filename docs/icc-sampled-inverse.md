# ICC 샘플 곡선 역변환

## 명세와 계약

[ICC.1:2022 Annex F.1–F.3](https://www.color.org/specifications/ICC.1-2022-05.pdf)은 비상수 증가·감소 곡선의 역변환과 평탄 구간의 선택 규칙을 정의합니다. 끝까지 이어지지 않는 평탄 구간은 가장 큰 x를, 끝점까지 이어진 평탄 구간은 가장 작은 x를 선택합니다. 원래 값 범위 밖의 y는 가장 가까운 원래 y에 대응하는 x를 선택합니다. 상수나 비단조 곡선을 단순 파일 손상으로 취급하지 않으며 역변환 불가와 원시 파싱 실패는 별개입니다.

`sampled_inverse.invert(samples, y)`는 curveType 샘플 배열에만 적용합니다. 입력 y는 0–65535로 인코딩된 정규화 값이고 반환값은 정규화 x의 정확한 u64 분수입니다. 분수는 약분하지 않을 수 있습니다. 부동소수점 반올림·감마 평가·parametricCurve 평가는 포함하지 않습니다.

`invertNormalized(samples, numerator, denominator)`는 정규화 u128 분수 입력을 직접 받아 u256 분자·분모를 반환합니다. 0인 분모와 분자가 분모를 넘는 입력은 InvalidIccCurveCoordinate로 거부합니다. 부호 있는 행렬 결과의 0~1 제한은 Annex F.3에 따라 향후 모델 연결 계층이 담당하며 이 함수가 암묵적으로 처리하지 않습니다.

두 API는 동일한 비공개 ordinate 계산기를 사용합니다. 기존 API는 y/1, 정규화 API는 (65535×numerator)/denominator를 전달합니다. 샘플도 같은 분모로 확장한 뒤 비교·보간하므로 u16 격자로 양자화하지 않습니다. u128 입력에서 확장 ordinate는 2^144 미만, 결과 분모와 분자는 2^176 미만입니다. u256 중간값이 충분하며 기존 API의 출력만 증명된 2^48 미만 범위에서 u64로 변환합니다. 전체 단조성 검사·평탄 구간 선택·배열 경계 규칙은 복제하지 않습니다.

전체 배열의 단조성을 먼저 검사하므로, 처음에 답이 있어도 뒤쪽의 방향 반전을 놓치지 않습니다. 감소 곡선과 증가 곡선에 같은 x 위치 기준 평탄 규칙을 적용합니다. 배열 길이·최소 2개·최대 u32 개수를 검사한 후 계산하며 기존 u16 API의 중간 곱은 (u32 개수−1)×65535 이내입니다. 정규화 입력의 추가 분모 배율은 위 u256 범위 증명을 적용합니다. 시간은 O(n), 추가 공간은 O(1)이며 배열을 변경하거나 결과에 포인터를 보관하지 않습니다. 원본이 빌린 입력이므로 호출 중 변경해서는 안 됩니다.

[감마 역변환](icc-gamma-inverse.md)은 별도 계산기와 검증 기록에서 관리합니다. identity를 포함한 TRC 역방향 연결, para의 정의역·역함수, 행렬 계산 모델 연결, 제품 색상 변환과 전체 필수 태그 검증은 아직 남아 있습니다. 정규화 입력 추가만으로 모델 역변환이 완성된 것은 아닙니다. 샘플 순방향 보간은 아래 별도 문서에서 관리합니다. 기존 TRC 결과의 의미 보류 표시를 이 함수의 존재만으로 해제하지 않습니다.

## 검증

### 2026-09-08 정규화 입력 확장

네이티브 479/479 테스트가 통과했습니다. u128 최대 분모의 항등·감소 곡선, 격자 사이의 1/2 입력, 증가·감소 평탄 곡선별 65,536개 기존 입력과의 동치, 잘못된 좌표·비단조 꼬리·상수·배열 오류를 포함합니다. 별도 순방향 선분 식으로 만든 1,536개 분수 입력의 역변환도 대조했습니다. 기존 API와 새 API 간 대조는 공유 계산기의 독립 검증이 아니므로 독립 선분 식 및 WASM 기준 검사를 병행합니다.

WASM mode177은 u128 BE 분자·분모 32바이트와 curveType payload를 받아 u256 LE 분자·분모 64바이트를 반환합니다. 기존 독립 JS 역상 집합 기준에 분수 ordinate를 지원하여 같은 규칙의 두 번째 사본을 만들지 않았습니다. 전체 감사의 완료 결과는 실행 종료 후 기록합니다.

Debug WASM 직접 실행에서 새 경로 비교 905건·예상 오류 거부 5,808건, 기존 u16 경로 비교 965건·거부 6,734건이 통과했습니다. 길이 2~6의 세 값 배열 전수 조합, 최대 분모 부근 좌표, 평탄 경계의 양쪽 분수 입력, 잘림·한도·실패 후 정상 호출을 포함합니다. 별도 수동 검사에서 65535의 배수인 최대 u128 부근 분모를 사용해 증가·감소 곡선의 평탄 지점과 ±1 분자 차이 52건도 BigInt 기준과 일치했습니다. 이 52건은 정규 감사 수에 합산하지 않습니다.

시스템 ICC 실파일 읽기 전용 조사에서 Generic Gray Gamma 2.2 Profile.icc의 kTRC와 sRGB Profile.icc의 rTRC/gTRC/bTRC, 총 4개 샘플 태그(각 1,024개 샘플)에 최대 u128 분모의 좌표 6종을 적용했습니다. 24개 결과가 원본 샘플의 독립 역상 집합 기준과 정확하게 일치했습니다. 프로파일을 복사·수정하지 않았고 정규 감사 수에는 합산하지 않습니다. 공유 payload의 고유 개수나 전체 픽셀 변환 검증을 뜻하지 않습니다.

추가 적대적 검사에서 65,536개 샘플의 증가·감소 직선에 최대 u128 분모의 좌표 4종을 적용한 8건이 항등/반전의 직접 수식과 일치했습니다. 이 수동 검사는 정규 감사 수에 합산하지 않습니다. 이론적 최대 결과 분모 `(2^32−2)×65535×(2^128−1)`가 176비트임을 BigInt로 별도 확인했습니다. 최대 u32 개수의 실제 배열 할당 검사는 수행하지 않았습니다.

Debug 전체 감사는 `/tmp/hwpjs-icc-normalized-inverse-Debug.log`에서 종료 코드 0, 20/20 단계·네이티브 479/479·WASM 5,148,838건 검사로 통과했습니다. 새 경로 905/5,808과 기존 경로 965/6,734의 비교/거부 수를 모두 확인했습니다. ReleaseSafe도 `/tmp/hwpjs-icc-normalized-inverse-ReleaseSafe.log`에서 종료 코드 0과 동일한 단계·테스트·검사 수로 통과했습니다. ReleaseFast도 `/tmp/hwpjs-icc-normalized-inverse-ReleaseFast.log`에서 종료 코드 0, 20/20 단계·479/479·WASM 5,148,838건으로 통과하여 세 모드 검증을 마쳤습니다.

테스트 민감도 확인에서는 WASM 호출 직전 정규화 입력을 의도적으로 u16 격자에 내림 양자화하는 임시 래퍼를 삽입했습니다. 정상 제품은 변경하지 않았습니다. 새 독립 비교가 ERR_ASSERTION으로 이 변형을 검출하여, 중간 양자화 결함을 놓치지 않는 사례를 확인했습니다. 모든 가능한 잘못된 구현을 검출한다는 의미는 아닙니다.

최종 적대적 재검토에서 전체 배열 검사 후 반환, 시작/내부/끝 평탄 구간의 방향 독립 선택, 0 분모·범위 오류, 넓은 중간값과 기존 API 축소 범위, probe의 크기 한도·빌린 입력·반환 메모리 경계를 확인했습니다. 이번 범위에서 추가 결함은 발견하지 못했습니다. 제품 계산기는 두 API가 공유하고 독립 JS 기준도 기존 역상 집합 구현을 확장했습니다. 포맷·변경 JS 문법·diff 공백·문서 로컬 링크 1개 검사도 통과했습니다. 전체 문서 및 ICC 역변환 모델 완성을 뜻하지 않습니다.

### 이전 u16 입력 검증 이력

후속 [샘플 순방향 보간](icc-sampled-forward.md)은 위 역변환의 분수를 직접 입력받습니다. 분수 타입과 배열 경계 검사는 두 방향이 공유하며 감마·파라메트릭 평가로 확대하지 않습니다.

2026-09-07 포맷 검사와 `zig build test --summary all`이 5/5 단계, 네이티브 436/436으로 통과했습니다. 분수 비교는 교차 곱으로 수행하여 약분 형태에 의존하지 않습니다.

신규 네이티브 테스트는 증가·감소 보간, 범위 밖 값, 시작·중간·끝 평탄 구간, 범위 밖에서 평탄 구간으로 매핑되는 경우, 상수·비단조 꼬리·빈 배열·한 개 요소·홀수 바이트 배열을 검사합니다.

테스트 mode 157은 y u16 BE와 curveType payload를 받아 u64 LE 분자·분모를 반환합니다. 독립 JS 기준은 모든 선분과 목표 ordinate의 교점을 모아 평탄 구간 선택을 적용하며, 분수는 BigInt 교차 곱으로 대조합니다. 길이 2–6의 세 값 배열 전수 조합, 감소 곡선, 평탄/범위 밖 값, 65,536개 샘플, 잘림·한도·복구를 검사했습니다. 신규 Debug WASM 직접 실행에서 정상 비교 965건·예상 오류 거부 6,734건이 통과했습니다.

macOS `/System/Library/ColorSync/Profiles/`의 Generic Gray Gamma 2.2 Profile과 sRGB Profile에서 2개 이상의 샘플을 가진 curv 태그 4개를 조사했습니다. 끝값·중간값·범위 경계의 질의 총 28건이 독립 기준과 일치했습니다. 태그별 비교이며 공유 데이터의 고유 개수가 아닙니다. 시스템 프로파일을 수정·복제하지 않았고, 수동 대조는 자동 감사 수에 합산하지 않습니다. 전체 색상 변환 결과 대조가 아닙니다.

최종 Debug·ReleaseSafe·ReleaseFast 전체 감사가 모두 종료 코드 0, 20/20 단계, 네이티브 436/436, 감사 검사 4,555,409건으로 통과했습니다. 신규 비교 965건·예상 오류 거부 6,734건도 세 모드 모두 확인했습니다. 최종 로그는 로컬 `/tmp/hwpjs-icc-inverse-Debug-final.log`, `/tmp/hwpjs-icc-inverse-ReleaseSafe-final.log`, `/tmp/hwpjs-icc-inverse-ReleaseFast-final.log`입니다. 검사 건수는 반복·변형을 포함하며 문서 수나 포맷 지원률이 아닙니다.

재검토에서 최대 분모 `(2^32−2)×65535 = 281470681612290`이 2^48보다 작음을 BigInt로 확인했습니다. 보간 분자는 구간 내 질의에서 분모보다 작고, 정확한 샘플/평탄 구간 결과는 인덱스가 분모 이하입니다. 나눗셈 0은 비상수 검사와 엄격한 구간 내부 비교로 배제합니다. 전체 단조성 검사 전 조기 반환이 없으며 감소 곡선에서도 평탄 선택은 x 위치를 기준으로 합니다. 추가 결함은 발견하지 못했습니다. 포맷·JS 문법·diff 공백 검사도 통과했습니다.
