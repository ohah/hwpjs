# 반복 그림의 페이지별 그리기 후보

## 계약

원본 그림 하나는 section/pictureNode로 식별하지만 표시 인스턴스는 pageOrdinal/columnOrdinal로 구분합니다. picture-layers.mjs는 flowPictures의 첫 항목만 찾지 않고 같은 원본의 모든 명시적 위치를 선택합니다. 각 위치는 같은 쪽·단의 원본 문단 anchor 행을 가져야 하며, 다른 쪽의 행으로 표시 자격을 대신 증명하지 않습니다. 여러 위치에서 쪽 누락·잘못된 단·중복 쪽/단은 해당 원본의 반복 그리기를 거부합니다. 비유한/음수 크기의 rectangle은 그리지 않습니다. 구형 단일 위치의 쪽 생략 호환은 유지합니다.

원본 picture 객체와 자원 해독은 공유하며 페이지마다 다른 원본 객체나 별도 편집 캐시를 만들지 않습니다. 그림 coverage의 원본 개수와 페이지별 그리기 횟수는 다릅니다. 그룹 그림 경로는 이번 수정의 범위가 아닙니다.

## 검증

repeated-picture-layers.test.mjs는 같은 원본의 두 쪽, 같은 쪽 두 단, 해당 인스턴스 anchor 행 누락, 중복/잘못된 단, 무한 rectangle 및 원본 불변을 검사합니다. 수정 전 두 쪽 요청에서 첫 번째 y좌표만 반환해 실패했고 수정 후 둘 다 반환합니다. 기존 picture-inline 회귀와 합쳐25/25·skip0 통과했습니다.

실제 copay/5f3baacd/현재 JS 브라우저 회귀도16쪽·1206행·이미지8/8해독·꼬리 구간 drawImage6회로 통과했습니다. 산출물은 hwpjs-page-area-objects-H3ypKo이며 소유 세션/전용 서버는 finally로 닫았습니다. 이 문서에 반복 인스턴스가 실제로 둘 이상 선택됐다는 proof나 꼬리말 그림 픽셀 동치 검증은 아니므로, 반복 위치 자체의 회귀는 앞의 명시적 단위 입력이 소유합니다. 기본 데모 반영 전입니다.
