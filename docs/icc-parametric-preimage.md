# ICC 전체 파라메트릭 곡선의 도달 역상

u512 목표값의 solveWide 확장은 [넓은 전체 도달 역상](icc-extended-parametric-preimage.md)에서 관리합니다. 아래 기존 경로와 검증 순서·조립·빈 집합 판정을 공유합니다.

## 계약

`parametric_preimage.solve(precision, curve, n, d)`는 [0,1]에서 clip(f(x))=n/d인 모든 실제 x를 두 분기의 기여분 합집합으로 보존합니다. 정규화 u128 목표와 전체 곡선의 실수 정의역을 기존 거듭제곱 역상 경로에서 먼저 검증합니다. 결과는 undecided 또는 set입니다. 어느 한 분기의 해가 미확정이면 전체 결과를 undecided로 반환하며 확정된 다른 분기만 부분적으로 노출하지 않습니다.

set.linear는 [선형 역상](icc-linear-preimage.md)의 선택적 WideInterval입니다. null은 하위 분기의 기여분이 없다는 뜻으로, 분기 비활성과 활성 분기의 해 부재를 여기서 별도로 구분하지 않습니다. set.power는 [거듭제곱 역상](icc-power-preimage.md)의 선택적 Set이며 null이면 거듭제곱 분기가 비활성입니다. 활성이나 해가 없는 거듭제곱 분기는 source를 가진 빈 Set으로 남습니다. isEmpty는 두 기여분 모두 비어 있는지 판정합니다.

반환값은 정렬·병합·중복 제거한 표준 구간 목록이 아닙니다. 합집합 전체가 도달 역상이며 개별 분기나 항목을 전체 해로 취급하면 안 됩니다. 비단조 곡선의 여러 해도 그대로 반환하고 임의로 하나를 고르지 않습니다. 전체 역함수 적격성, F.1의 실제 최솟값/최댓값 선택, 가장 가까운 출력값의 존재 여부는 별도입니다. 빈 역상을 최근접 출력으로 채우지 않습니다.

## 분기 경계와 SSOT

후속 극값 조립에 필요한 [넓은 기호근 순서 비교](icc-normalized-root-order.md)는 별도 모듈이 소유합니다. 비교 기반의 구현을 극값 선택 완료로 간주하지 않습니다.

전체 역상의 하한·상한과 실제 도달 여부는 [역상 경계](icc-preimage-bounds.md)에서 관리합니다. 이는 F.1의 최종 선택과 별개입니다.

parametric_segments가 하위 [0,start)와 상위 [start,1]의 소유권을 결정합니다. start=1이면 상위의 닫힌 단일점이 남고, 상위가 비활성이면 하위 [0,1]의 끝이 포함됩니다. 이 계층은 그 규칙을 다시 구현하지 않고 기존 분기 역상 결과의 끝점 포함 정보를 유지합니다.

power_preimage와 linear_preimage가 각각의 해 집합을 소유하고, parametric_preimage는 검증 순서와 조립만 수행합니다. 결과 타입과 isEmpty는 parametric_preimage_types에 분리합니다. 반복 호출되는 순수 assemble은 같은 정의역·분기 정책을 공유하며 계산 규칙을 복제하지 않습니다. 코어는 할당·파일 접근·부동소수점 근사를 하지 않습니다.

## 검증 진행

신규 네이티브 검사는 0에서 1로 점프하는 곡선의 열린 하위 역상과 값 범위 틈, 마지막 x=1 단일점, 비활성 상위 분기의 선형 해, 하위 한 점과 상위 두 점의 세 분리 해, 상위 미확정 시 하위의 확정 해도 숨기는 정책, 하위에 해가 있어도 잘못된 전체 정의역을 거부하는 경우를 포함합니다. 전체 테스트 결과와 WASM 독립 대조·적대적 검증은 아래에 구분합니다.

추가 후 네이티브 전체 549/549가 통과했습니다.

## WASM 독립 대조

테스트 mode200 입력은 precision u32 BE, 목표 n/d u128 BE의 36바이트 뒤에 para 태그를 붙입니다. 미확정 출력은 status=0인 정확히 4바이트입니다. 확정 출력은 status=1 u32 LE, isEmpty u32 LE, 기존 136바이트 선형 역상 wire, 기존 가변 길이 거듭제곱 역상 wire 순서입니다. 두 직렬화는 전용 output helper로 옮겨 기존 mode193/199와 공유하며 기존 출력 계약은 바꾸지 않았습니다. 조립 시 임시 power 버퍼는 defer로 해제하고 결과에 복사하므로 반환 버퍼가 임시 데이터 수명에 의존하지 않습니다.

JS 검사는 독립 정의역/분기 기준으로 하위 구간과 계수를 구성하고, 독립 선형 critical-cell 기준과 정확한 분수·끝점 플래그를 대조합니다. 상위는 독립 거듭제곱 집합 기준으로 모든 기호 경계와 사이 구간을 검증합니다. 각 기여분이 정확하고 원본 분기 소유권을 보존하는지 확인한 뒤 isEmpty도 검사합니다. 제품의 전체 조립 결과를 기대값 생성에 사용하지 않습니다.

Debug 직접 검사에서 comparisons=5040, rejected=3135, undecided=1, membershipChecks=13422가 통과했습니다. membershipChecks는 상위 집합 내부의 대조 횟수이며 추가 WASM 호출 수가 아닙니다. 하위 slope·상위 offset·하위 offset을 서로 다른 값으로 조합해 계수 혼용을 검사하고, 열린 경계·마지막 단일점·점프 틈·세 분리 해·확정된 하위 해가 있는 상위 미확정·잘림·과잉·한도·정밀도·잘못된 목표·오류 후 복구를 포함합니다.

공통 출력 추출 후 기존 거듭제곱 검사는 comparisons=6440/rejected=3351/undecided=1/membershipChecks=18994, 선형 검사는 comparisons=1947/empty=5110/rejected=2655/chosen=1337/unattained=674로 통과했습니다.

형식상 유효한 출력에서 하위 기여분 삭제, 상위 기여분 삭제, 하위의 열린 끝을 닫기, 미확정 대신 확정된 하위 해만 노출하는 네 변형을 각각 ERR_ASSERTION으로 검출했습니다. 분기를 삭제할 때 isEmpty도 남은 내용에 맞췄으며, 부분 노출은 고정밀도 결과에서 하위만 복사해 유효한 wire로 만들었습니다. 제품 파일에는 오류를 남기지 않았습니다. 전체 세 모드 감사는 별도로 실행합니다.

## 실제 ICC 태그의 전체 집합 대조

시스템 DCI(P3) RGB, Display P3, ITU-2020, ITU-709, ROMM RGB의 type0/type3 para TRC 태그 15개를 읽기 전용으로 검사했습니다. 양의 비정수 g·양의 a·활성 구간의 음수가 아닌 밑을 확인했습니다. 목표 0/1의 상위 경계 x=(65536*y−b)/a와 하위 선형식의 경계를 정확한 유리수로 계산하고, x가 분기 시작 이상이면 상위 식을 적용하는 독립 기준과 반환 합집합을 비교했습니다.

전체 역상 집합 30개, 원래 분기 경계·반환 경계·목표 경계 및 그 사이 구간의 포함 여부 138회가 일치했습니다. 정규 audit checks에는 합산하지 않는 수동 검사이며 목표 0/1에 한정됩니다. 모든 목표값의 전체 프로파일 역변환이나 렌더링 품질 검증은 아닙니다.

## 최종 감사와 재검토

Debug·ReleaseSafe·ReleaseFast 전체 audit가 각각 20/20 단계, 네이티브 549/549, WASM checks=6,557,470으로 통과했습니다. comparisons/rejected/undecided 합계 8,176건이 이전 6,549,294건에 추가됐습니다. membershipChecks는 추가 WASM 호출로 세지 않습니다. 로컬 로그 `/tmp/hwpjs-icc-parametric-preimage-{Debug,ReleaseSafe,ReleaseFast}.log`는 임시 파일입니다.

ReleaseSafe·ReleaseFast 산출물 직접 검사도 같은 신규 수치로 통과했고, 하위 기여분을 제거하면서 isEmpty를 남은 내용에 맞추는 변형을 각각 검출했습니다. 변경 문서의 로컬 링크 9개·Zig 포맷·JS 문법·diff 공백 검사가 통과했습니다.

최종 재검토에서는 전체 정의역/목표 선행 검증, 미확정에서 부분 분기 비노출, 분기 경계 소유권과 마지막 단일점, 서로 다른 계수의 연결, 빈 집합 판정, 임시 직렬화 버퍼의 defer 해제와 복사 수명, 기존 모드의 출력 계약 보존을 확인했습니다. 해당 범위에서 추가 결함을 발견하지 않았습니다. 표준 구간 목록 정리와 전체 역함수 적격성·F.1 선택·최근접 출력 존재 판정은 여전히 미완료입니다.
