# 도형의 위아래 본문 예약

[도형 내부 그림 소속](drawing-picture-scope.md)은 내부 인라인 그림을 본문 그림과 분리하는 계약과 후속 실제 참조 조사 결과를 소유합니다.

[혼합 표 앵커](inline-table-host-anchors.md)는 같은 문단의 표·도형·그림 표시 문자를 구분하는 계약을 소유합니다.

## 책임

`drawing-page-reference.mjs`는 현재 UTF-16 앵커와 완전한 문단 행을 확인해 기준 영역을 선택합니다. 실제 도형 projection과 예약이 같은 함수를 사용합니다. 문단 기준 TOP_AND_BOTTOM·상단 정렬에서는 `flowAnchorY`를 사용해 예약 때문에 이동한 행을 다시 도형의 시작점으로 삼지 않습니다. 좌표 산술은 기존 `placeFloatingDrawing`을 재사용합니다.

`drawing-wrap-body-flow.mjs`는 원본 본문 재조판 콜백에 `rowY`와 `minimumRowPage`를 전달합니다. 페이지별 도형 예약은 기존 `intersectPictureLineRegions`에 위임하며, 가로 위치에 관계없이 위아래 감싸기의 전체 줄 제외와 외부 여백을 적용합니다. 예약이 바뀌면 원본에서 다시 조판하고 최대32회에 수렴하지 않으면 명시적으로 실패합니다. 기존 출력 행을 누적 이동하지 않습니다.

하위 조판기가 예약 옵션을 무시하거나 후속 표 배치가 예약 영역에 들어오면 `IncompleteDrawingWrapFlow`입니다. 본문 행뿐 아니라 제공된 표 collision footprint도 확인합니다. 변환된 본문 행은 별도 지원 전까지 거부합니다. 이 검사는 실제 표 외곽 inventory가 완전하다는 독립 보증을 대신하지 않습니다.

## 검증과 현재 연결 상태

`tests/hwpx/drawing-wrap-body-flow.test.mjs`의4개 검사는 원문·입력 불변, 예약과 실제 도형 좌표 일치, 앵커 유지, 외부 여백, 잘못된 예산, 비유한 기준점, 비수렴, 하위 본문 오류 전파, 옵션 무시 및 후속 표 침범 거부를 다룹니다. 기존 그림 정렬 회귀와 합쳐 격리 게시 소스5/5가 통과했습니다. 정규 HWPX 검사에 등록합니다.

2026-10-19 작업 트리에서는 본문·표 페이지 경로에 콜백을 연결한 후보를 검사했습니다. 추적 HWPX는 암호 기본 거부1개를 제외한45개가 기존과 같이 paginated입니다. 고정 폭/높이 측정의 Worker/페이지 검사이며 실제 글꼴 조판 동치나 전체 편집 검증은 아닙니다.

참조 `copay_cap_tac_table_leading.hwpx`와 `issue5543_carried_anchor_ladder.hwpx`는 도형 감싸기 정책 거부를 지난 뒤 `UnsupportedTablePagePictures`에서 중단됩니다. 도형 내부 문단에도 인라인 그림이 있으며 기존 본문 그림 분류·투영 순서와의 조합을 더 확인해야 합니다. 두 문서의 정상 페이지/화면 지원으로 집계하지 않습니다.

이번 게시 범위는 예약 엔진·공유 기준점·회귀입니다. 본문/표 진입점 연결과 wrap 정책 완화는 아직 미게시 후보이며, 실제 참조 문서 조합을 통과하기 전까지 main의 자동 도형 감싸기 지원으로 주장하지 않습니다.
