# ICC 클리핑된 거듭제곱 분기의 역상

## 계약과 표현

`power_preimage.solve(precision, curve, n, d)`는 활성 거듭제곱 분기에서 clip(f(x))=n/d인 모든 실제 x의 집합을 구합니다. 정규화 u128 목표 검증과 전체 곡선 정의역 검증은 [근 위치 계층](icc-normalized-root-locations.md)이 선행합니다. 결과는 inactive, undecided, 또는 set입니다. 빈 set은 활성 분기는 있으나 해가 없다는 뜻이며 inactive와 다릅니다. undecided에는 부분 결과를 넣지 않습니다.

set은 원본 Power source, 최대 여섯 기호 구간과 최대 두 위치가 판정된 기호근을 보존합니다. 구간 끝점은 기존 power_clip_types.Interval을 재사용하며 원래 포함 플래그를 유지합니다. 근과 기호 구간 경계는 source의 a/b를 통해 x를 뜻하고 f64 좌표를 생성하지 않습니다. 배열은 각 count 안에서만 읽습니다.

결과의 의미는 모든 구간과 점의 **집합 합집합**입니다. 정렬·병합·중복 제거된 목록이 아니며, 점이 구간 안에 있거나 경계와 중복될 수 있습니다. 기호근은 양수·음수 생성 순서로서 x 오름차순을 보장하지 않습니다. 개별 항목에 F.1 선택을 먼저 적용해서는 안 됩니다.

하위 선형 분기의 역상, 두 분기의 정규화된 전체 합집합, 단조성·비상수성에 따른 역변환 적격성, F.1 선택과 가장 가까운 출력값의 존재 여부는 후속 범위입니다.

## 완전성과 책임 분리

0<y<1에서는 clip(f)=y와 f=y가 동치이므로 정규화 근 위치 결과만 사용합니다. 전체 활성 분기가 동일한 값이면 source의 전체 구간 하나로 표현합니다.

y=0에서는 f≤0, y=1에서는 f≥1이 해입니다. [기존 클리핑 분할](icc-power-clipping.md)의 해당 zero/one 구간을 수집하고, 정확한 f=y 근도 함께 보존합니다. 클리핑 분할은 내부 경계를 오른쪽 조각에 귀속시키므로 평탄 구간만 모으면 끝의 등식 점을 놓칠 수 있습니다. 또한 (2x−1)²의 y=0처럼 평탄 구간 없이 단독 영점만 존재할 수도 있습니다. 등식 근을 함께 수집하면 두 경우를 모두 포함합니다.

근 위치가 미확정이거나 필요한 클리핑 분할이 미확정이면 전체 결과를 undecided로 반환합니다. 이미 수집한 점이나 구간을 확정된 전체 역상처럼 노출하지 않습니다. 위치와 클리핑은 각각 기존 공통 모듈이 소유하며, 이 계층은 합집합 구성만 수행합니다. 재호출되는 순수 assemble/검증은 같은 정책을 재사용하고 정의역 규칙을 복제하지 않습니다. 결과 타입은 power_preimage_types에 분리합니다.

## 검증 진행

네이티브 검사는 단독 영점, 내부 목표의 두 부호 근, 양쪽 포화 평탄 구간과 경계 근, 내부 zero 평탄 구간의 밑 영점 분할, 범위 밖 상수·전체 등식·빈 역상·inactive·잘못된 목표/정의역을 포함합니다. 활성 시작 출력보다 약 2^-160 큰 목표에서 128비트 undecided, 512비트 단일 내부 근 반환도 확인했습니다. 이 검사를 포함한 네이티브 전체 544/544가 통과했습니다. WASM 독립 대조·전체 모드 감사와 적대적 검증 결과는 아래에 구분합니다.

## 테스트 WASM 출력

mode199 입력은 precision u32 BE + 목표 n/d u128 BE의 36바이트 뒤에 para 태그를 붙입니다. 출력은 status u32 LE(0 inactive, 1 undecided, 2 set), interval_count u32, point_count u32입니다. inactive/undecided는 정확히 12바이트이며 두 count는 0입니다.

set은 12바이트 헤더 뒤에 기존 40바이트 source 구간 wire, a/b/g/offset i32 LE 네 값을 저장합니다. 68바이트 prefix 다음 각 구간은 32바이트 경계 두 개와 flags u32(총 68바이트), 각 점은 location u32와 76바이트 넓은 근(총 80바이트)입니다. 기존 mode189의 경계와 mode195의 근 직렬화를 전용 공통 helper로 추출해 재사용했습니다. wire 크기·의미는 기존 모드에서 바꾸지 않았습니다. 제품 JS API는 변경하지 않았습니다.

Debug WASM 직접 빌드에서 단독 영점·양쪽 포화 구간·범위 아래 상수의 출력 구조 세 건을 확인했습니다. 공통 helper 추출 후 기존 mode195 검사는 comparisons=1412, rejected=45, roots=1198, bridges=350, 클리핑 검사는 comparisons=7534, rejected=4022, pieces=8480으로 통과했습니다. 이 수치는 새 역상 집합의 완전성 검증을 대신하지 않습니다. 기호 경계·점 및 그 사이 열린 구간을 대상으로 하는 독립 집합 대조는 다음 절에 기록합니다.

## 독립 집합 대조와 오류 주입

독립 JS 기준은 입력 식에서 목표값·0·1의 모든 실근과 밑 영점을 구하고, source 끝점 및 출력 경계도 함께 모아 정확한 기호 순서로 정렬합니다. 각 경계점과 그 사이 열린 구간의 유리수 표본에서 반환 합집합의 포함 여부를 정확한 BigInt 거듭제곱 값 비교와 대조합니다. 출력 경계는 허용된 클리핑 수준/밑 영점/source 끝점인지, 출력 점은 목표값의 실제 근인지 먼저 검증합니다. 고정 격자만 검사하지 않으며, 제품의 평탄 구간·점 수집 알고리즘이나 상하한 계산을 기대값으로 재사용하지 않습니다.

모든 목표 근과 밑 영점 사이에는 원래 분기의 목표값 교차가 없습니다. 출력 구간 경계도 분할에 포함하므로 각 열린 구간에서 기대 포함 여부와 반환 집합의 포함 여부는 각각 일정합니다. 경계점 자체는 별도로 검사해 단독 영점과 끝점 포함을 검증합니다. 반환 집합의 중복 표현 자체는 오류로 보지 않습니다.

Debug 직접 검사는 comparisons=6440, rejected=3351, undecided=1, membershipChecks=18994로 통과했습니다. membershipChecks는 함수 호출 수가 아니라 반환 집합 내부 대조 횟수입니다. 다섯 curve 유형·양/음/영 지수·상수 밑·양/음 기울기·활성 시작/끝/비활성 분기·목표 0/1/1/3·넓은 분수·정밀도 승격과 입력 오류·복구를 포함합니다.

형식상 유효한 wire를 유지하면서 모든 점을 제거, 모든 구간을 제거, 미확정을 유효한 source를 가진 빈 set으로 바꾸는 세 오류 주입을 각각 ERR_ASSERTION으로 검출했습니다. 반환 복사본에만 적용했고 제품에는 변형을 남기지 않았습니다.

추가 재검토에서는 첫 구간의 양 끝 포함 플래그를 제거하는 변형과, 빈 set을 source 전체의 닫힌 구간으로 바꾸는 변형도 각각 ERR_ASSERTION으로 검출했습니다. 후자는 count·길이·source·경계 wire까지 유효하게 구성했습니다. 검증기가 해 누락뿐 아니라 잘못 추가된 해도 검출함을 확인했으며 제품 코드는 변경하지 않았습니다.

## 실제 ICC 태그의 집합 대조

시스템 DCI(P3) RGB, Display P3, ITU-2020, ITU-709, ROMM RGB의 type0/type3 para TRC 태그 15개를 읽기 전용으로 검사했습니다. 양의 비정수 g, 양의 a, 활성 구간에서 음수가 아닌 밑을 확인했습니다. 두 유형의 상위 출력 오프셋은 0이므로 y=0의 해는 밑 영점, y=1의 해는 밑≥1인 구간입니다. 경계 x=(65536*y−b)/a를 정확한 유리수로 계산해 반환된 기호 경계·근을 해석하고, 입력으로 구한 경계와 출력 경계의 모든 점 및 사이 구간을 대조했습니다.

실제 태그의 역상 집합 30개, 포함 여부 90회가 일치했습니다. 이는 목표 0/1에 한정한 수동 검증이며 정규 audit checks에 합산하지 않습니다. 모든 목표값·전체 프로파일 역변환이나 렌더링 품질 검증을 뜻하지 않습니다.

## 최종 감사

Debug·ReleaseSafe·ReleaseFast 전체 audit가 각각 20/20 단계, 네이티브 544/544, WASM checks=6,549,294로 통과했습니다. comparisons/rejected/undecided 합계 9,792건이 이전 6,539,502건에 추가됐습니다. membershipChecks는 추가 WASM 호출로 세지 않습니다. 로컬 로그 `/tmp/hwpjs-icc-power-preimage-{Debug,ReleaseSafe,ReleaseFast}.log`는 임시 파일입니다.

ReleaseSafe·ReleaseFast 산출물 직접 대조도 같은 신규 수치로 통과했고 점 누락 변형을 각각 검출했습니다. 로컬 문서 링크 7개·Zig 포맷·JS 문법·diff 공백 검사가 통과했습니다. 최종 재검토에서는 클리핑 경계 단독 해의 보존, 미확정의 부분 결과 비노출, 공유 source와 경계 표현, 고정 배열 count, 집합 중복 표현과 최종 역변환 선택의 구분을 확인했습니다. 해당 범위에서 추가 결함을 발견하지 않았습니다. 하위 선형 분기와의 합집합 정리 및 전체 역변환 선택은 여전히 미완료입니다.
