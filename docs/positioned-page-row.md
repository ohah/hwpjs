# 페이지 위치 확정 후 본문 행 조각

`paginateBodyRows`의 선택적 `measurePositionedRow(source,row,context)`는 현재 페이지·단·세로 위치에서 다시 측정합니다. `rowY`가 위치를 옮긴 뒤 호출하며, 새 페이지로 넘치면 그 페이지의 기준으로 다시 호출합니다. 기존 `measureRow`와 역할을 섞지 않고 옵션이 없을 때 기존 측정을 유지합니다.

SQUARE 그림의 양쪽 영역처럼 한 논리적 줄을 여러 표시 행으로 그려야 할 때 결과의 `positionedFragments`로 조각을 반환합니다. `positioned-row-fragments.mjs`는 원문 구간의 연속성과 grapheme/UTF-16 경계·모든 caret 경계·동일 소속·수치/너비/행 높이·실제 행 예산을 확인합니다. 표 식별자/배치 제어를 조각에 복제하거나 이미 배치된 페이지 좌표를 재사용할 수 없습니다. glyph 경계의 너비 비교에는 기존 배치 계층과 같은1e-8 수치 허용 범위를 사용하지만 좌표를 수정하거나 clamp하지 않습니다.

조각들은 같은 세로 위치에 놓이고 줄 높이는 한 번만 전진합니다. 총 행 예산은 조각 수로 계산합니다. 표시 결과에는 `spatialRows`를 명시해 viewport 시작 행 계산 때문에 같은 높이의 다른 조각이 빠지지 않게 합니다. 중간 표현인 `positionedFragments`는 최종 행에서 제거합니다.

`tests/hwpx/positioned-page-row.test.mjs`의4개 검사는 좌표 주입 순서·페이지 이동 뒤 재측정·줄 높이 한 번 전진·원문 불변·예산·빈 문단 삽입점·서로게이트 분할/경계 누락/오염된 좌표/소속/표 식별자 복제 거부를 다룹니다. 격리 게시 소스의 새4개·기존 그림 정렬1개·그림 원본 검사2개가7/7 통과했습니다. 현재 작업 트리의 기존 페이지 회귀와 새 검사는19/19입니다. 작업 트리와 게시 소스는 논리 앵커 등 미게시 코드 범위가 다르므로 결과를 합산하지 않습니다.

이 변경은 위치 기반 조판의 연결 경계입니다. 아직 표 본문의 SQUARE 그림 조판기가 이 콜백을 자동 선택하도록 연결한 상태가 아니며 실제 복합 참조 문서의 정상 표시나 브라우저 편집 완료를 뜻하지 않습니다.
