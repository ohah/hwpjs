# Canvas 개체 활성화

`surface.registerObjectActivation(listener)`은 현재 화면에서 더블클릭한 개체의 종류·주소와 현재 `StateToken`을 전달하고 등록 해제 함수를 반환한다. Canvas 호스트의 이벤트이며 Core에 DOM이나 WebHwpCtrl 호환 액션을 추가하지 않는다. 개체 주소만으로 편집 권한을 만들지 않는다. 소비자는 현재 token과 Native capability를 검증하는 기존 명령·조회 API를 사용한다.

## 관측과 수명

이미 그린 최신 프레임에서만 hit test한다. 입력·조합·이력 처리 중, 비활성 lease, 열린 modal, 문서 교체·이전 프레임에서는 열기를 허용하지 않는다. CSS 좌표·스크롤·확대율 변환은 직접 입력과 같은 함수를 사용한다. 뒤늦은 이벤트를 새 프레임에 재생하지 않는다. callback이 Native 상태를 바꾸거나 surface를 닫으면 나머지 전달을 중단한다. 같은 상태에서 modal을 연 사실만으로 다른 구독자의 통지를 없애지 않는다. 정리 후에는 listener와 DOM 이벤트를 해제한다. React/Svelte 데모 relay는 늦은 mount와 surface 교체에서 이전 구독을 해제한다.

## 데모 연결과 지원 경계

- 차트: 더블클릭으로 개체 속성을 열고 현재 Native 차트의 제목·크기·글자처럼 취급·위치 정보를 조회한다. 데이터 편집은 그 창의 별도 버튼으로 **같은 차트**에 연결한다. 차트의 크기·위치 변경은 지원하지 않는다. 기존 차트 데이터 창도 실제 capture 대상과 선택 항목을 일치시킨다.
- 그림: 기존 선택과 같은 hit 경로로 그림 속성 창을 연다. 현재 Native capability와 보호 조건을 만족하는 그림의 크기 편집만 연결한다. 회전·자르기·모든 배치 속성을 제공하는 창이 아니다.
- 글상자: 검증된 회전 없는 독립 개체의 테두리에서 정보 창을 연다. 테두리 판정은 화면 5 CSS px이며 확대율을 반영한다. 내부 더블클릭은 텍스트 입력 경로를 유지한다. 현재 창은 조회용이며 크기·배치 편집을 하지 않는다.

그룹·회전·소유자가 모호한 겹침·표시되지 않은 개체를 임의의 사각형이나 첫 번째 개체로 대체하지 않는다. 그림은 직접 입력의 기존 선택 우선순위를 유지하여 글상자 안의 그림을 다른 개체로 열지 않는다. 지원 가능한 Native 원값만 표시하고 상대 크기를 절대 mm로 추정하지 않는다. 글상자 텍스트는 기존 문서 순서와 증가하는 문단 번호를 검증해 선형으로 순회하며 정렬하거나 큰 번호 간격을 반복하지 않는다.

공식 공개 데모의 관측에서 차트·그림 더블클릭은 개체 속성, 글상자 내부는 텍스트 편집이었다. 선택 개체의 P 키 진입도 관측했지만 이 더블클릭 API 자체가 기본 단축키 전체나 범용 개체 선택 모델을 구현한 것은 아니다.

## 형식별 글상자 관측

`web/preview/drawing-observation.mjs`는 hit·demo relay·속성 조회의 읽기 SSOT다. H5 projected drawing에 HWPX source 필드를 요구하거나 누락 필드를 만들어 넣지 않고, 현재 raw component/control·anchor·local transform·body list/flow와 연결한다. H5는 증명된 독립 사각형·무회전·identity 변환만 허용한다. HWPX는 기존 원본 주소/transform 증명을 유지한다. 한 동기 query의 지역 index만 사용하며 문서/토큰 사이에 권위를 재사용하지 않는다. 소유 Surface 코드는 바꾸지 않으며 P handler는 별도의 현재 선택·token fence를 유지해야 한다.
