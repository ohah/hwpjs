# 0.1.1

SDK·CLI·MCP를 `@ohah/hwpjs` 한 패키지로 제공합니다. 별도 MCP 패키지를 설치할 필요가 없습니다. Node.js 24.20.0 이상에서 다음 명령을 사용합니다.

```sh
npx -y @ohah/hwpjs --help
npx -y @ohah/hwpjs read document.hwpx
npx -y @ohah/hwpjs mcp
```

기존 `hwpjs-mcp` 실행 파일도 같은 패키지에서 유지합니다. 새 진입점은 기존 CLI·서버를 같은 프로세스에서 실행하며 문서 파서나 엔진을 복제하지 않습니다.

0.1.0의 12개 MCP 도구에 표 전체 삭제·PNG/JPEG 그림 삽입·그림 바이트 교체·의미 HTML 내보내기를 추가해 총 16개를 제공합니다. root SDK의 `toHtml`도 공유 변환 계층을 사용합니다. 새 파일 변환에 필요한 Native ABI를 WASM에 포함합니다.

편집은 원본을 덮어쓰지 않고 새 파일로 저장합니다. 표 삭제·그림 삽입은 명시적인 stale-layout 동의가 필요하며 원본과 같은 조판을 보장하지 않습니다. 그림 삽입은 필드가 없는 구역의 지원 본문 문단에 인라인 PNG/JPEG 하나를 추가하는 범위입니다. HTML은 문서의 의미 구조이며 원본 서식·페이지 배치를 재현하지 않습니다. 기존 편집 세션·웹 UI의 undo에 파일 변환이 연결됐다는 뜻은 아닙니다.

기존 한컴 문서 형식 공개 명세와 참조 구현을 바탕으로 개발했으며, 세부 출처와 라이선스는 패키지의 THIRD_PARTY_NOTICES.md 및 프로젝트 문서를 따릅니다.
