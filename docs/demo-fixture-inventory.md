# 전체 데모 픽스쳐 목록

`web/preview/fixture-inventory.mjs`는 Git 추적 HWP/HWPX101경로의 명시적 허용 목록을 소유합니다. `fixture-catalog.mjs`는 이 목록과 기존 참조 행정 편람1개를 조립하고 URL을 소유합니다. 서버는 같은 카탈로그만 제공합니다. 실행 중 디렉터리를 탐색하거나 임의 경로를 공개하지 않습니다. 문서 추가/제거 시 목록을 갱신하며 `tests/hwpx/fixture-inventory.test.mjs`가 Git 목록과의 정확한 차이를 거부합니다.

서로 다른 경로의 같은 파일명은 경로 SHA256 앞16자리와 원래 파일명을 ID로 사용합니다. UI 표시에는 경로를 덧붙이며 loader에 전달하는 원래 파일명은 바꾸지 않습니다. ID 중복은 검사에서 거부합니다. 한 경로의 여러 사본을 지원 성공 수로 합산하지 않습니다.

2026-10-10 모든101추적 입력은 실제 CFB55/ZIP46서명이고64MiB 이하입니다. 이는 HWP5/HWPX 전체 의미·편집 지원 증명이 아닙니다. HWP3 입력은 이번 목록에 없으며 지원 범위에도 추가하지 않습니다. 암호/배포 문서도 숨기지 않고 기존 명시적 암호/편집 정책을 유지합니다.

전체 목록·카탈로그 원본/GET/HEAD·경로 거부·입력 준비 실패 원자성·UI lazy loader4파일8/8·skip0·exit0과465모듈 static 연결을 확인했습니다. 데모 서버만 PID79172에서97214로 재시작했고 외부 HTTPS의102파일 모두 HTTP200·원본 해시 일치였습니다. Tailscale나 기본 WASM은 이 변경으로 바꾸지 않았습니다. 다운로드 가능함을102파일 모두 편집 가능하다는 뜻으로 읽지 않습니다.
