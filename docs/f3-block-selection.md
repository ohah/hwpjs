# F3 블록 선택

Canvas에서 F3를 누르면 현재 커서에서 블록 설정을 시작합니다. 이어서 누를 때 낱말, 문단, 문서 범위로 확장합니다. 첫 단계에서 좌우 방향키로 범위를 늘릴 수 있고, Escape로 블록 설정을 끝냅니다. 단축키 설정에서 F3를 다른 키로 바꿀 수 있습니다.

문서 전체 단계는 같은 본문 소유 범위가 완전하게 확인될 때 제공합니다. 잘린 문서나 서로 다른 편집 범위를 하나로 묶을 수 없는 경우에는 확인된 선택 범위를 유지합니다. 조합 입력 중에는 블록 단계로 전환하지 않으며, 키를 누르고 있을 때 발생하는 자동 반복은 다음 단계로 세지 않습니다.

Vanilla·React·Svelte의 Canvas에서 같은 단계와 저장 바이트 보존을 확인했습니다.
