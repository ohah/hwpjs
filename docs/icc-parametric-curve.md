# ICC parametricCurveType 원시 파서

## 계약

[ICC.1:2022 §10.18, Tables 67/68](https://www.color.org/specifications/ICC.1-2022-05.pdf)에 따라 `parametric_curve.zig`가 para 타입을 읽습니다. 함수 종류 0–4의 파라미터 수는 1·3·4·5·7개이며 순서는 g·a·b·c·d·e·f입니다. `Function.count`가 제품 코드의 개수 규칙을 소유합니다. 원시 signed s15Fixed16 값은 변환 없이 소유하는 배열로 반환합니다. `get(Parameter)`는 해당 함수에 없는 필드를 null로 반환하므로 부재와 0을 구분합니다. values의 미사용 저장 슬롯은 파라미터가 아닙니다.

타입 접두사는 기존 검사기를 재사용하고 추가 예약 필드(10–11바이트), 지원 함수 번호, 정확한 payload 길이를 검사합니다. 미지원 함수는 전용 오류로 반환하며 보정하지 않습니다. 할당·빌린 입력·파일 접근이 없고 개수 곱셈은 검증된 최대 7개에만 적용됩니다.

이는 원시 배치 검사입니다. 파라미터로 인해 생길 수 있는 복소수·정의되지 않는 함수, 감마 지수, 구간 연결, 출력 clipping, TRC별 관계와 필수 태그 검사는 아직 하지 않습니다. 명세가 2010 판본과 다른 수식 표를 명시하므로 수학적 평가를 추가할 때 2022 표를 기준으로 별도 검증해야 합니다. v2 지원으로 소급하지 않습니다.

## 검증 기록

후속 수학적 평가는 [감마·파라메트릭 순방향 평가](icc-analytic-forward.md)에서 별도로 구현·검증 중입니다. 아래 기록은 원시 파서 검증 이력이며 계산 검증으로 확대하지 않습니다.

신규 Debug WASM에서 독립 JS 대조를 직접 실행하여 비교 141건·예상 오류 거부 66,141건이 통과했습니다. 정규 전체 감사 완료와는 구분합니다.

macOS의 `/System/Library/ColorSync/Profiles/`를 읽기 전용으로 조사했습니다. DCI(P3) RGB, Display P3, ITU-2020, ITU-709, ROMM RGB의 v4 파일 5개에서 최상위 para 태그 각 3개, 총 15개가 독립 Node 정수 읽기와 mode 154 결과에 일치했습니다. 파일이나 제품 데이터를 저장소로 복제하지 않았습니다. 실파일에서 확인한 함수는 0·3이며 1·2·4의 실파일 근거는 아직 없습니다. 비교 수는 태그 기준이며 공유 데이터의 고유 개수가 아닙니다. 이는 원시 파싱 비교이며 수학적 평가·색상 출력 또는 전체 프로파일 유효성 검증이 아닙니다.

2026-09-07 최초 테스트 빌드의 불필요한 세미콜론을 수정한 뒤 포맷 검사와 네이티브 테스트가 5/5 단계, 431/431로 통과했습니다. 각 함수의 파라미터 순서·signed 경계·입력 변경 후 소유 값·부재와 0을 검사했습니다. 16비트 함수 번호 전체, 길이 0–41, 타입과 두 예약 영역의 손상·복구도 검사합니다.

테스트 mode 154는 함수 번호와 존재하는 파라미터만 little-endian으로 반환합니다. JS 기대값은 제품의 개수 규칙에서 생성하지 않고 별도 배열에서 구성합니다. 모든 미지원 함수 번호와 파라미터별 경계값, 길이, 접두사/예약 필드의 각 비트 손상·한도·복구를 정규 감사에 연결했습니다. 최종 Debug·ReleaseSafe·ReleaseFast 감사가 모두 종료 코드 0, 20/20 단계, 네이티브 431/431, 감사 검사 4,546,464건으로 통과했습니다. 신규 비교 141건·예상 오류 거부 66,141건도 세 모드 모두 확인했습니다. 최종 로그는 로컬 `/tmp/hwpjs-icc-parametric-Debug-final.log`, `/tmp/hwpjs-icc-parametric-ReleaseSafe-final.log`, `/tmp/hwpjs-icc-parametric-ReleaseFast-final.log`입니다. 검사 건수는 반복·변형을 포함하며 문서 수나 지원률이 아닙니다.

코드 재검토에서 Function.count의 단일 정의, 부재와 0의 구분, 소유 값의 입력 수명 독립성, 미지원 함수 번호와 추가 예약 필드 처리를 확인했습니다. 추가 결함은 발견하지 못했으나 함수 유효성과 수학적 평가의 미완료 범위는 그대로 남아 있습니다. Zig 포맷·변경 JS 문법·diff 공백 검사도 통과했습니다.
