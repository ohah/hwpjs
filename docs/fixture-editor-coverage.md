[중첩 목록 편집](hwp5-nested-text-edit.md) 연결 후 같은 1,481문단 중 712개가 삽입·저장 대조에 성공했습니다. 26파일은 일부 성공, 19파일은 전부 거부이며 3개의 미리보기 거부와 HWPX 45개의 공개 연결 미구현은 그대로입니다. software는 101문단 중 70개 성공입니다. 남은 전체 거부는 제어 포함 228건·텍스트 부재 383건·구역 컨트롤 정책 157건·미지원 중첩 소유 1건입니다. 이전에 먼저 걸리던 중첩 제한이 제거되면서 뒤의 거부 이유가 드러났으며, 새로운 파일 손상을 발견했다는 뜻은 아닙니다. 전체 목표는 계속 미완료입니다.

[기존 빈 문단 연결](hwp5-empty-text-edit.md) 직후 실측은 1,481문단 중 1,095개 성공이었습니다. 당시 32파일 일부 성공·13파일 전부 거부·3파일 미리보기 거부이며 HWPX 45개는 공개 연결 미구현이었습니다. software는 당시 101문단 중 93개 성공·제어 포함 8개 거부였습니다. 최신 수치는 문서 첫머리를 따르며 일반 저장·원본 조판 완료를 뜻하지 않습니다.

- 두 포맷의 편집 모델·저장 계약 확장과 임의 위치·미지원 명령 검증. HWPX 공개 읽기·편집·저장은 연결됐으나 전체 의미 모델 완성은 아닙니다.
- rhwp의 셀 경로·명령 이력·조판 갱신 책임을 참고한 Canvas UI 및 실제 픽스쳐 E2E.
