# Axis 선택 배치의 연속 경계 검증

## 후보 재시도에서 단일 경계 계산으로

기존 [배율 본문 조사](hwp5-chart-value-text-evidence.md)는 +54/+78 후보를 진단용으로 재시도했습니다. 새 조사기는 **Axis 원시 82바이트의 +6 u16**을 관측 선택 값으로 사용합니다. 0이면 짧은 꼬리, 1이면 24바이트가 추가되는 배치를 한 번만 읽습니다. 다른 선택 값은 UnsupportedAxisTailLayout으로 거부하며 길이를 추측하거나 타입 문자열을 검색하지 않습니다.

꼬리는 배율 값의 TextBlock 기반 클래스 끝에서 시작합니다. 배율 배열이 0/0이면 Axis 제목 뒤 배열 헤더 끝에서 바로 시작합니다. 관측 배치는 raw36, 선택 값 1일 때 raw24, raw14, 알려진 VtObject v1 타입 참조 네 바이트입니다. 길이는 각각 54/78바이트입니다. 각 raw를 복사해 보존하며 마지막 기반 타입과 버전을 확인합니다.

공식 차트 revision 1.2의 AxisScale(3.9)·ScaleType(4.38) 표를 확인했습니다. API 표는 wire 순서를 제공하지 않으므로 +6 값을 Log/Date/Value 등 의미 이름으로 확정하지 않습니다. raw36/24/14도 의미 필드로 완전 분해한 것이 아닙니다. 선택 값 2 이상, 다른 Axis 버전, 전체 비문자열 객체 충돌과 포맷 의미 검증은 미완료입니다.

## 책임 분리

- `chart-axis-tail-evidence.mjs`: 명시적으로 주어진 선택 값의 꼬리 배치·raw 보존·마지막 타입·경계 오류만 소유합니다.
- `chart-axis-evidence.mjs`: 기존 Axis 접두부와 선택 ValueBlock/TextBlock 조사기를 조립하고 +6 선택 값을 전달합니다. 타입·String·숫자 사전을 복제해 다음 Axis 상태를 반환합니다. 값 본문이나 타입/문자열 읽기를 다시 구현하지 않습니다.
- `chart-axis-survey.mjs`: corpus 순회, 정확히 이어지는 다음 VtAxis 타입 확인, SHA-256, 잘림/변형 검증과 집계를 담당합니다. 입력에서 관측된 축 4개를 corpus 회귀 기대값으로 검사하며 일반 파일의 축 수를 4로 제한하는 제품 규칙이 아닙니다.

이번 결과는 **선택 배치의 Axis 경계 조사**입니다. 제품 Zig Axis 파서·레이아웃·저장 구현이나 모든 필드 의미 지원을 뜻하지 않습니다. 기존 후보 조사 스크립트는 과거 진단 재현용이며 새 조립기는 이를 호출하지 않습니다.

## 실제 43개 결과

43개 모두 Axis **4개씩, 총 172개**를 끊김 없이 읽었습니다. 처음 두 개뿐 아니라 뒤의 축에도 같은 계산이 적용됐습니다. 그중 배율 값 있음 69개, 없음 103개, 긴 꼬리 6개, 숫자 선택 값 2개였습니다. 이후 구간은 읽지 않은 Plot 후속 데이터로 남습니다. 입력 SHA-256·각 축/값/꼬리·끝 위치는 `/tmp/hwpjs-chart-axis-survey.json`에 기록했습니다.

## 적대적 검증

- 전체 Axis 구간의 모든 잘림 **106,011건**을 정확한 일반 incomplete Error로 거부했습니다.
- 각 축의 +6 선택 값을 뒤집은 **172건**, 마지막 타입 ID를 FFFFFFFF로 바꾼 **172건**을 UnsupportedAxisTailType으로 거부했습니다. 실패하면 다른 길이를 재시도하지 않습니다.
- 각 축의 정확한 끝에서 자르거나 이후 전체를 FF로 바꿔도 결과가 원본과 같았습니다. 다음 객체 내용을 빌려 경계를 맞추지 않습니다.
- 꼬리 합성 테스트 2개는 선택 0/1, offset 0/1/17/257, 희소 타입 ID, FF/80/A5 원시 값, 모든 잘림, 미지원 선택 값, 잘못된 기반 클래스/버전, 잘못된 offset, 뒤 데이터와 복사 수명을 검사합니다.
- `/tmp/hwpjs-chart-axis-tail-mutants.y7mcul`의 raw 삭제, 긴 꼬리 소비 누락, 기반 타입 검사 생략, 버전 검사 생략, 끝 위치 오류, offset 0 강제 **6종**은 구문 검사 후 런타임 실패(종료 코드 1)로 검출됐습니다.

```sh
node --test tests/hwp5/chart-axis-tail-evidence.test.mjs
node tests/hwp5/chart-axis-survey.mjs --verify
```

제품이나 정규 audit 경로를 변경하지 않은 독립 조사 단계입니다. 직전의 전체 Zig audit 수치를 재실행 결과로 재사용하지 않습니다. 다음 제품 구현에서는 조사로 확인한 배치와 기존 공통 파서를 연결하되, nullable 본문·숫자 값 참조·객체 사전 소유권과 실패 경로 검증이 추가로 필요합니다.
