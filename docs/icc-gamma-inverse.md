# ICC 감마 역변환

## 계약

[ICC.1:2022 §10.6·Annex F.1](https://www.color.org/specifications/ICC.1-2022-05.pdf)의 curveType 단일 값은 순방향 지수 γ입니다. `gamma_inverse.evaluate(raw, y)`는 γ=raw/256인 곡선의 역함수 `y^(256/raw)`를 계산합니다. 입력은 유한한 f64 [0,1]이고 결과는 근사 f64입니다. 역지수를 다시 u8Fixed8로 인코딩하거나 샘플 배열로 근사하지 않습니다.

raw>0이면 실수 함수는 전체 [0,1]에서 연속·엄격 증가이고 양 끝점은 0과 1입니다. 따라서 샘플 곡선의 평탄 구간 탐색이 필요하지 않습니다. 부동소수점 출력의 언더플로·반올림으로 같은 결과가 나오는 현상을 원래 실수 곡선의 평탄 구간으로 취급하지 않습니다. raw=0은 (0,1]에서 상수이고 기존 계산 정책상 0^0도 정의되지 않아 모든 정상 좌표에서 NonInvertibleIccGamma를 반환합니다. 원시 태그 파서는 raw=0을 계속 보존하며 역변환 실패와 파일 파싱 실패를 구분합니다.

좌표 검사·거듭제곱·출력 범위 제한은 기존 curve_math를 재사용합니다. 잘못된 좌표는 감마 검사보다 먼저 InvalidIccCurveCoordinate를 반환합니다. raw=256은 입력을 그대로 반환하여 항등 계산에서 최소 양의 f64도 보존합니다. 모든 경로에서 strict float 정책을 사용합니다. 비할당 순수 계산이며 f64 전수 정확 반올림이나 임의 정밀도는 보증하지 않습니다.

이 함수는 감마 역변환만 소유합니다. 행렬 결과의 0~1 제한, 정확 분수의 명시적 근사 변환, identity·sample·para를 연결하는 TRC 역방향 디스패처, 파라메트릭 곡선 전체 단조성·역함수, 프로파일·픽셀 연결은 후속 범위입니다. 기존 [샘플 역변환](icc-sampled-inverse.md)과 [감마·파라메트릭 순방향](icc-analytic-forward.md)의 책임을 합치지 않습니다.

## 검증 설계와 실행 기록

후속 파라메트릭 역변환의 선행 조건은 [전체 정의역 검사](icc-parametric-domain.md)에서 관리합니다. 이 검사를 감마 계산이나 역변환 전체 완료와 혼동하지 않습니다.

테스트 mode178은 mode159와 같은 f64 BE 좌표+curveType payload 입력 및 f64 LE 출력 형식을 사용합니다. analytic probe의 명시적 operation 분기로 계산기만 선택하며 태그 파싱·출력 직렬화를 복제하지 않습니다. 기존 mode159/160의 wire 형식은 유지합니다.

네이티브 테스트는 모든 양의 u16 감마에서 끝점, 항등의 비정규수 보존, 제곱·제곱근·최소 지수·언더플로, 0 감마와 비유한/범위 밖 좌표를 검사합니다. WASM 독립 수식 대조는 모든 양의 감마 값에 8개 좌표를 적용합니다. 일반 비교 허용 오차는 `2e-12×|expected|+8×Number.MIN_VALUE`로 작은 결과를 고정 절대 오차에 묻지 않습니다. 별도로 2의 거듭제곱 입력과 정수 결과 지수의 사례는 역지수 Math.pow에 의존하지 않는 직접 이진수 기대값과 같은 오차 정책으로 비교합니다. 항등과 선택한 정확 결과는 정확 비교를 유지합니다. 잘림·한도·잘못된 곡선 종류·실패 후 정상 호출도 포함합니다. 실행 완료 전에는 통과로 기록하지 않습니다.

최초 네이티브 실행은 5/5 단계·482/482로 통과했습니다. 최초 Debug WASM 직접 실행은 일반 거듭제곱에 비트 동일성을 요구한 테스트에서 `0.12500000000000003 != 0.125`로 실패했습니다. 이진 거듭제곱 사례를 별도 조사한 최대 차이는 g=1024, y=2^-884에서 127 ULP(상대 약 1.4e-14)였습니다. 근사 계약의 제품 계산기는 변경하지 않고 일반 거듭제곱 검사를 사전에 정한 상대 오차 계약으로 맞췄습니다. 비트 단위 정확 반올림을 달성했다는 주장은 하지 않으며, 최초 실패 실행은 최종 통과 근거에서 제외합니다.

수정된 Debug WASM 직접 대조는 비교 534,900건·예상 오류 거부 49건으로 통과했습니다. 최초 전체 감사 `/tmp/hwpjs-icc-gamma-inverse-Debug.log`도 이전 테스트의 정확 비교에서 종료 코드 1로 실패했습니다. 수정본 전체 감사는 별도 `-Debug-final.log`로 실행합니다.

독립 고정밀 수동 기준은 Python 표준 Decimal의 정밀도 120자리에서 `exp(ln(Decimal.from_float(y))×256/Decimal(raw))`를 계산한 뒤 f64로 변환하여 만들었습니다. raw=[257,511,513,768,65535], y=[2^-1074,0.5,1-2^-53]의 15개 조합을 실제 WASM 출력과 비교한 최대 상대 차이는 약 5.095e-14였고 위 허용 오차 안에 들었습니다. 256/raw를 먼저 f64로 반올림하지 않은 기준이므로 일반 JS 수식과 다른 수치 경로입니다. 모든 감마/좌표에서 이 오차 이하라는 보증은 아닙니다.

시스템 실파일 ACESCG Linear, AdobeRGB1998, Generic Gray Profile, Generic RGB Profile의 감마 TRC 태그 10개에서 raw 256/563/461과 좌표 7종(0·최소 비정규수·최소 정규수·1/8·1/2·1 바로 아래·1)을 확인했습니다. 70건이 독립 JS 수식과 허용 오차 안에서 일치했습니다. 태그별 집계이며 공유 payload의 고유 개수는 아닙니다. 읽기 전용으로 사용했고 프로파일 파일을 복사·수정하지 않았습니다. 고정밀·실파일 수동 검사 수는 정규 감사 수에 합산하지 않습니다.

테스트 민감도 검사는 mode178 대신 기존 순방향 mode159를 호출하도록 임시로 치환하여 수행했습니다. 새 비교가 ERR_ASSERTION으로 잘못된 지수 방향을 검출했습니다. 제품 코드나 저장소 파일에 변형을 남기지 않았습니다.

추가 수동 단조성 조사에서는 모든 양의 u16 감마에 최소 비정규수·정규/비정규 경계·1/2 경계·1 바로 아래의 4개 구간마다 연속 f64 값 4개를 적용했습니다. 총 1,048,560번 평가의 인접 결과 786,420쌍에서 감소는 관측하지 못했습니다. 반올림에 의한 동률은 허용합니다. 전 f64 정의역의 수치 단조성 증명은 아니며 정규 감사 수에 합산하지 않습니다.

Debug 전체 감사는 종료 코드 0, 로그의 20/20 단계·482/482를 확인했으나 저장 공간 부족 시점에 WASM 상세 JSON이 로그에 남지 않았습니다. 따라서 그 로그만으로 WASM 검사 수를 확정하지 않습니다. 문서 추가 쓰기도 한 차례 실패했으며 기존 문서 내용은 보존됐습니다. 이후 저장 공간이 외부 요인으로 회복된 것을 확인했고 에이전트가 캐시나 사용자 파일을 삭제하지 않았습니다. 기존 Debug WASM을 재빌드 없이 실행하여 stdout JSON을 메모리에서 검증하고 누락된 결과를 재확인합니다.

Debug WASM 감사 재실행이 종료 코드 0으로 완료됐습니다. stdout을 별도 Node 프로세스의 메모리에서 JSON.parse하여 전체 검사 5,683,787건·외부 import 0개·감마 역변환 비교 534,900건/거부 49건·정규화 샘플 역변환 비교 905건/거부 5,808건을 확인했습니다. 재실행에 사용한 제품 바이너리는 최초 Debug 감사와 동일한 `.zig-cache/o/32db7ccdd88aab52098081c4cb93f9db/hwp5-probe.wasm`입니다. 앞서 확인한 20/20 단계·482/482 결과와 누락됐던 WASM 상세 결과를 구분해 기록합니다. ReleaseSafe·ReleaseFast는 완료 후 별도 기록합니다.

ReleaseSafe 전체 감사는 `/tmp/hwpjs-icc-gamma-inverse-ReleaseSafe-final.log`에서 종료 코드 0, 20/20 단계·네이티브 482/482·WASM 5,683,787건으로 통과했습니다. 감마 역변환의 비교 534,900건·오류 거부 49건도 동일하게 확인했습니다.

ReleaseFast 전체 감사도 `/tmp/hwpjs-icc-gamma-inverse-ReleaseFast-final.log`에서 종료 코드 0, 20/20 단계·네이티브 482/482·WASM 5,683,787건으로 통과했습니다. 감마 역변환 비교/거부 수도 동일합니다. 이로써 세 모드 확인을 마쳤으며 위 완료 전 표현은 실행 당시의 기록입니다.

최종 적대적 검토에서 양의 지수 범위, 0 감마의 점과 무관한 역변환 거부, 좌표 검사 순서, 항등의 비정규수 보존, ReleaseFast의 strict 계산, 기존 mode159/160 wire 유지와 결과 메모리 경계를 확인했습니다. 제품 수치 정책은 curve_math를 공유하며 입력 생성과 probe 파싱도 기존 구현을 재사용합니다. 이번 범위에서 추가 결함은 발견하지 못했습니다. 포맷·변경 JS 문법·diff 공백·문서 로컬 링크 4개 검사도 통과했습니다. 근사 수치 계약 및 남은 파라메트릭/모델 연결 범위를 전체 문서 검증 완료와 혼동하지 않습니다.
