# 웹 인쇄 미리보기와 PDF

편집기에서 **파일 → 인쇄 미리보기**를 선택합니다. 미리보기에서 쪽을 넘겨 확인하고 PDF를 내려받거나 브라우저 인쇄 창을 열 수 있습니다. Vanilla·React·Svelte는 같은 Canvas 출력 경로를 사용합니다.

## 호스트 API

Canvas Surface의 `getPrintAvailability()`로 현재 화면에서 작업을 시작할 수 있는지 확인합니다. `openPrintPreview({ filename })`는 호스트 대화상자를 열고 준비 상태를 기다릴 `ready`와 닫기 함수 `close()`를 반환합니다. `capturePrintPages({ signal, scale })`는 쪽 순서와 용지 크기를 포함한 PNG 출력 작업을 반환합니다.

Core의 `captureDocumentOutput`는 입력 조합과 기존 변경의 처리를 마친 시점의 관측값을 잡습니다. 페이지 출력기는 그 관측값에 대해 기존 Canvas 조판 결과를 사용하며 각 쪽을 독립 크기로 그립니다. 출력 도중에 문서, 화면 조판 또는 표면이 바뀌면 작업을 중단합니다. 이미 열려 있는 미리보기의 PDF 내려받기와 인쇄도 실행 직전에 같은 문서인지 검사합니다.

## 출력 범위

내려받는 PDF는 쪽별 용지 크기를 갖는 이미지 PDF입니다. 미리보기 PDF는 약 192 DPI이며 텍스트 검색·선택과 벡터 PDF는 후속 범위입니다. 브라우저 인쇄에서는 해당 브라우저의 용지 치수 반올림과 사용자 설정이 적용될 수 있습니다.

출력은 쪽당 픽셀·전체 픽셀·인코딩 바이트에 각각 예산을 적용합니다. 대상 문서의 전체 페이지나 지원되는 조판을 확인할 수 없으면 미리보기에서 이유를 표시합니다. 페이지 출력은 대화상자 수명과 표면 수명에 묶입니다.
