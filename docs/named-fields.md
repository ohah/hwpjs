# 이름 있는 필드 조회·생성·수정

`editor.listNamedFields()`는 현재 문서 토큰에 묶인 필드 목록을 반환합니다. `readNamedField({ name, occurrence })`는 이름으로 값을 조회하고 `moveToNamedField({ name, occurrence })`는 위치를 확인한 필드로 선택을 옮깁니다. 이름은 원본 문자열과 정확히 일치해야 합니다. 같은 이름이 여러 개일 때 순번을 생략하면 모호한 결과를 반환합니다. 순번은 원본 순서의 0 기반입니다.

이름 없음, 명시적 빈 이름, 읽을 수 있는 빈 값, 읽을 수 없는 값을 구분합니다. 위치 이동은 기존 Core 선택 검증을 거치며 문서 이력을 바꾸지 않습니다. 부분 결과에서는 이름의 부재나 유일성을 확정할 수 없습니다.

HWP5는 단일 본문 문단의 검증된 누름틀·책갈피 이름과 위치를 지원합니다. HWPX는 원본 섹션에서 소유 관계를 확인한 필드를 지원합니다. 중첩·다문단·구조 변경으로 값 범위를 증명할 수 없는 필드는 이름을 보존하고 값과 이동 위치가 가용하지 않음을 표시합니다.

## HWPX 필드 값 바꾸기

`SET_NAMED_FIELD_VALUE_COMMAND`에 `selector`, `expectedValue`, `text`와 현재 관측의 `token`, `stateVersion`을 전달합니다. 관측의 `stateVersion`은 명령의 `selectionVersion`에 넣습니다. `canSetValue`가 있는 필드에서 명령을 시도할 수 있습니다. 실제 적용 전에는 현재 값, 전체 목록의 확인 범위, 보호 속성과 문서의 쓰기 정책을 다시 검사합니다.

명시적으로 편집 가능한 단일 본문 문단의 HWPX 누름틀에서 한 줄 평문을 설정하거나 빈 값으로 지울 수 있습니다. 이름이 중복되면 순번을 지정합니다. 성공하면 기존 이력에 한 번만 기록되며, 같은 값은 이력을 변경하지 않습니다.


## HWPX 필드 이름 바꾸기

`RENAME_NAMED_FIELD_COMMAND`에 현재 이름의 `selector`, `newName`, 현재 상태의 `token`과 `selectionVersion`을 전달합니다. 중복된 현재 이름은 0 기반 순번으로 지정합니다. 다른 필드에서 이미 사용하는 이름은 거부합니다. 현재 이름을 다시 지정하면 기존 이력과 다시 실행 상태가 유지됩니다.

문자열이 비어 있지 않은 이름을 가진 편집 가능 누름틀 중, 본문 한 문단에 속한 범위를 확인할 수 있는 필드를 바꿉니다. 목록이 부분적이거나 보호 속성이 있으면 거부합니다. 저장할 때 대상 시작 마커의 이름이 바뀌며 이전 값과 속성이 보존됩니다. 실행 취소와 다시 실행으로 이전 이름과 새 이름을 오갈 수 있습니다. HWP5, 중첩 누름틀과 참조 문자열 갱신은 지원 범위 밖입니다.


## HWPX 누름틀 만들기

`CREATE_NAMED_FIELD_COMMAND`는 현재 HWPX 본문의 한 텍스트 요소에 속한 선택을 누름틀로 감쌉니다. 캐럿 위치에서는 빈 누름틀을 만들 수 있습니다. 이름, 입력 지시문, 설명을 지정하며 현재 선택과 문자열을 명령 실행 시 다시 확인합니다. 구체적인 생성 범위와 저장 속성은 [필드 마커 생성 계약](hwpx-field-markers.md#본문-누름틀-생성)을 따릅니다.

공개 플레이그라운드 후보에서 한글·이모지 선택과 실제 Canvas 키보드 선택으로 생성하고, 빈 누름틀에 값을 넣어 저장·재열기했습니다. 독립 ZIP/XML 검사에서 대상 밖 섹션과 나머지 ZIP 항목 6개의 보존, 생성·값 변경의 실행 취소/다시 실행 11쌍의 바이트 일치, 안내문·설명 문자열의 UTF-16 길이를 확인했습니다. 중복 이름·보호 구간·읽기 전용 문서·부분 목록의 거부도 문서 불변으로 확인했습니다. 이 검증은 HWPX 본문의 위 생성 범위에 한하며, HWP5 생성이나 임의 중첩 필드 지원을 뜻하지 않습니다.

## HWPX 안내문과 도움말

`readNamedFieldParameters`는 안내문 `direction`과 도움말 `memo`를 조회합니다. 부재는 `null`, 명시적 빈 값은 빈 문자열입니다. `SET_NAMED_FIELD_PARAMETERS_COMMAND`는 현재 관측의 token·selectionVersion·기대값을 검사해 두 문자열을 함께 수정합니다. 보호 문서는 읽기와 쓰기 가용성을 구분합니다. Command·Direction·HelpState의 저장 규칙은 [필드 마커 계약](hwpx-field-markers.md)을 따릅니다.

원본 문단 순서·귀속이 유지되는 문단 서식 변경이 앞서 있을 때에는 현재 구역 값을 임시 원본에 반영하고 필드 ID를 다시 확인한 뒤 속성을 바꿉니다. 완성된 구역만 기존 세션에 설치하며 머리표 등 헤더 리소스의 저장 의도는 기존 모델에 남습니다. 글머리표와 속성 수정의 독립 실행 취소·다시 실행, 저장·재열기와 새 경로의 할당 실패 434곳에서 원본·redo 보존을 확인했습니다. 문단 합치기·나누기·생성, 보호/제어 이동 등 일반 구조 변경을 허용하는 계약은 아닙니다.
