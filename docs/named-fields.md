# 이름 있는 필드 조회와 이동

`editor.listNamedFields()`는 현재 문서 토큰에 묶인 필드 목록을 반환합니다. `readNamedField({ name, occurrence })`는 이름으로 값을 조회하고 `moveToNamedField({ name, occurrence })`는 위치를 확인한 필드로 선택을 옮깁니다. 이름은 원본 문자열과 정확히 일치해야 합니다. 같은 이름이 여러 개일 때 순번을 생략하면 모호한 결과를 반환합니다. 순번은 원본 순서의 0 기반입니다.

이름 없음, 명시적 빈 이름, 읽을 수 있는 빈 값, 읽을 수 없는 값을 구분합니다. 위치 이동은 기존 Core 선택 검증을 거치며 문서 이력을 바꾸지 않습니다. 부분 결과에서는 이름의 부재나 유일성을 확정할 수 없습니다.

HWP5는 단일 본문 문단의 검증된 누름틀·책갈피 이름과 위치를 지원합니다. HWPX는 원본 섹션에서 소유 관계를 확인한 필드를 지원합니다. 중첩·다문단·구조 변경으로 값 범위를 증명할 수 없는 필드는 이름을 보존하고 값과 이동 위치가 가용하지 않음을 표시합니다. 필드 쓰기·생성·이름 변경은 후속 기능입니다.
