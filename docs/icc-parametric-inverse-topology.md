# 파라메트릭 역변환: 분기·클리핑·열린 끝점 조사

## 조사 결론

단조성 구현 전에 실제 곡선의 분기 경계를 조사했습니다. 전체 실수 정의역 검사를 통과하더라도 내부 방향 전환, 클리핑된 상수 곡선, 하향 점프가 있을 수 있습니다. 또한 비상수 단조 곡선이라도 열린 구간 때문에 특정 역상 선택에 최대값이나 최근접값이 존재하지 않을 수 있습니다. 이 문서는 다음 구현의 요구조건과 반례를 소유하며 **단조성 검사기나 역함수 구현 완료를 뜻하지 않습니다.**

기준은 [ICC.1:2022 §10.18 Table 68·Annex F.1](https://www.color.org/specifications/ICC.1-2022-05.pdf)입니다. Table 68의 하위 분기는 x<d, 상위 분기는 x>=d이므로 아래쪽 구간의 끝점은 열려 있습니다. Annex F.1의 평탄 구간에서 가장 큰/작은 x 선택과 범위 밖 y의 최근접 선택을 구현할 때 실제 값의 존재 여부를 확인해야 합니다. 아래 ‘존재하지 않음’은 수식으로부터 도출한 수학적 분석이며, 명세에 같은 이름의 오류가 정의되어 있다는 주장이 아닙니다.

## 정확한 합성 반례

모두 type4이며 원시 파라미터 순서는 [g,a,b,c,d,e,f]입니다. 모든 사례는 현재 전체 정의역 검사를 통과합니다.

| 사례 | 원시 파라미터 | 필요한 구분 |
|---|---|---|
| 내부 방향 전환 | [131072,131072,-65536,0,0,0,0] | (2x−1)^2는 끝점이 같지만 상수가 아니며 비단조 |
| 위쪽 클리핑 | [131072,131072,-65536,0,0,65536,0] | 원래 식은 방향이 바뀌지만 최종 곡선은 항상 1 |
| 아래쪽 클리핑 | [131072,131072,-65536,0,0,-65536,0] | 최종 곡선은 항상 0 |
| 하향 점프 | [65536,65536,0,131072,32768,0,0] | x<1/2에서 2x, 이후 x. 두 분기 모두 증가하지만 전체는 비단조 |
| 열린 평탄 구간 | [65536,0,0,0,32768,65536,0] | x<1/2에서 0, 이후 1. y=0의 역상에 가장 큰 x가 없음 |
| 열린 값 범위 | [65536,0,0,65536,32768,65536,0] | x<1/2에서 x, 이후 1. y=3/5에 최근접 출력이 없음 |

열린 평탄 구간에서 임의의 역상 x<1/2에 대해 x'=(x+1/2)/2도 역상이고 x'>x입니다. 따라서 최대 역상이 없습니다. 상한 1/2을 반환하면 실제 함수값이 1이므로 원래 y=0과 다릅니다. 가장 큰 f64 입력을 반환하는 것은 실수 정의역을 f64 격자로 바꾸는 별도 정책이지 동일한 계약이 아닙니다.

열린 값 범위는 [0,1/2)∪{1}입니다. y=3/5에서 x=1/4의 출력은 1보다 더 가깝고, 임의의 x<1/2보다 위 x'의 출력이 더 가깝습니다. 거리의 하한은 1/10이지만 이를 달성하는 출력 1/2은 범위에 없습니다. 최근접 선택을 ‘하한에 접근하는 값’으로 몰래 대체하면 안 됩니다.

## 시스템 프로파일 경계 실측

2026-09-08 시스템 파일을 읽기 전용으로 조사했습니다. 아래 네 프로파일의 헤더 버전 원값은 모두 04000000입니다. **ICC.1:2022 수식으로 원시 계수를 해석한 결과**이며 macOS 색상 엔진의 실제 정책이나 모든 v4 판본의 유효성 판정이 아닙니다. 각 프로파일의 r/g/bTRC가 같은 계수를 가져 태그 12개·고유 계수 4종을 확인했습니다.

| 프로파일 | type3 raw [g,a,b,c,d] | clip(상위 분기 d 값) − clip(하위 분기 d 극한) |
|---|---|---|
| Display P3 | [157286,62119,3417,5072,2651] | +8.492809088738593e−7 |
| ITU-2020 | [145636,59616,5920,14564,5308] | +2.734386123070731e−7 |
| ITU-709 | [145636,59632,5904,14564,5308] | −5.439968220691808e−5 |
| ROMM RGB | [117965,65536,0,4096,128] | −1.087870179742783e−4 |

Python 표준 Decimal의 정밀도 120자리에서 원시 고정소수점 계수를 변환하고 상위 거듭제곱은 exp(g×ln(a×d+b)), 하위 극한은 c×d로 계산했습니다. 각 결과에 명세의 [0,1] 제한을 적용했습니다. 모든 해당 d는 [0,1] 내부입니다. 음수 점프 두 종류는 실제 WASM에서 d 바로 아래 f64와 d를 입력해서도 확인했습니다. 고정 허용 오차로 이 차이를 없애거나 연속으로 보정하지 않습니다. 프로파일 전체가 손상됐다고 판정하거나 OS가 같은 방식으로 거부한다고 추론하지 않습니다.

## 다음 구현의 필수 조건

분기 경계의 반올림 없는 수치 비교 기반은 [유리수 거듭제곱 비교](icc-rational-power-order.md), 좌극한·상위 실제 값의 클리핑 후 순서는 [경계 점프](icc-parametric-jump.md), 전체 방향 합성은 [단조성·상수성 판정](icc-parametric-trend.md)에서 관리합니다. 역상 선택이나 역변환 완료를 의미하지 않습니다.

원본 두 분기의 열린 끝점 보존은 [분기 구간 모델](icc-parametric-segments.md)에서 구현·검증합니다. 아래의 추가 분할·전체 단조성·역상 조건과 구분합니다.

1. 기존 parametric_domain의 전체 정의역 검사와 powerDomain의 정확한 분기점을 재사용합니다. 분할 구간에 시작/끝 포함 여부를 둡니다.
2. 밑의 영점·거듭제곱 방향·선형 기울기·클리핑 경계를 반영합니다. 클리핑 전 방향 전환만으로 최종 곡선을 비단조라고 판정하지 않습니다.
3. 각 구간 방향뿐 아니라 분기점의 좌극한과 실제 값을 비교합니다. f64 값이 같거나 가깝다는 이유로 정확한 연속성·상수성을 선언하지 않습니다. 비교가 확정되지 않은 상태를 유효성 성공으로 처리하지 않습니다.
4. 비단조·상수·정의 불가를 구분하고, 비상수 단조 곡선에서도 해당 y의 역상/최근접값이 달성되는지 확인합니다. 없는 최대값·최근접값은 명시적인 실패로 표현해야 하며 임의 보정으로 숨기지 않습니다. 동률 선택이 명세로 결정되지 않는 경우도 별도 정책 검토 대상입니다.
5. 엄격한 수학적 역변환과 특정 엔진의 근사/호환 정책을 분리합니다. 실제 프로파일의 경계 불연속을 삭제하거나 입력 계수를 수정하지 않습니다.

구간 표현·경계 점프·전체 방향 판정의 현재 구현 범위는 위 연결 문서가 소유합니다. 달성 가능한 역상 선택·역함수·TRC/행렬 연결은 아직 구현할 작업입니다. 위 요구조건은 목표를 줄이기 위한 지원 제한이 아니라 잘못된 성공 판정을 방지하기 위한 구현 기준입니다.

## 회귀 검사

tests/hwp5/icc-parametric-topology.mjs를 정규 audit에 연결했습니다. 합성 사례 6개와 실측 계수 사례 4개에서 정의역 통과 10건·점 계산 비교 44건을 수행합니다. 합성 기대값은 정확한 이진수, 실측 점프는 위 Decimal 기준과 1e−12 차이 이내인지 확인합니다. 이 테스트는 아직 없는 단조성 검사기를 통과시킨 것이 아니라 그 검사기가 처리해야 할 반례를 현재 파서·점 계산기에서 고정한 것입니다.

Debug 전체 감사 `/tmp/hwpjs-icc-parametric-topology-Debug.log`는 종료 코드 0, 20/20 단계·네이티브 485/485·WASM 5,693,484건으로 통과했습니다. 신규 cases=10, comparisons=44, domains=10도 확인했습니다. 제품 Zig 코드는 이번 조사에서 변경하지 않았습니다. 나머지 모드는 완료 후 기록합니다.
