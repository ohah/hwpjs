# HWPX `hp:t/hp:tab` 속성 진단

`src/hwpx/tab_attributes.zig`는 [text 노드 검사](hwpx-text-nodes.md)가 2011 namespace의 `hp:t` 직접 자식으로 선택한 `hp:tab`의 `width`·`leader`·`type`만 판정합니다. 세 속성의 부재와 원값 형식을 보존하며 탭을 표시 문자나 실제 간격으로 변환하지 않습니다. `width`는 공통 XML `nonNegativeInteger` 어휘를 검사하고, 32비트 범위 초과는 진단으로 남깁니다. 세 속성의 정규화 UTF-8 길이에는 `TextNodeOptions.max_attribute_bytes`, 탭 개수에는 `max_tabs`를 적용합니다. 알려지지 않은 다른 속성·namespace 속성도 개수로 남깁니다.

[참고 2011 ParaList XSD 사본](https://github.com/edwardkim/rhwp/blob/main/mydocs/manual/OWPML%20SCHEMA/ParaList%20XML%20schema.xml)은 `type`에 `LEFT`·`RIGHT`·`CENTER`·`DECIMAL`을 필수로, `leader`에 [Core XSD의 `LineType2`](https://github.com/edwardkim/rhwp/blob/main/mydocs/manual/OWPML%20SCHEMA/Core%20XML%20schema.xml) 이름을 선택적으로 규정합니다. 반면 [한컴 `CTab` 구현](https://github.com/hancom-io/hwpx-owpml-model/blob/1453388472c703a4b299a0834f425cdac16644b9/OWPML/Class/Para/tab.cpp)은 세 값을 `UINT`로 읽고 쓰며, [한컴 `LineType2` enum](https://github.com/hancom-io/hwpx-owpml-model/blob/1453388472c703a4b299a0834f425cdac16644b9/OWPML/Class/enumdef.h)은 XSD 이름 12개 외에 6개를 더 둡니다. 검사기는 숫자형·XSD 이름형·모델 확장 이름형·미인식형을 따로 세고 **이름과 숫자의 대응 관계를 추측하지 않습니다.** `type` 누락도 관측값이지 이 단계의 즉시 거부 오류가 아닙니다. `type`의 4 초과와 `leader`의 모델 enum 17 초과 숫자도 진단이며, 이를 모든 버전의 유효 범위로 단정하지 않습니다.

독립 Python ZIP/ElementTree oracle(`tools/hwpx-manifest-xml-oracle.py`)의 로컬 HWPX 476개 수용 문서에서 section 직접 `hp:tab`은 7,582개, 선택 마스터페이지는 0개였습니다. section의 세 속성은 모두 명시적 숫자형이며 `width` 합계 42,342,698, `type` 원값 합계 6,687, `leader` 원값 합계 2,340입니다. 별도의 원값 분포 조사에서는 `type="4"`도 36개 관측되어 XSD의 네 문자열만 강제하면 이 corpus를 거부함을 확인했습니다. 누락·0 너비·32비트 초과·추가 속성·미인식 값은 관측되지 않았고, 해당 분기는 합성 테스트로 검사합니다. 이 집계는 2011 입력의 관측 사실일 뿐 서식의 화면상 간격이나 버전별 기본값을 증명하지 않습니다.

보고서는 section `XmlTrees.inspectTextNodes`와 마스터페이지 `Document.inspectMasterPageTextNodes`의 `tab` 필드에 포함되고, `inspectKnown`에도 같은 필드로 노출됩니다. 원문 바이트는 상위 XML 트리가 소유하고 보고서는 개수·합계만 소유합니다. 탭의 자식 콘텐츠, 줄 배치, `type` 숫자의 의미, 다른 인라인 요소의 속성, 편집·저장은 후속입니다.

2026-09-24 검증: 독립 oracle의 `section_tab_fields`·`master_tab_fields` 21개 지표를 선택 실파일 8개 shard의 Zig 보고서와 대조해 모두 일치했습니다. 합성 테스트에서는 숫자형·이름형·모델 확장명·미인식값, 누락·0·32비트 초과·잘못된 너비, 타 namespace·중첩 탭, 두 마스터페이지에 걸친 `max_tabs` 한도와 할당 실패를 확인했습니다. XSD의 네 `type` 이름과 모델의 18 `leader` 이름도 각각 전수 분류 테스트에 넣었습니다. 전체 Debug 테스트 2,252개, ReleaseSafe 제품 빌드, 전체 audit 40단계·2,291개 테스트, 전용 ReleaseSafe·ReleaseFast 테스트가 통과했습니다. 이 결과는 인라인 탭 속성 진단 범위의 근거이며 모든 HWPX 파일의 XSD 적합성이나 탭 렌더링 동치 증명이 아닙니다.
