# 통합 후보의 Native 전체 검사

2026-11-12의 `source-split-named-main-integration-r1` R3는 Git `4c2f746b` 위의 격리 후보 검사다. 현재 Git 작업 트리, 공개 데모, 다른 후보의 검증 결과로 바꾸어 읽지 않는다. 특히 Root에 남은 셀 수직 정렬 WIP와 후속 그림 셀 나누기 수정은 이 실행에 포함하지 않았다.

`zig build test -Doptimize=ReleaseSafe -j1 --summary all`은 종료 코드 1이었다. 전체 5,680개 중 5,482개 통과·44개 건너뜀·154개 실패이며, root 실행은 5,316개 중 5,118개 통과·44개 건너뜀·154개 실패다. 검사 전후 Native 입력 3,636파일의 SHA가 같았다. 따라서 최신 후보의 전체 Native 검사는 아직 통과하지 않았다.

이전 R2의 실패 이름 228개와 대조하면 현재 실패 이름 154개는 모두 이전 목록에 있다. 이름이 사라진 74개를 제품 버그 수정 수로 계산하지 않는다. 정확한 입력 파일 확보, 잘못된 검사기 호출과 기대값의 수정, 실제 제품 수정이 섞여 있으며, 같은 이름의 실패가 같은 원인이라는 보장도 없다. 남은 실패는 원래 입력과 검증 조건을 보존한 채 개별 재현으로 분류한다. 파일 부재를 손상 문서나 파서 결함으로 처리하거나, 실패를 없애기 위해 원래 테스트를 건너뛰지 않는다.

후속 소스·입력 조사에서는 143개 실패 테스트의 선택한 코드·로컬 helper가 참조하는 fixture 경로가 후보에 없었다. 고유 누락 경로는 66개이며, 그중 64개는 Root에 파일이 존재한다는 사실만 확인했다. 별도 6개 corpus 검사는 입력 파일명 집합이 불완전했다. 원본이 있는 예산 계약 2개, 원본이 있는 OOM/제품 동작 미확정 검사 2개, 합성 OOM 검사 1개는 추가 제어 검사가 필요하다. 이 분류는 실제 실패 당시의 오류 값을 수집한 결과가 아니므로, 149개를 환경 문제로 확정하거나 나머지 5개를 제품 버그 수로 읽지 않는다. Main은 154개 테스트 이름·소스 SHA·R3 입력 ledger와 현재 파일 존재 여부를 독립 대조했다. 원자료는 `native-r3-failure-source-triage-r1`과 `native-r3-triage-main-r1`에 보존한다.

동일 소스의 별도 제품 검사에서는 ReleaseSmall WASM `4a84a747a60335708ffa48403fbab991a4a4607ec733f2047811994b252d6395`의 CLI·MCP 정규 검사 818개와 Worker 회귀 45개가 통과했다. ReleaseSafe 제품 빌드도 통과했다. 이 결과는 전체 Native 검사의 실패를 상쇄하지 않으며, 서로 겹치는 검사를 고유 테스트 수로 합산하지 않는다.

실제 누리 다섯 번째 표의 최신 웹 후보는 HWPX에서 Vanilla·React·Svelte의 행 편집·입력·이력·저장·재열기를 통과했다. HWP5의 최초 세 검사는 전체 흐름을 마치지 못했으나, 동기화와 관측을 보완한 무계측 후속 세 조합은 끝 행 삽입·삭제·입력·이력·저장·재열기를 통과했다. 최초 실패는 지우지 않았으며, 별도 계측 재현에서는 다른 viewport의 PNG에서 산출한 좌표가 현재 geometry를 벗어난 것을 확인했다. 최초의 모든 실패를 같은 원인이라고 소급 확정하거나 제품 코드 수정으로 분류하지 않는다. 저장 파일의 SDK 관측과 실제 Canvas 검증은 별도이며, 이 후보는 아직 공개 데모에 배포하지 않았다.

원자료는 검증 폴더의 `NATIVE-ALL-EXIT-r3.json`, `FULL-NATIVE-FAILED-NAMES-r3.json`, `FULL-NATIVE-COMPARISON-r2-r3.json`, `SOURCE-PINS-current-r14.json`, `VERIFICATION.json`에 남긴다. 실행·입력 SHA와 실제 실패 목록이 결론의 근거다. 후속 소스나 다른 바이너리의 성공을 이 실행에 소급하지 않는다.

현재 소스에는 이 전체 검사와 WASM `4a84` 생성 이후의 그림 포함 표 셀 나누기·공개 오류 변환 수정이 들어 있다. 그 수정의 최신 Main Native·SDK·Canvas 검사는 아직 실행하지 않았다. 따라서 보존한 `4a84` 바이너리의 성공 결과를 현재 소스 전체의 검증으로 적용하지 않는다. 실행 여건이 충족되면 해당 변경의 집중 검사와 실제 WASM 검사를 먼저 수행한다.
