# HWPX 표 행·셀 직접 자식 topology

`src/hwpx/table_child_topology.zig`는 [표 격자 검사](hwpx-table-geometry.md)가 이미 선택한 직접 `hp:tr`과 `hp:tc`에서 공개 모델에 없는 직접 자식·속성을 진단합니다. 행의 알려진 직접 자식은 `hp:tc`, 셀은 `cellAddr`, `cellSpan`, `cellSz`, `cellMargin`, `subList`입니다. 이 다섯 이름은 `table_xml_fields.cell_child_names`를 주소·크기·목록 검사와 공유합니다. 행/셀 속성의 알려진 목록은 기존 셀 필드 모듈이 소유하고, 이 검사는 나머지 속성의 개수만 셉니다. 네임스페이스 선언은 속성으로 세지 않습니다. 부재·중복·필드 원값·격자 점유는 기존 검사기의 책임을 유지합니다.

보고서는 행·셀 수, 알 수 없는 직접 자식과 그중 다른 namespace 자식, 미등록 속성, 셀의 알려진 직접 자식 전체 수를 구분합니다. 알려진 자식들 가운데 첫 요소가 `subList`인지, 마지막 요소가 `cellAddr`인지와, 전체 알려진 자식 순서가 실파일에서 관측한 두 패턴 중 어느 쪽인지도 별도로 셉니다. 같은 첫/마지막 요소라도 가운데 순서가 다르면 `other_known_sequence`입니다. 이 지표는 일부 자식의 부재·중복도 포함하므로 그 자체로 오류 종류를 뜻하지 않습니다. 다른 요소 사이에 끼어 있어도 **알려진 자식의 순서**만 비교합니다. 중첩 `tc`·`subList`나 다른 namespace의 동명 요소를 직접 자식으로 오인하지 않습니다. 순서·부재·추가 요소는 현재 진단이지 문서 거부 조건이 아닙니다. 문자 데이터, 주석, PI와 셀 내부 문단 의미는 이 보고서의 대상이 아닙니다.

근거는 한컴 공개 모델 고정 커밋의 [`tr.cpp`](https://github.com/hancom-io/hwpx-owpml-model/blob/1453388472c703a4b299a0834f425cdac16644b9/OWPML/Class/Para/tr.cpp)와 [`tc.cpp`](https://github.com/hancom-io/hwpx-owpml-model/blob/1453388472c703a4b299a0834f425cdac16644b9/OWPML/Class/Para/tc.cpp)입니다. 이 모델의 자식 등록 순서를 XSD상 필수 직렬화 순서로 가정하지 않습니다. 독립 ZIP/ElementTree 조사에서 2026-09-25 로컬 허용 HWPX 476개 문서의 23,708개 행·106,998개 셀은 미등록 행/셀 속성·직접 요소가 0개였습니다. 모든 셀의 알려진 직접 자식 첫 요소는 `subList`였고, 106,939개는 `subList/cellAddr/cellSpan/cellSz/cellMargin`, 나머지 59개는 `subList/cellSpan/cellSz/cellMargin/cellAddr` 순서였습니다. 뒤의 59개는 `reference/rhwp/samples/hwpx/issue2019_floating_form_74312.hwpx`의 셀 전부이며 그 파일의 `version.xml`은 5.0.0.0, `appVersion`은 `9, 1, 0, 2172 (RC)WIN32LEWindows_7`입니다. 한 파일의 순서 차이를 버전 규칙으로 일반화할 수 없습니다. 두 순서 모두 원문 그대로 진단하며 어느 쪽도 자동 수정·거부하지 않습니다. 이는 해당 표본 분포이지 다른 버전의 허용 순서나 필수 자식 규칙의 증명은 아닙니다.

합성 반례는 외부 namespace·손자 `tc`, 두 형태의 알려진 자식 순서, 미등록 속성, 부재·중복, 공유 행/셀 한도, 모든 할당 실패를 검사합니다. `python3 tools/hwpx-table-oracle.py --self-test`는 독립 조사기의 반례이고, 인자 없는 실행은 실파일 집계입니다. `zig test src/root.zig --test-filter 'HWPX table child topology'`는 합성 검사를, `zig test src/hwpx_known_survey.zig -O ReleaseFast --test-filter 'HWPX known document inspections shard N'`의 N=0..7은 독립 shard별 행·셀·자식 수와 두 순서 지표를 대조합니다. 선택 실파일 검사는 Git에 없는 로컬 `reference/rhwp`가 필요합니다. 표/셀의 전체 XSD, 내용 모델·레이아웃·편집·저장·무손실 왕복은 아직 미구현입니다.

2026-09-25 최종 검증: Debug 전체 `zig build test --summary all` 2,319/2,319, ReleaseSafe·ReleaseFast `zig build audit -Doptimize=… --summary all` 종료 코드 0, 위 실파일 shard 0~7 모두 통과했습니다. 독립 조사기는 476개 문서·4,182개 표·23,708개 행·106,998개 셀에서 미등록 행/셀 직접 자식·속성 0개, 정확한 두 순서 106,939/59개, 그 외 순서 0개를 다시 확인했습니다. 적대적 재검토에서 선두/후미만 비교하면 가운데 두 자식의 교환을 놓친다는 반례가 발견돼 전체 알려진 자식 순서를 비교하도록 수정했고, 해당 반례는 Zig·독립 조사기 양쪽의 테스트에 남겼습니다. 이 검증은 선택 corpus와 현재 보고서 필드에 한정되며 전체 HWPX 문서 적합성 증명은 아닙니다.

2026-09-27 현재 내용 재검증: 고정 버전 모델·공유 셀 자식 이름·현재 전체 순서 판정 코드를 대조하고 독립 조사기 자체 반례 및 허용 476개 실파일 집계를 실행했습니다. 행 23,708개·셀 106,998개에서 미등록 직접 자식·속성은 0개, 알려진 직접 자식 총수는 534,990개이고 순서는 정확히 106,939/59개로 갈렸습니다. 차이 파일의 59개 셀 모두 첫 자식은 `subList`, 마지막 자식은 `cellAddr`임을 원본 XML XPath로 별도 확인했습니다. 집중 테스트는 Debug·ReleaseSafe·ReleaseFast 각 6개 통과했습니다. 이전 known-inspections 8개 shard는 제품 코드 불변을 확인해 재사용했으며 이 날짜에 재실행한 것으로 세지 않습니다.
