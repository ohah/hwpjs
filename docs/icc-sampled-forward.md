# ICC 샘플 곡선 순방향 보간

## 계약과 책임

[ICC.1:2022 §10.6](https://www.color.org/specifications/ICC.1-2022-05.pdf)의 균일한 입력 간격과 선형 보간을 `sampled_forward.evaluate`에 구현했습니다. 정규화된 분수를 입력받아 정규화된 정확한 분수를 반환합니다. u16 질의만 받는 함수가 아니므로 기존 샘플 역변환 결과를 양자화 없이 직접 전달할 수 있습니다.

Fraction은 `fraction.zig`, 샘플 배열의 유효 개수 검사는 `curve_type.Samples.checkedCount`가 소유하며 순방향과 역방향이 공유합니다. 기존 sampled_inverse.Fraction 별칭과 오류 이름은 유지합니다. 파싱·보간·역변환의 책임을 합치지 않습니다.

입력 분모는 0보다 크고 분자는 분모 이하여야 합니다. 정확한 출력 분수를 u64로 표현하기 위해 분모 상한은 floor(u64최대/65535)로 명시합니다. 기존 역변환의 모든 결과 분모는 이 상한 이내입니다. 상한을 넘으면 반올림하거나 잘라내지 않고 IccFractionLimitExceeded로 거부합니다. 샘플 구간 위치 계산만 u128을 사용하고 가중합과 출력 분모는 검증된 u64 범위 안에 있습니다.

끝점 x=1은 마지막 샘플을 직접 반환하며 배열 끝을 넘지 않습니다. 샘플 두 개만 조회하므로 시간·추가 공간은 O(1)이고 할당하지 않습니다. 상수·비단조 곡선도 순방향 평가는 가능하므로 역변환의 단조성 제약을 적용하지 않습니다. 원본 입력을 변경하거나 결과에 포인터를 남기지 않습니다.

이 API는 샘플 곡선만 다룹니다. identity/gamma/para 평가, 전체 TRC 모델, 행렬·PCS 변환과 필수 태그 검증은 아직 남아 있습니다. 분모 상한 때문에 임의 정밀도의 모든 유리수를 지원한다고 주장하지 않습니다.

## 검증

2026-09-07 포맷 검사와 `zig build test --summary all`이 5/5 단계, 네이티브 438/438로 통과했습니다. 기존 역변환 테스트도 공통 경계 검사 추출 후 통과했습니다.

네이티브 테스트는 증가·감소·평탄 곡선의 역변환 결과를 순방향에 넣어 원래 y(범위 밖에서는 가장 가까운 y)를 정확히 재현하는지 u128 교차 곱으로 대조합니다. 상수·비단조 곡선, 분모 상한·0·범위 밖 분자, 빈/홀수 바이트 샘플을 검사합니다.

테스트 mode 158은 u64 BE 분자·분모와 curv payload를 받아 u64 LE 결과 분수를 반환합니다. 독립 JS 기준은 유리수 비교로 구간을 찾고 기울기 형태의 식을 BigInt로 계산합니다. 작은 배열 전수 조합, 최대 분모, 65,538개 샘플의 64비트 초과 중간 위치, 잘림·한도·복구를 검사했습니다. 신규 Debug WASM에서 비교 7,689건·오류 거부 39건·역변환 왕복 40건이 통과했습니다.

macOS 기본 Generic Gray Gamma 2.2 Profile과 sRGB Profile의 샘플 curv 태그 4개에 대해 분수 입력 7개씩, 총 28건이 독립 기준과 일치했습니다. 파일을 수정·복제하지 않았고 공유 데이터는 태그별로 셌습니다. 수동 결과는 자동 감사 수에 합산하지 않으며 전체 색상 변환 대조가 아닙니다.

최종 적대적 검토에서 공식 §10.6의 입력 간격 1/(n−1), 출력 인코딩 0–65535, 선형 보간을 구현과 재대조했습니다. 독립 BigInt 계산으로 최대 입력 분모 281479271743489, 최대 출력 분모 18446744073709551615, 최대 중간 위치 1208944266077223612448766을 확인했습니다. 역변환 최대 분모 281470681612290도 입력 상한 이내입니다. 가중합은 두 가중치의 합이 입력 분모이므로 u64 최대를 넘지 않고, 위치 계산은 u128 이내입니다. 역변환 문서에 남은 순방향 미구현 문구도 바로잡았습니다.

Debug·ReleaseSafe·ReleaseFast 전체 감사가 각각 20/20 단계, 네이티브 438/438, HWP5 감사 검사 4,563,217건으로 통과했습니다. 각 모드에서 신규 비교 7,689건·오류 거부 39건·왕복 40건도 통과했습니다. 로그는 `/tmp/hwpjs-icc-forward-{Debug,ReleaseSafe,ReleaseFast}-final.log`입니다. 검사 수는 명세 지원율이나 전체 색상 변환 정확도를 뜻하지 않습니다.
