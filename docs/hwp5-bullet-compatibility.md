# HWP5 빈 이미지 글머리표 배치

`docinfo/bullet.zig`는 기존 14바이트 기본형·23바이트 이미지 그룹·25바이트 체크 문자 배치를 유지합니다. 별도로 정확히 24바이트이고 이미지 identifier와 뒤의 네 이미지 속성 바이트가 모두 0인 레코드는 4바이트 빈 이미지 속성 뒤의 완전한 WCHAR를 읽습니다. 이미지가 활성화되거나 속성이 0이 아닌 24바이트 입력을 이 배치로 추정하지 않습니다. 기존 16비트 BinData ID와 미지 꼬리 해석은 변경하지 않습니다.

로컬 명세 표42는 이미지 속성을 4바이트로 기술하지만 문단 머리 정보 길이도 실제 자료와 차이가 있으므로 표 전체 크기만으로 모든 배치를 결정하지 않습니다. RHWP의 현재 글머리표 writer도 이미지 속성 4바이트와 체크 WCHAR를 기록합니다. 실제 `issue4514/sample1-repro.hwp`의 24바이트 글머리표 3개는 모두 빈 이미지이며 문자는 U+25A1/U+002D/U+203B입니다. 기존 파서는 5바이트 이미지 속성 뒤에 체크 문자를 읽다가 UnexpectedEnd로 중단됐습니다.

이 선택은 레코드 길이와 관측 값으로 알려진 배치를 구분하는 호환 해석입니다. 의도적으로 잘린 full-width 레코드가 같은 24바이트 값을 만들었는지 원본만으로 판별할 수 있다는 주장이 아닙니다. 비어 있지 않은 compact 이미지·추가 꼬리가 있는 compact 레코드의 배치는 이번 변경으로 추정하지 않습니다. 원본 바이트를 재작성하거나 CFB 보정 동의를 자동으로 부여하지 않습니다.

검증은 별도 `bullet_fixture_tests.zig`의 독립 원문 문자·체크 값·입력 불변 검사와 기존 이미지 그룹 절단/16비트 ID/미지 꼬리 반례를 함께 실행합니다. 합성 검사는 compact 체크 문자 U+2713을 확인하고 이미지 영역의 8개 바이트를 하나씩 바꾼 24바이트 입력을 거부합니다. 실파일이 없는 환경의 fixture 검사는 명시적으로 skip하며 완료 증거로 세지 않습니다.

2026-10-18 작업 트리의 명시적 CFB 보정 편집 조사에서는 기존 제외 73경로 중 68개에서 원값·전체 스트림 보존, 66개에서 첫 문단 prefix 입력·저장·재열기·undo/redo를 확인했습니다. 입력 거부 2개, 사용자 제외 1개, 오류 4개는 성공에 포함하지 않았습니다. 위 글머리표 오류 1개를 추적한 결과이며 구역 수 선언/실제 불일치 3개를 자동 보정하지 않습니다. 이 편집 조사의 normalized API는 기존 미커밋 작업 트리에 있으므로 main 전체 편집 지원 증거로 읽지 않습니다.

## 수정 후 검증

실제 글머리표·기존 이미지·새 경계 검사는 작업 트리 Debug/ReleaseSafe 각각 6/6, 게시 변경만 분리한 main 기반 사본 ReleaseSafe 6/6으로 skip/실패 없이 통과했습니다. 분리 사본 ReleaseSafe 제품 빌드와 관련 API 19/19도 종료 0입니다. 해당 WASM SHA256은 `b4a749c6f56a79c942c6a177743896fa32df7f8453c16006079fe4657767f6e5`이며 기본 데모는 변경하지 않았습니다.

격리 사본에서 5개 변이를 각각 실행해 지원 분기 제거(실제 파일 UnexpectedEnd), 24바이트 무조건 허용(잘린 이미지 수용), 체크 문자 0 덮어쓰기, compact 오프셋 1바이트 이동, 기존 16비트 ID의 8비트 축소를 모두 검출했습니다. 실패는 기대한 검사 단언에서 발생했으며 컴파일 실패를 변이 검출로 세지 않았습니다. 변이는 모두 원복했습니다.

작업 트리 새 후보 `35f04c5ac8e52f9b40669df0b658751f4b67cac5fb9af293469e40987077043a`로 같은 73경로를 재검사해 원값/전체 스트림 보존 69개, 첫 문단 prefix 입력/저장/재열기/undo/redo 67개를 확인했습니다. 실제 sample1-repro가 새 성공 1개입니다. 기존 구역 컨트롤 입력 거부 2개·사용자 제외 1개·구역 수 불일치 오류 3개는 유지했습니다. 구역 수 선언/실제는 issue5715 2/1, issue5802 11/2, issue5828 4/1이며 RHWP는 실제 연속 스트림을 세지만 현재 strict 정책을 임의로 대체하지 않았습니다. 이는 해당 위치의 편집 증거이며 모든 위치·서식·UI·원본 조판 동치가 아닙니다.

앞서 실행 중인 전체 native 4,318개는 이 수정 이전 바이너리입니다. 새 focused 결과를 그 전체 실행의 통과로 소급하지 않습니다.
