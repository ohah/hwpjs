# 캐럿 문단의 글머리표 조회

`CanvasSurface.getHeadingString()`은 Canvas에 배치된 현재 캐럿 문단의 글머리표를 읽습니다. HWP5에서는 문단 모양과 DocInfo의 글머리표 참조를 확인합니다. HWPX에서는 문단 모양과 헤더의 글머리표 ID를 확인합니다. 상태와 문서 이력은 변경되지 않습니다.

문자 글머리표가 확인되면 원본 문자와 출처를 반환합니다. 글머리표가 없다는 원본 정보가 있으면 빈 문자열을 반환합니다. 이미지·체크 글머리표, 불명확한 참조, 범위 선택, 현재 문단을 확인할 수 없는 경우에는 이유가 있는 조회 불가 결과를 반환합니다.

## 문단 번호와 개요 번호

원본 번호 정의, 시작값, 수준과 본문 순서가 확인되면 현재 번호 문자열을 반환합니다. 상위 수준 번호가 바뀌면 하위 수준을 재시작합니다. 같은 개요 정의를 쓰는 구역의 번호는 이어집니다.

HWP5는 확인된 10진 번호와 10진 수준 경로를 처리합니다. HWPX는 원본이 형식을 명시하고 지원되는 포매터가 결과를 계산할 수 있을 때 값을 반환합니다. 중첩된 본문 외 목록, 시작값 충돌, 해석되지 않은 재시작 제어, 다른 개요 정의로 전환된 구역은 계산할 근거가 없으면 `numbering-not-computed`를 반환합니다. 이 값은 조회 API가 제공하며 Canvas 위의 번호 표시·편집은 별도입니다.
