# ICC 고정소수점 행렬 적용

순방향·역방향의 정확한 고정소수점 입력 계산을 구현하고 세 모드 전체 감사를 통과했습니다. 색상 변환 전체의 검증 완료가 아니며 아래 연결·백색점 검증 범위는 남아 있습니다.

## 수학 계약

[ICC.1:2022 §9.2.15 식 (11)](https://www.color.org/specifications/ICC.1-2022-05.pdf)의 행 우선 3×3 행렬을 적용하는 순수 계산 계층입니다. `matrix3_transform.forward/inverse`는 행렬 계수 9개와 XYZ 3개를 모두 signed 16.16 원시 정수로 받습니다. [chad 파싱·비특이 검사](icc-chromatic-adaptation.md)와 독립적이며 파일 읽기·할당·판본 정책을 포함하지 않습니다.

출력 ExactVector는 실제 좌표를 나타내는 i128 분자 3개와 양수 u128 공통 분모입니다. 기존 TRC의 Fraction은 0~1 범위의 unsigned 계약이므로 음수·범위 밖 XYZ를 표현하는 데 재사용하지 않습니다. 결과를 약분·클리핑하거나 s15Fixed16로 다시 반올림하지 않습니다.

순방향 분자는 각 행의 계수와 입력 벡터의 내적이며 분모는 65536²입니다. 곱 3개의 절댓값 합은 3×2^62 이하이므로 i128에서 정확합니다. 특이행렬도 순방향 선형 변환 자체는 정의되므로 이 계산기는 거부하지 않습니다. chad로서의 유효성은 별도 파서가 검사합니다.

역방향은 Cramer 공식으로 각 열을 입력 벡터로 교체한 행렬식과 원본 행렬식을 사용합니다. 계수와 입력의 16.16 스케일이 상쇄되어 결과 좌표는 두 정수 행렬식의 비입니다. 기존 matrix3_fixed.determinantNumerator가 유일한 행렬식 구현입니다. 분모 0은 오류, 음수 분모는 분자·분모의 부호를 함께 반전합니다. 분자·분모의 최대 절댓값은 기존 i128 증명 범위 안이며 negation도 안전합니다.

## 범위와 검증 진행

이 단계는 고정소수점 입력의 정확한 선형 변환입니다. 부동소수점/TRC 결과 연결, 입력·출력 인코딩 변환, 실제 백색점의 일치, 상태가 나쁜 행렬의 수치적 안정성 진단, PNG 픽셀 연결은 아직 남아 있습니다. 역행렬이 존재한다는 이유로 전체 색상 변환을 검증했다고 보고하지 않습니다.

네이티브 테스트는 항등·비대칭 행렬의 행/열 순서, 고정소수점 스케일, 음수·1 초과 좌표, i32 극값의 누산, 음수 행렬식, 특이행렬 거부, 큰 곱 상쇄 뒤 행렬식 -1인 경우를 포함합니다. WASM 독립 비교와 전체 감사 결과는 실행 후 기록합니다.

2026-09-08 최초 네이티브 실행은 종료 코드 0, 5/5 단계·470/470 테스트로 통과했습니다. 포맷·diff 공백 검사도 통과했습니다. WASM 독립 계산·세 모드 전체 감사·최종 적대적 검증은 아직 완료 전입니다.

WASM mode173/174를 정규 감사에 연결했습니다. 입력은 행렬 9개·벡터 3개의 big-endian i32이며 출력은 i128 분자 3개·u128 분모의 little-endian 64바이트입니다. 독립 JS는 유리수 가우스 소거와 행 교환으로 역방향 해를 계산하고, 교차 곱으로 출력 분수와 비교합니다. 제품의 Cramer 공식이나 행렬식 함수를 사용하지 않습니다.

최초 Debug WASM 직접 실행에서 정상 비교 36,367건·오류 거부 8,223건이 통과했습니다. 계수 {-1,0,1}의 3^9 조합, 무작위 i32 행렬 2,048개, min/max 계수 조합 512개, 상쇄 경계, 잘림·초과 길이·한도·실패 후 복구를 포함합니다. 독립 계산기 자체는 비대칭 삼각행렬·행 교환·특이행렬·항등 스케일의 알려진 결과 4건으로 별도 확인했습니다.

로컬 시스템의 v4 ICC 프로파일 6개에서 읽은 chad 행렬에 벡터 4종을 순·역방향으로 적용한 수동 검사 48건도 독립 기대값과 일치했습니다. 0, 단위 좌표, 음수·범위 초과, i32 극값 입력을 포함합니다. 프로파일을 저장소에 복사하지 않았으며 실제 채택 백색점 검증이나 픽셀 변환의 정확성을 주장하지 않습니다. 수동 검사 수는 정규 감사에 더하지 않습니다. Debug 전체 감사는 실행 중입니다.

추가 수동 적대적 검사에서는 다른 고정 seed의 i32 행렬·벡터 2,048개를 사용하여 WASM이 반환한 역방향 분자·분모를 원래 방정식에 대입했습니다. 가우스 소거 기대값이나 행렬식을 다시 계산하지 않고 각 행의 A×numerators = input×denominator를 직접 확인했습니다. 6,144개 정수 등식이 모두 성립했고 모든 분모가 양수였습니다. 이 수동 검사 수는 정규 감사에 합산하지 않습니다.

Debug 전체 감사는 `/tmp/hwpjs-icc-matrix-Debug-final.log`에서 종료 코드 0, 20/20 단계·470/470 네이티브 테스트·WASM 5,124,481개 검사로 통과했습니다. 이번 주제 비교 36,367건·거부 8,223건도 확인했습니다. ReleaseSafe·ReleaseFast 전체 감사는 아직 완료 전입니다.

ReleaseSafe 전체 감사도 `/tmp/hwpjs-icc-matrix-ReleaseSafe-final.log`에서 종료 코드 0, 20/20 단계·470/470 네이티브 테스트·WASM 5,124,481개 검사로 통과했습니다. 이번 주제 비교 36,367건·거부 8,223건이 일치했습니다. ReleaseFast 감사는 진행 중입니다.

ReleaseFast 전체 감사도 `/tmp/hwpjs-icc-matrix-ReleaseFast-final.log`에서 종료 코드 0, 20/20 단계·470/470 네이티브 테스트·WASM 5,124,481개 검사로 통과했습니다. 이번 주제 비교 36,367건·거부 8,223건이 일치하여 세 모드 검증을 마쳤습니다. 위 진행 중 표현은 각 실행 당시 기록입니다.

최종 적대적 리뷰에서 입력 길이·한도, i128 중간값과 부호 반전 범위, 고정소수점 스케일, 특이행렬의 순/역방향 정책 차이, 반환 계수 소유권과 행렬식 SSOT 재사용을 확인했습니다. 이번 범위에서 추가 결함은 발견하지 못했습니다. 포맷·변경 JS 구문·diff 공백과 관련 문서 로컬 링크 2개 검사도 통과했습니다. 전체 ICC 프로파일·PNG 픽셀·HWP/HWPX 문서 검증은 계속 미완료입니다.
