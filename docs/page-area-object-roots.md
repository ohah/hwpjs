# 본문·머리말·꼬리말의 원본 도형 소유권

`partitionPageAreaOwnership`는 표시 개체와 `hwp5Drawings` 원본 목록을 같은 소유 범위로 나눕니다. 원본의 section/hostParagraph를 기존 owner 해석에 전달하므로 머리말의 표 셀·도형 텍스트 안에 있는 개체도 해당 영역에 남습니다. 본문 기본값으로 추정하거나 배열 순서로 소유자를 정하지 않습니다.

각 원본 항목은 본문 또는 하나의 영역에 정확히 한 번 포함되며, 항목의 참조와 입력은 유지합니다. section/componentNode를 기존 index로 검증하여 같은 구역의 중복 ID와 잘못된 값을 거부합니다. 없는 문단·개체 소유자, 잘못된 리스트 참조와 순환도 계속 거부합니다. 다른 구역의 같은 로컬 번호로 대체하지 않습니다.

원본 목록이 없으면 속성 부재를 유지하고, 빈 목록을 명시한 경우 본문/영역에 빈 배열을 제공합니다. 이 분리는 consumer의 누락 배치 검사나 미지원 개체 정책을 완화하지 않습니다.

`node --test tests/hwp5/page-area-object-roots.test.mjs`는 서로 다른 구역의 같은 로컬 번호, 중첩 표/도형 소유권, 누락/중복/순환과 입력 불변성6건을 검사합니다. 게시 전 HEAD 사본에도 이 변경만 적용해 같은 검사를 실행합니다. 이 계약은 전체 페이지 조판 지원을 뜻하지 않습니다.
