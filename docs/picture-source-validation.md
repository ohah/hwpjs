# 그림 원본 검사 단일 출처

`picture-source-validation.mjs`는 원본 조회 오류7개 필드와 crop의 유한 좌표4개 배열 구조를 소유합니다. 본문·표·도형 내부 그림이 동일 검사를 사용하며 인라인 그림 색인도 같은 crop 검사를 재사용합니다. 기존 경로별 오류 이름과 판정 순서는 호출자가 유지합니다.

오류 필드의 누락/null은 오류 없음이고, 다른 값은 빈 문자열·false·0이어도 오류가 있는 입력입니다. crop은 정확히4개인 일반 배열이며 희소 배열·비유한 숫자·typed array는 이 JSON 모델 경계에서 거부합니다. 이는 crop 좌표의 방향·범위·픽셀 매핑을 모두 검증한다는 뜻이 아닙니다. 그 의미는 기존 crop geometry가 계속 소유하며 유한한 음수 값을 여기서 임의로 수정하지 않습니다.

2026-10-19 수정 전 격리 HEAD에 새 회귀를 적용하면, 유효한 나머지 필드와 희소 crop 배열을 가진 그림이 도형 내부 소속에 포함되어 실패했습니다. `Array.every`가 빈 칸을 검사하지 않는 것이 원인입니다. `Array.from`으로 빈 칸까지 검사하고 인라인 색인과 소속 경로가 모두 거부하도록 수정했습니다. 실제 파일 바이트에서 희소 JS 배열이 나왔다는 주장은 아닙니다.

`tests/hwpx/picture-source-validation.test.mjs`는 모든 원본 오류 필드의 부재/명시 값과 crop의 배열 길이·희소성·비유한 숫자, 기존 소속/색인의 거부를 검사합니다. 캡션 native/복합 프레임 후보와 독립적인 JS 수정입니다.

새 원본 검사2개와 기존 도형 소속4개·표 앵커4개·그림 정렬1개를 격리 게시 소스에서11/11, skip0으로 확인했습니다. 실제 참조2문서의 Worker 소속도 포함하지만 모든 픽스쳐의 조판·편집 완료 검사는 아닙니다.
