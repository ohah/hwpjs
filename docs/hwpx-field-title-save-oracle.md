# 필드·제목 마커 서식의 독립 저장 검사

`tools/hwpx-field-title-save-oracle.py`는 원본 ZIP과 명시한 편집 명령만으로 기대 XML을 생성합니다. 제품의 저장 결과에서 서식이나 run 분할을 역으로 추론하지 않습니다. 기존 `hwpx-character-format-oracle.py`의 리소스·스칼라 검사와 함께 사용합니다.

지원하는 검사 범위는 원본 텍스트 요소별 동일 서식 변경과 제목 마커 경계의 선언된 한 문자 교체입니다. 가시 텍스트는 요청한 서식 ID로 바꾸고, 빈 텍스트 요소는 기존 서식과 소유권을 유지합니다. 필드 제어·dirty·마커·속성·주석·처리 지시문을 보존하며, 선언한 대상 줄 캐시 무효화만 허용합니다. 같은 텍스트 요소 내부의 여러 서식과 이동한 제목 마커는 이 검사기의 완료 범위가 아닙니다.

전체 기대 XML infoset과 결과를 비교하며 비대상 ZIP 항목의 payload는 바이트 단위로 비교합니다. ZIP 항목 순서·중복·CRC·메타데이터·주석도 확인합니다. XML 인용부호·동등한 문자 참조·빈 태그 표기의 바이트 동일성이나 ZIP 재압축 결과의 바이트 동일성을 뜻하지 않습니다.

최초 원본에 서식 변경과 교체 명령을 함께 재생합니다. 잘못된 기대 서식은 원본 헤더에 존재하는 다른 유효 ID를 사용하므로, 리소스 유효성 검사에서 우연히 거부된 결과를 서식 검증 성공으로 세지 않습니다.

독립 합성 반례18개는 빈 요소 서식 변경·삭제, 필드 복제·dirty 변경, 제목 마커 위치 변경, 다른 문단·속성·주석·처리 지시문·바이너리 변경 등을 거부합니다. 실제 WASM·브라우저 실행이나 한글 조판 동치를 증명하는 검사는 아닙니다.

```sh
mise exec -- node --test tests/hwpx/field-title-save-oracle.test.mjs
```

위 명령은 Python 일반·최적화 모드에서 자체 검사를 실행하며 WASM·reference·과거 로컬 캡처를 요구하지 않습니다. 개별 JSON 요청은 `before`/`after`의 base64 ZIP, 문단, 서식 ID, 범위와 검사 모드를 명시해 Python 도구의 stdin으로 전달합니다. 전체 제품 gate와의 연결은 별도 Native·공개 API 검증에 속합니다.
