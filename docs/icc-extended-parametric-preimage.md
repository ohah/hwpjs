# ICC 512비트 목표값의 전체 도달 역상

## 계약

`parametric_preimage.solveWide(precision, curve, n, d)`는 [0,1]에서 clip(f(x))=n/d인 모든 실제 x를 선형·거듭제곱 분기의 기여분 합집합으로 보존합니다. 목표는 정규화 u512이며 결과는 undecided 또는 set입니다. 목표와 전체 곡선 정의역을 먼저 검사합니다. 상위가 미확정이면 확정된 하위 해도 부분적으로 노출하지 않습니다.

`Wide.Set.linear`는 [넓은 선형 역상](icc-extended-linear-preimage.md)의 optional ExtendedInterval이고, power는 [넓은 클리핑 역상](icc-extended-power-preimage.md)의 optional Set입니다. linear=null은 하위 기여분 부재입니다. power=null은 상위 분기 비활성이고, 활성이나 해가 없으면 source를 가진 빈 Set을 유지합니다. isEmpty는 두 기여분을 모두 확인합니다.

선형 끝점과 거듭제곱 점의 성분은 u1024로 보존합니다. 반환 집합은 정렬·병합·중복 제거한 표준 목록이나 선택된 역함수 값이 아닙니다. 비단조 곡선의 분리된 여러 해도 유지하고, 빈 역상을 최근접 출력으로 채우지 않습니다.

## 경계와 SSOT

전체 집합의 하한·상한과 도달 여부는 [확장 경계](icc-extended-preimage-bounds.md)에서 별도로 구합니다. 집합 조립과 역함수 선택의 책임은 합치지 않습니다.

기존 [u128 전체 역상](icc-parametric-preimage.md)과 solveFor가 검증 순서·분기 조립을 공유합니다. parametric_preimage_types.Of가 두 폭의 Set/Result와 isEmpty를 공유하며 별도의 합집합 알고리즘을 복제하지 않습니다.

parametric_segments의 하위 [0,start)·상위 [start,1] 소유권을 그대로 유지합니다. start=1이면 상위 닫힌 단일점이 남고, 상위가 비활성이면 하위의 끝 1이 포함됩니다. 선형·거듭제곱 해 계산은 각각 기존 모듈이 소유하며 전체 조립은 할당·파일 접근·실수 근사를 하지 않습니다. 기존 solve/Result와 제품 JS API는 유지합니다.

## 독립 검증

테스트 mode228 입력은 precision u32+n/d u512의 132바이트 BE prefix 뒤 para 태그입니다. undecided는 status=0의 4바이트뿐입니다. 확정 결과는 status=1, isEmpty, 520바이트 선형 wire, 가변 길이 넓은 power wire 순서이며 power는 offset 528에서 시작합니다. probe는 기존 mode200과 폭별 입력·출력 조립을 공유하고 임시 power 버퍼는 defer로 해제한 뒤 복사합니다.

JS 기준은 독립 정의역/분기 기준으로 하위 식과 열린 구간을 만들고 선형 critical-cell 기준으로 대조합니다. 상위는 기존 독립 거듭제곱 집합 기준으로 모든 기호 경계와 사이 구간을 검사합니다. 원래 분기 소유권과 두 기여분이 정확한지 확인하고 isEmpty도 대조합니다. 제품의 전체 조립 결과로 기대값을 만들지 않습니다.

신규 직접 결과는 comparisons=5,060, rejected=3,231, undecided=1, membershipChecks=13,495입니다. 마지막 수치는 상위 집합 내부 검사 수이며 추가 WASM 호출 수가 아닙니다. 기존 경로도 5,040/3,135/1, membershipChecks=13,422로 통과했습니다. 다섯 곡선 유형, 서로 다른 상·하위 계수, 열린 경계·마지막 단일점·비활성 분기·점프 틈, 세 분리 해, 최대 u512 분모와 이웃, 잘림·한도·오류 후 복구를 포함합니다.

네이티브는 점프 틈, 마지막 단일점, 선형 한 점+상위 두 점, 상위 미확정 시 하위 비노출, 잘못된 전체 정의역을 검사합니다. near-start 목표 `65537^2*2^448/(2^512−1)`는 128비트 정밀도에서 전체 undecided이고 1024비트에서 하위 해와 상위 내부 근을 모두 보존합니다.

## 적대적 검사와 실파일

하위 기여분 삭제, 상위 기여분 삭제, 하위 열린 끝을 닫기, 미확정 대신 고정밀 결과의 하위 해만 노출하는 네 변형을 모두 ERR_ASSERTION으로 검출했습니다. 삭제할 때 isEmpty와 길이도 남은 내용에 맞추어 단순 wire 불일치만 검출한 것이 아니도록 했습니다. 임시 복사본 `/tmp/hwpjs-extended-parametric-mutant.ewjDA2/icc`에서 isEmpty가 선형 해를 무시하도록 바꾼 다섯 번째 소스 변형은 세 모드 모두 5개 중 2개 테스트가 실패했습니다. 제품에는 변형을 적용하지 않았습니다.

실제 시스템 ICC 프로파일 5개의 para 태그 15개에서 양의 g/a, a+b=65536, 활성 시작의 양수 밑과 양의 하위 기울기 등 필요한 전제를 읽기 전용으로 확인했습니다. 이 전제에서 전체 곡선의 출력 0/1 역상은 각각 {0}/{1}입니다. u512 최대 분모로 표현한 목표에 대해 반환된 선형 구간·상위 기호 구간·점의 모든 성분을 정확한 유리수 좌표로 해석해 30개 집합, 45개 기여 항목이 이 기준과 일치했습니다. 중복된 동일 해 표현은 허용합니다. 정규 audit 횟수에 합산하지 않으며 모든 목표값이나 렌더링 일치의 증명은 아닙니다.

## 최종 회귀 결과

Debug·ReleaseSafe·ReleaseFast 전체 audit는 모두 종료 코드 0, 20/20 단계, 네이티브 648/648, WASM checks=6,947,166으로 통과했습니다. 이전 6,938,874에 신규 8,292회 호출이 추가됐으며 membershipChecks는 별도 호출로 더하지 않습니다. 로그는 `/tmp/hwpjs-extended-parametric-{Debug,ReleaseSafe,ReleaseFast}.log`이며 임시 로컬 산출물입니다.

Safe/Fast 실제 audit WASM의 직접 대조에서도 신규·기존 결과와 출력 변형 4종 검출이 일치했습니다. 소스 변형은 세 모드 네이티브 테스트에서 검출했습니다. 변경 문서의 로컬 링크 13개, Zig 포맷·JS 문법·diff 공백을 확인했습니다. 전체 정의역 선행 검사, 미확정의 부분 결과 비노출, 분기 끝점 소유권, source를 가진 빈 상위 집합과 비활성의 구분, 임시 serializer 버퍼 수명을 재검토했습니다.

## 미완료 경계

두 분기의 넓은 도달 역상 합집합까지 연결했습니다. 표준 구간 목록 정리, 전체 역상의 경계 순서·실제 극값과 F.1 선택, 단조성·비상수성에 따른 역함수 적격성, 최근접 출력 및 넓은 TRC 모델 통합은 후속 범위입니다. 전체 ICC/HWP/HWPX 문서 검증은 미완료입니다.
