# 문단 번호·글머리표 Canvas 표시

번호 문자열과 원본 정의 조회는 [캐럿 문단 머리표](canvas-caret-heading.md)가 소유합니다. 이 문서는 원본 머리표의 슬롯·정렬·간격을 본문 Canvas와 인쇄 페이지에 배치하는 계약을 소유합니다. HWP5의 문단 머리 정보와 HWPX의 문단 heading 및 numbering/bullet 정의를 사용하며 본문 문자열에서 번호를 추측하지 않습니다.

## 표시와 원문 경계

Native는 참조된 머리표의 정렬, 실제 너비 사용 여부, 자동 내어쓰기, 너비 조정, 간격 단위·값과 글자 모양 참조를 투영합니다. `paragraph-marker.mjs`는 원본 값과 같은 본문 글꼴의 측정으로 첫 행 슬롯과 계속 행의 시작점을 구합니다. 첫 행의 화면 전용 prefix에만 표시 문자열을 두며 원문 UTF-16 좌표·선택·복사 텍스트를 늘리지 않습니다. 기존 자동 번호 표시가 있는 문단에 중복으로 그리지 않습니다.

본문 전체 흐름과 다단의 지연 행 생성은 같은 계산을 사용합니다. 지연 행 생성의 머리표 계획은 조판 호출 소유의 WeakMap과 너비별 Map으로 재사용합니다. 재조판은 새 캐시를 만들며, 기존 문단 번호가 편집되어 다음 번호가 바뀔 수 있는 경우 문단 행 캐시를 우회합니다. 화면과 인쇄는 같은 prefix painter를 사용합니다.

## 지원 범위와 제한

확인된 번호 형식과 일반 본문 LEFT/JUSTIFY 정렬, 본문에서 상속한 글꼴부터 표시합니다. 중첩 표·글상자·개체 owner, 원본이 모호한 정의, private-use 글머리 문자, 명시적 별도 머리표 글꼴, 가로 배율·상대 높이 변경 글꼴, 저자 지정 첫 행 들여쓰기와 자동 내어쓰기의 조합은 기존 배치로 돌립니다. tab·부분 텍스트와 본문 가운데/오른쪽 정렬도 후속입니다. 원문은 보존합니다.

머리표 문자열은 128 UTF-16 unit, 본문은 32,768 unit까지 이 경로에서 처리합니다. 예약 너비는 256px와 가용 폭 1/3 중 작은 값으로 제한합니다. 이 제한을 전체 문서 지원 완료로 해석하지 않습니다. 머리표 적용·해제 writer와 새 numbering/bullet 선언 생성은 표시와 별도 기능입니다.

## 검증 경계

통합 후보의 행·머리표·캐럿·F5 집중 검사와 Native 원본 투영·할당 실패 검사를 수행합니다. 화면과 모든 인쇄 페이지의 실제 문자열·좌표 및 독립 PNG ink 검사는 별도 브라우저 증거로 확인하며, 단위 검사만으로 공식 한글의 조판과 같다고 주장하지 않습니다. HWP5 wire의 새 optional export는 기존 export를 유지하고, 미지원 엔진에서는 기존 조회 경로를 사용합니다.

통합된 ReleaseSafe 엔진의 확인 결과는 집중 JS 23개, Native 6개, 기존 셀 합치기 Core 7개, 실제 Worker 누름틀·선택·프로필 39개 통과입니다. 실제 Chromium에서 HWP5/HWPX 원본 여섯 개와 정렬·고정 슬롯·가로 용지·초과 너비 파생본 여섯 개의 43쪽·머리표 255개를 화면/인쇄 및 독립 PNG/XML로 확인했습니다. 공통 문단 58개의 HWP5/HWPX 머리표 위치가 일치했고, 양 형식의 실제 문단 서식 변경에서 다음 번호가 `2. → 1. → 2.`로 갱신됐습니다. 이는 명시한 문서·지원 배치의 증거이며 전체 문서나 공식 한글의 픽셀 동치를 뜻하지 않습니다.
