# ICC curveType 원시 파서

## 계약과 근거

[ICC.1:2022 §10.6, Table 35](https://www.color.org/specifications/ICC.1-2022-05.pdf)를 대조해 `curve_type.zig`에 원시 형식을 구현했습니다. 0개는 identity, 1개는 u8Fixed8 감마 원형, 2개 이상은 빌린 big-endian u16 샘플 배열입니다. 감마를 역수나 0–65535 정규화 샘플로 오해하지 않도록 union으로 구분합니다. 감마 0도 원형대로 보존하며 수학적 평가 정책은 적용하지 않습니다.

공통 타입 접두사는 기존 `type_prefix.zig`를 재사용합니다. 개수는 payload 길이의 나눗셈 결과와 대조하며 곱셈으로 오버플로를 유발하지 않습니다. 정확한 패딩 제외 payload만 받으며, 선언 개수와 다른 길이·홀수 꼬리·불필요한 태그 패딩을 거부합니다. 샘플 조회는 인덱스를 먼저 검사합니다. 파싱은 할당하지 않고, 샘플의 수명은 입력에 종속됩니다. identity와 gamma는 입력을 빌리지 않습니다.

샘플 순서·끝값을 보정하거나 단조 증가를 임의로 요구하지 않습니다. 실제 곡선 평가(감마 지수·선형 보간), TRC별 규칙, parametricCurveType, LUT 내부 prefix 소비·패딩과 문서/PNG 연결은 아직 미완료입니다. 이 원시 파싱의 성공은 변환 유효성이나 전체 필수 태그 검증 성공이 아닙니다.

[ICC.1:2001-04 §6.5.3, Table 37](https://www.color.org/specification/ICC.1-2001-04.pdf)도 대조했습니다. 이 판본의 curv 배치와 0/1/다수 개수 해석은 현재 파서와 일치합니다. 해당 문서의 개정 이력은 1998년 zero/one-entry 해석 통일을 언급하므로, 이 확인을 모든 이전 v2 판본의 동일 의미 보장으로 확대하지 않습니다.

## 검증

새 Debug WASM에서 독립 JS 대조를 직접 실행하여 비교 65,793건·예상 오류 거부 332건이 통과했습니다. 이는 아래 전체 감사의 최종 완료와 구분합니다.

공식 RGB 등록부의 [sRGB2014](https://registry.color.org/rgb-registry/profiles/sRGB2014.icc)를 메모리로 읽어 curv 태그 3개(각 1,024개 샘플)를 독립 Node 정수 읽기와 mode 153으로 대조했으며 모두 일치했습니다. 태그별 비교 수이며 공유 데이터의 고유 개수를 뜻하지 않습니다. 같은 등록부의 v4 preference·displayclass 파일에는 최상위 curv 타입 태그가 없어 비교 0건이었습니다. LUT 내부 곡선을 조사한 것이 아니므로 이를 v4 실파일 곡선 검증 통과로 취급하지 않습니다. 수동 결과는 자동 감사 수에 합산하지 않습니다.

2026-09-07 포맷 검사와 `zig build test --summary all`이 통과했습니다(5/5 단계, 네이티브 429/429). 신규 네이티브 검사는 감마 전체 65,536개 원형, 서로 다른 샘플/입력 공유, 최대 인덱스, 큰 u32 개수, 길이 0–33, 접두사 변형과 복구를 포함합니다.

테스트용 mode 153은 종류 DWORD와 원시 감마/샘플 u16 LE 배열을 반환합니다. JS는 원래 값 배열에서 독립 기대값을 생성합니다. 감마 전체 원형, 2–256개 샘플, 잘림·큰 개수·각 접두사 비트 손상·입력 한도와 복구를 정규 감사에 연결했습니다. 최종 Debug·ReleaseSafe·ReleaseFast 전체 감사가 모두 종료 코드 0, 20/20 단계, 네이티브 429/429, 감사 검사 4,480,182건으로 통과했습니다. 신규 비교 65,793건·거부 332건도 세 모드 모두 확인했습니다. 로그는 로컬 `/tmp/hwpjs-icc-curve-Debug-final.log`, `/tmp/hwpjs-icc-curve-ReleaseSafe-final.log`, `/tmp/hwpjs-icc-curve-ReleaseFast-final.log`입니다. 검사 건수는 반복·변형을 포함하며 문서 수나 포맷 지원률이 아닙니다.

재검토에서 개수 곱셈 이전의 길이 대조, 조회 인덱스 경계, 할당 없는 파싱과 샘플 수명, 공통 접두사 규칙의 단일 소유자를 확인했습니다. 추가 결함은 발견하지 못했으며 전체 TRC 의미·곡선 평가의 미구현 범위는 그대로 남아 있습니다.
