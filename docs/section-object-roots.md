# 구역별 원본 도형 목록

`sectionObjectContent`는 장면의 개체 목록과 원본 HWP5 도형 목록을 같은 구역으로 제한합니다. componentNode는 구역 내 ID이므로 다른 구역의 같은 번호를 같은 개체로 취급하지 않습니다. 항목의 구역 값과 선언 구역의 존재를 먼저 검사하고, 선택한 배열만 새로 만들며 원본 항목과 입력을 변경하지 않습니다.

원본 `hwp5Drawings`를 전 문서 그대로 전달하면 특정 구역의 충돌 검사가 다른 구역 그림의 배치를 찾게 됩니다. 원본 목록을 producer에서 함께 제한하며, 누락 배치나 미지원 개체를 확인하는 consumer 검사는 완화하지 않습니다.

`node --test tests/hwp5/section-object-roots.test.mjs`는 같은 로컬 노드 번호를 가진 두 구역, 원본 불변성, 잘못된/미선언 소유권을 확인합니다. 이 독립 검사는 전체 문서 조판이나 모든 개체의 지원을 증명하지 않습니다.
