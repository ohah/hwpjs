# 인라인 표의 영구 가로 비적합 판정

`inline-table-row-fit.mjs`는 기존 문단 정렬·여백 계산을 공유해 표가 물리 종이 안에 들어가는지 판정합니다. 본문 단보다 넓어도 종이 안이면 허용합니다. 원본 셀 폭·표 크기·문단 ID·캐럿 좌표를 축소하거나 보정하지 않습니다.

기존 페이지 배치기는 종이를 넘는 인라인 표도 다음 단과 페이지에서 다시 시도해 최대 2,000페이지를 소모한 뒤 `PageFlowLimit`을 반환했습니다. HWP5 실제 저장 입력의 표 폭 54,000HU, 종이 폭 59,528HU, 왼쪽 여백 5,669HU와 문단 정렬/들여쓰기 원값을 다시 읽었습니다. 이 입력은 본문 폭 초과 자체가 아니라 실제 종이 오른쪽을 141HU(1.88px) 넘습니다. 동일 입력의 집중 대조는 변경 전 적합 검사 2,000회, 후보 1회이며 원본 값은 같습니다. 전체 문서 열기나 입력 반응의 속도 개선율을 뜻하지 않습니다.

## 소유자와 증명 범위

일반 `rowFitsColumn` callback은 페이지에 따라 결과가 달라질 수 있습니다. 배치기는 기본적으로 기존 재시도를 유지합니다. 표 본문 소유자가 `createInlineTableFitRejection`을 명시적으로 연결한 불변 표 band만 추가 판정을 사용합니다. 그림·종이 기준 표·주입된 별도 paginator, 위치 의존 재측정과 `paragraphSource`가 있는 가변 텍스트는 이 판정에서 제외합니다.

페이지 geometry 검증이 끝난 뒤 `left_only` 또는 gutter가 0이고 좌우 여백이 같은 `left_right`에만 증명을 활성화합니다. 현재 이 설정들의 수평 종이·단 배치는 페이지 사이에서 불변입니다. 페이지별 수평 geometry를 바꾸는 기능을 추가할 때 이 gate와 소유자 계약을 함께 갱신하며, 증명이 추가되기 전에는 opt-in에서 제외해야 합니다.

각 source의 실제 적합 판정 결과를 관찰해 false인 단 순번만 Set에 저장합니다. 모든 단의 false를 확인한 경우에만 `InlineTablePaperOverflow`와 원본 폭·종이 폭·정렬 경계·좌우 초과량·소유자 진단을 반환합니다. true가 나오거나 관측 geometry/fit 입력이 달라지면 증명을 폐기합니다. 같은 key가 반복됐다는 이유나 세로 공간 부족만으로 가로 실패를 확정하지 않습니다. Set은 다음 source로 재사용하지 않습니다.

추가 관측 작업은 방문한 단마다 평균 O(1), 임시 상태는 O(단 수)입니다. 기존 열 생성·측정·전체 조판의 복잡도나 실행 시간을 이 보장으로 확대하지 않습니다. 기본 strict 배치는 페이지 경계 초과 표를 계속 거부합니다. Canvas의 제한된 단순 표는 [부분 미리보기](inline-table-paper-preview.md)에서 원본 폭을 유지해 클립하며, 이 별도 화면 정책을 전체 조판 지원으로 해석하지 않습니다.

## 검증

집중 검사는 실제 HU 경계, 본문 여백의 허용 넘침, 여러 정렬·부호 있는 들여쓰기, 다음 페이지 앞 단과 역방향 단에서의 성공, 건너뛴 단·source별 상태 분리, 일반 callback의 뒤 페이지 성공, 위치 의존 경로의 opt-out, 변경된 geometry와 입력, 잘못된 callback 결과 및 64단에서의 방문 횟수를 확인합니다. 실행은 [개발 명령](development-commands.md)을 따릅니다. 기본 번들의 실제 브라우저·저장·Native 이력과 공개 배포 증거는 별도 기록합니다.

후보 `438044e0060fb0f40ab8a4a76eee2027e387f68579d547487fcd74ca88129088`와 정적 manifest `7aa21b57c6a598fdb0f905e6aca10b8f537192b24c6d3862b4415dcc34910327`에서 일반 편집 6조합·24동작·168개 저장 오라클과 별도 너비 초과 HWP5 3조합을 실제 브라우저로 확인했습니다. 너비 초과의 결과는 `InlineTablePaperOverflow`·논리 fallback·읽기 전용이며, 세 framework가 저장한 CFB 5120바이트는 승인 원본과 같습니다. 브라우저 오류 캡처는 비어 있고 소유 세션 종료를 확인했습니다. `oversize-table-flow-r1/task-e/{browser-r1,final-report-r2.json}`이 근거입니다. 공개 서버의 정적 파일 동일성 확인과 로컬 브라우저 실행은 별도입니다. 현재 수정은 Git 소스·데모 대상으로 npm 게시를 포함하지 않습니다.
