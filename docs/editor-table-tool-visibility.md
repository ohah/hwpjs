# 표 도구 가시성

표 삽입 입력과 가시성은 `table-creation-controls.mjs`가 소유합니다. 사용할 수 없는 닫힌 도구에 안내가 없을 때만 form.hidden=true로 둡니다. 실제 선택과 리소스가 준비되면 기존 버튼을 노출합니다. 이미 열린 입력이나 진행/완료/오류 안내는 선택이 없어져도 숨기지 않습니다. 별도 가시성 캐시나 삽입 정책을 만들지 않습니다.

HTML도 초기 hidden으로 시작하고 공통 [hidden] 스타일이 flex보다 우선합니다. 기존 메뉴의 eligibility·실제 삽입 명령·ID와 포커스/ESC 계약은 유지합니다. 새 문서 load/unlock은 기존처럼 상태와 입력을 초기화합니다.

대역 DOM은 닫힌 비활성 도구 숨김, 선택 후 노출, 열린 입력의 선택 상실, 닫힌 완료 안내 유지, 새 문서/close 초기화와 기존 stale-caret/리소스 상실 반례를 검사합니다. 별도 정적 검사는 초기 HTML/CSS hidden 계약을 확인합니다. 실제 Chromium 레이아웃이나 전체 표 생성 동치의 증거는 아닙니다.
