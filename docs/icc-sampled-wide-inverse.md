# 512비트 목표의 sampled 역변환

## 범위와 책임

`sampled_inverse.invertWide(samples, numerator:u512, denominator:u512)`는 정규화 목표를 받아 정확한 u1024 분자/분모 쌍 ExtendedFraction을 반환합니다. 분모는 양수이고 분자는 분모 이하입니다. 이 결과 타입은 정수 쌍이며 암묵적 부동소수점 변환 API를 제공하지 않습니다.

기존 invert(u16 목표)/invertNormalized(u128 목표)의 타입과 계약은 유지합니다. 세 경로는 같은 generic invertOrdinate 구현을 사용하고 정규화 입력은 기존 fraction.Normalized.validate를 호출합니다. sampled_inverse_types가 입력·작업 정수·결과 타입 대응을 소유합니다. 단조성/상수 거부·최근접 끝점·보간 로직을 폭별로 복제하지 않습니다.

전체 sample 배열 검증 뒤 평탄 역상 선택을 기존 preimage_choice에 맡깁니다. 이 구간의 좌표는 sample 인덱스/구간 수이므로 기존 u256 표현에 충분히 들어가며 선택된 분수만 결과 폭으로 정확히 확장합니다. 감소 곡선에도 입력 위치 기준의 기존 F.1(a) 규칙을 적용합니다.

## 정밀도와 경계

Samples.checkedCount가 개수를 2..u32 최대값으로 제한합니다. u512 분모에 16비트 sample 값을 곱한 값은 2^528 미만이고, 보간 결과는 구간 수를 곱해도 2^560 미만입니다. 작업과 반환값은 u1024여서 전체 입력 범위를 포함합니다. 실제로 [0,65535] 곡선의 최대 부근 목표는 약분하지 않은 결과가 512비트를 넘습니다. 이를 u512에 담거나 0/1로 근사하지 않습니다.

목표 분모 0·분자>분모는 배열 검사 전에 InvalidIccCurveCoordinate로 거부합니다. malformed 배열, 뒤에서 발견되는 비단조성, 상수 곡선도 기존 오류를 유지합니다. 알고리즘은 비할당이고 원본 sample 바이트를 빌립니다.

## 검증 진행

신규 네이티브 4개와 기존 sampled 역변환 6개가 통과했습니다. 최대 u512 목표와 512비트 초과 결과, 시작/중간/끝 평탄부, 증가/감소, 출력 범위 밖 목표, 전체 배열 검증, 기존 u128 경로와 원분수 일치를 포함합니다.

테스트 mode 219는 u512 목표 분자/분모의 big-endian 128바이트 뒤 curv 태그를 파싱합니다. 출력은 u1024 분자/분모의 little-endian 256바이트입니다. identity/gamma 태그를 sampled로 처리하지 않으며 길이/limit와 실패 후 복구를 검사합니다.

Debug WASM 직접 대조는 비교 1,815·거부 5,904(합계 7,719건)으로 통과했습니다. sample 값 {0,32768,65535}의 길이 2~6 전체 조합과 목표 6종, 무작위 단조/역순 곡선 1,024건, u512 최대 분모, 평탄부·범위 밖 목표·잘림·오류 후 재사용을 포함합니다. 독립 JS oracle은 각 선분과 목표의 교점을 구해 전체 후보에서 위치 규칙을 적용합니다.

기존 정규화 역변환 905 비교/5,808 거부와 u16 역변환 965 비교/6,734 거부도 동일하게 통과했습니다. 출력의 상위 비트를 지워 512비트로 좁히기, 분자를 0으로 대체하기, 분자/분모 교환의 세 변형은 각각 ERR_ASSERTION으로 검출했습니다.

임시 소스 복사본 `/tmp/hwpjs-sampled-wide-mutant.6FphY8/icc`에서 512비트 목표 경로의 작업 폭을 u1024 대신 u512로 변경했습니다. Debug·ReleaseSafe는 최초 최대 목표 테스트에서 integer overflow panic으로 종료했고 ReleaseFast는 TestExpectedEqual로 잘못된 결과를 검출했습니다(3개 통과/1개 실패). 제품 원본은 변형하지 않았습니다.

추가 Debug WASM 수동 검사에서는 길이 65,537, 값 min(index,65535)인 곡선과 역순 곡선에 목표 5종을 적용했습니다. 증가 방향의 독립 기대식 x=65535×target/65536, 감소 방향 x=1−65535×target/65536과 비교한 10건이 일치했습니다. 최대 u512 분모·끝점 평탄부와 작은 목표를 포함하며 정규 audit 수에 합산하지 않습니다.

## 최종 확인과 남은 범위

전체 세 모드 audit가 `/tmp/hwpjs-sampled-wide-inverse-{Debug,ReleaseSafe,ReleaseFast}.log`에서 모두 종료 코드 0, 20/20 단계, 네이티브 618/618, WASM checks=6,654,233으로 완료됐습니다. 이전 6,646,514에 신규 7,719건이 추가됐습니다. ReleaseSafe·ReleaseFast 실제 audit 산출물 직접 실행에서도 신규 비교 1,815/거부 5,904, 기존 정규화 905/5,808, u16 경로 965/6,734가 일치했고 출력 변형 3종을 모두 검출했습니다.

최종 적대적 검토에서는 목표 선행 검증, 전체 곡선 단조/상수 검사, 감소 방향의 위치 기준 평탄 규칙, sample 개수와 보간 폭, 기존 타입 별칭, 공통 구간 선택 결과의 정확 확장, 입력/출력 wire 길이와 초기화를 확인했습니다. 추가 결함은 발견하지 못했습니다. Zig 포맷·변경 JS 문법·diff 공백과 관련 로컬 문서 링크 2개도 확인했습니다.

이번 완료 범위는 512비트 정규화 목표의 sampled 역변환입니다. 넓은 gamma/parametric 및 TRC 조립, 전체 색상 모델·렌더링·HWP/HWPX 문서 검증은 여전히 남아 있습니다.

gamma 경로의 후속 진행은 [넓은 gamma 역변환](icc-gamma-wide-inverse.md)에서 관리합니다.
