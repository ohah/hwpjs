# 글꼴 보조 도구 펼침

문서 글꼴 선택/적용·글자색·형광펜은 기존 도구 모음에 유지합니다. 이름으로 글꼴 지정하기와 시스템 글꼴 조회만 `font-source-options` native details 안으로 묶고 처음에는 닫습니다. summary는 `글꼴 이름·시스템 글꼴`입니다.

기존 input/button/status ID와 disabled 판정, 권한 요청 및 편집 명령은 유지합니다. 펼침 자체는 시스템 글꼴 조회나 문서 변경을 실행하지 않습니다. 별도 열린 상태나 복제 컨트롤을 만들지 않으며 저장 동의도 이 영역에 넣지 않습니다. 전체 RHWP UI 동치 구현은 아닙니다.

`node --test tests/hwp5/editor-controls.test.mjs`로 초기 닫힘·각 ID 유일성·보조 컨트롤 포함·주 글꼴/색상/저장 동의 제외와 기존 편집 컨트롤 경계를 검사합니다. 정적 구조/컨트롤 테스트이며 전체 화면 크기·OS 시스템 권한창·키보드 접근성 검증은 아닙니다.
