# ICC 헤더 수치 검증 (진행 중)

[v2 수치·미확정 영역](icc-header-v2-values.md)은 별도 검사기에 추가했습니다. 공통 비트 분해는 `header_bits`로 이동했지만 v4의 0 요구와 v2의 보류 진단은 합치지 않습니다.

이후 WASM 연결과 결과는 [헤더 의미 계층 검증](icc-header-verification.md)에 기록합니다. 아래 실행 기록은 각 네이티브 단계 당시의 결과입니다.

[ICC.1:2022 §4.2, §7.2.11~7.2.19](https://www.color.org/specifications/ICC.1-2022-05.pdf)를 기준으로 v4 헤더의 별도 수치 검사를 구현합니다. 기존 원값 파서나 식별자 검사에 규칙을 중복하지 않습니다. v2의 다른 표현·예약 규칙은 이 검사로 인증하지 않습니다.

## 책임과 범위

- `date_time.validateComponents`: dateTimeNumber의 월 1~12, 일 1~31, 시 0~23, 분·초 0~59를 검사합니다. 연도는 u16 원값을 보존합니다. 이 범위 검사만으로 실제 달력 날짜나 기록된 시각의 진위를 인증하지 않습니다. v4 명세는 UTC를 요구하지만 바이트 자체로 작성 프로그램의 시간대 사용을 증명할 수 없으며 호스트 시간대로 변환하지 않습니다. PNG의 초 60 허용 규칙과 혼용하지 않습니다.
- `pcs_illuminant.validateV4`: signed 16.16 원값을 네 자리 반올림하면 D50 0.9642/1.0000/0.8249인지 검사합니다. i64 정수 중간값으로 오버플로·부동소수점 플랫폼 차이를 피하며, 하나의 정수 인코딩만 강제하지 않습니다. PNG의 100000 배율과 무관합니다.
- `header_v4_values.inspect`: v4 major와 tail 종류를 확인하고 위 검사기를 호출합니다. 속성 비트 4~31과 마지막 예약 영역 28바이트는 0, 렌더링 의도 전체 DWORD는 0~3이어야 합니다. ID 바이트는 검사하지 않으며 기존 profile_id의 책임입니다.
- 반환 보고서는 내장 여부·독립 사용 금지·정의되지 않은 ICC 플래그·공급자 플래그, 미디어 속성·공급자 속성, 렌더링 의도를 분리합니다. 속성 상위 32비트는 공급자 영역이므로 0을 강제하지 않습니다. 플래그 표에 정의되지 않은 ICC 비트는 `unassigned_icc_flags`로 보류하며, 속성의 명시적인 0 요구와 같은 오류로 취급하지 않습니다. 두 내장 플래그의 조합도 임의로 보정하지 않습니다.

입력은 파싱된 Header 값이며 원본을 수정하거나 할당하지 않습니다. 프로파일 전체 길이·서명·등록부·태그·이미지 연결은 별도입니다. 이 함수의 성공은 전체 헤더/ICC 검증 완료가 아닙니다. 클래스별 추가 의미는 남아 있으며 v2 수치는 위 별도 문서의 계약을 따릅니다.

## 적대적 검증 기록

2026-09-07 첫 추가 후 Debug `zig build test --summary all` 418/418 통과를 확인했습니다. 날짜는 6개 위치의 u16 전 범위 393,216건을, D50는 3축 각각 raw 0~131072와 signed 극값을 독립 부동소수점 반올림 기준으로 대조합니다. 속성 64비트·플래그 32비트의 위치 편향, 의도 상위 비트, 예약 영역 28×255개 비영 변형과 major/tail 불일치를 검사했습니다.

후속 재검토에서 조립 함수의 날짜·D50 오류 전파, 공급자 비트 동시 설정, 입력 불변, 의도 0xffffffff 검사를 보강했습니다. 보강 후 재실행 결과는 아래에 기록합니다. 이 시점에는 WASM 독립 비교·실파일·전체 audit를 실행하기 전이었으며, 이후 결과는 위 검증 문서에서 관리합니다.

보강 후 `zig build test --summary all`, `zig build test -Doptimize=ReleaseSafe --summary all`, `zig build test -Doptimize=ReleaseFast --summary all`을 순차 실행했습니다. 모두 종료 코드 0, 4/4 단계, 418/418 테스트 통과입니다. Zig 포맷·diff와 관련 세 문서의 로컬 링크 5개도 확인했습니다. 네이티브 성공을 미실행 WASM/전체 감사의 성공으로 치환하지 않습니다.
