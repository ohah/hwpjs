# ICC 행렬/TRC 순방향 점 계산

현재 순방향 점 계산은 구현 후 세 모드 전체 감사를 통과했습니다. 역방향 TRC·프로파일 전체 의미·렌더링 의도·픽셀 연결은 아래 미완료 범위로 구분합니다.

## 계약

[ICC.1:2022 Annex F.3 식 F.3–F.6](https://www.color.org/specifications/ICC.1-2022-05.pdf)의 채널별 TRC 계산과 XYZ 행렬 적용을 연결합니다. matrix_trc_forward.evaluate는 [조립 모델](icc-matrix-trc-model.md)과 정규화 Fraction 3개를 받습니다. 곡선별 점 계산은 기존 trc_forward가 소유하며 별도로 재구현하지 않습니다.

세 채널이 모두 exact이면 matrix3_fraction.forward를 사용합니다. 이 계층은 signed 16.16 행렬과 정규화 u64 분수 좌표를 받아 i256 분자 3개·u256 공통 분모를 반환합니다. 분모는 65536×d0×d1×d2이며 각 분자 항은 계수×해당 채널 분자×다른 두 분모입니다. 분모는 2^208 미만, 분자의 절댓값 합은 2^225 미만으로 i256에서 안전합니다. 기존 i128 고정소수점 벡터로 강제 변환하거나 u64 입력 분모를 축소하지 않습니다.

한 채널이라도 approximate이면 정확 채널을 명시적으로 f64로 변환하고 matrix3_float.forward를 호출합니다. 결과 union은 approximate입니다. strict 부동소수점 모드로 계산하며 비유한 입력·결과를 거부합니다. XYZ에 0~1 클리핑이나 PCS 바이트 인코딩을 하지 않습니다. 곡선 단계의 기존 좌표·값 정책은 trc_forward와 그 하위 계산기가 계속 소유합니다.

profile_semantics_deferred·transform_priority_deferred는 true를 유지합니다. 한 점을 계산했다고 전체 곡선/백색점/프로파일이 유효하거나 LUT보다 우선한다고 판정하지 않습니다. 역방향 TRC 연결, 곡선 전체 유효성, 색상 렌더링 의도·PCS 인코딩·PNG 픽셀 연결은 남아 있습니다.

## 검증 진행

WASM mode176은 정규화 분수 3개와 실제 프로파일 바이트를 받아 tag_table→모델 조립→점 계산을 연결합니다. 결과는 exact/approximate 구분과 보류 플래그, i256 분자·u256 분모 또는 f64 좌표를 반환합니다. descriptor 배열은 성공·실패 모두 해제합니다.

Debug WASM 직접 검사에서 비교 774건·오류 거부 368건이 통과했습니다. identity·3점 샘플·감마 2·파라메트릭 type0 감마 2의 채널별 64가지 조합에 좌표 3종·행렬 4종을 대조했습니다. 최대 u64 부근의 서로 다른 분모, 음수/1 초과 XYZ와 i32 최소 계수, 잘못된 좌표·상속된 샘플 분모 한도·모든 잘림 길이·실패 후 복구를 포함합니다. 이 통합 검사가 모든 파라메트릭 함수의 수치 영역을 검사했다는 주장은 아닙니다.

정확 기대값은 BigInt의 분수 덧셈을 순서대로 수행하고 교차 곱으로 확인하여 제품의 3개 분모 곱 기반 고정폭 구현과 독립적으로 비교합니다. 근사 기대값은 해석 가능한 감마 2와 행렬 내적을 사용하고 2e-12×(1+|expected|)의 허용 오차를 적용합니다. 근사 출력의 유한성·미사용 출력 바이트와 두 보류 플래그도 검사합니다. Debug 전체 감사는 실행 중입니다.

후속 통합 검사에서는 기존 독립 Table 68 수식 기대값을 icc-analytic.mjs에서 export하여 재사용하고 별도 곡선 수식 사본을 만들지 않았습니다. 다섯 함수 각각을 세 채널 위치에서 0~1의 1/1024 간격으로 평가하고, type1~4 분기점의 -1/65536·정확 일치·+1/65536을 추가했습니다. 비대칭·음수 계수 행렬과 다른 두 identity 채널을 함께 계산합니다.

Debug WASM 직접 실행에서 추가 비교 15,412건·오류 거부 18건이 통과했습니다. 0^0, 0인 a의 임계값, 음수 밑의 분수 지수 오류를 각 채널과 영행렬에서도 전파하는지 검사하고 정상 입력으로 복구를 확인했습니다. 모든 함수 종류의 연결과 선택한 분기를 확인한 것이며 전체 파라미터 공간의 전수 검사는 아닙니다. 추가 검사 이전에 시작한 Debug 전체 감사는 이 새 테스트의 검증 근거로 사용하지 않습니다.

추가 파라메트릭 통합 검사 이전의 Debug 전체 감사는 `/tmp/hwpjs-icc-model-forward-Debug-final.log`에서 종료 코드 0, 20/20 단계·476/476 네이티브 테스트·WASM 5,126,695개 검사로 통과했습니다. 최신 테스트를 포함한 Debug 감사는 `/tmp/hwpjs-icc-model-forward-Debug-post-parametric.log`에 별도로 실행 중입니다.

읽기 전용 실파일 조사에서는 /System/Library/ColorSync/Profiles의 v4 행렬/TRC 프로파일 6개에 검정·백색·중간 회색·서로 다른 채널 분수의 4개 입력을 적용했습니다. 원본 곡선 payload에서 독립 수식으로 계산한 뒤 XYZ 열과 곱한 기대값에 대해 24개 점·72개 좌표가 허용 오차 안에서 일치했습니다. 실제 입력의 곡선 표현 때문에 24개 모두 approximate였고 exact 실파일 사례는 관측하지 못했습니다. 정확 경로는 앞선 합성 입력으로 검증합니다. 이 수동 검사는 렌더링 의도·실제 백색점·픽셀 인코딩의 정확성 증명이 아니며 정규 감사 수에 합산하지 않습니다.

최신 Debug 전체 감사는 `/tmp/hwpjs-icc-model-forward-Debug-post-parametric.log`에서 종료 코드 0, 20/20 단계·476/476 네이티브 테스트·WASM 5,142,125개 검사로 통과했습니다. 기본 통합 비교 774건·거부 368건과 파라메트릭 통합 비교 15,412건·거부 18건을 포함합니다. ReleaseSafe·ReleaseFast 감사는 아직 완료 전입니다.

ReleaseSafe 전체 감사도 `/tmp/hwpjs-icc-model-forward-ReleaseSafe-final.log`에서 종료 코드 0, 20/20 단계·476/476 네이티브 테스트·WASM 5,142,125개 검사로 통과했습니다. 기본 통합과 추가 파라메트릭 검사 수가 최신 Debug와 일치했습니다. ReleaseFast 감사는 진행 중입니다.

ReleaseFast 전체 감사도 `/tmp/hwpjs-icc-model-forward-ReleaseFast-final.log`에서 종료 코드 0, 20/20 단계·476/476 네이티브 테스트·WASM 5,142,125개 검사로 통과했습니다. 기본 통합 비교 774건·거부 368건, 파라메트릭 통합 비교 15,412건·거부 18건이 일치하여 세 모드 검증을 마쳤습니다. 위 진행 중 표현은 각 실행 당시 기록입니다.

최종 적대적 리뷰에서 넓은 정수 중간값 범위, 분모·스케일, 채널별 오류 전파, 정확/근사 결과 분기, 비유한 결과 거부와 반환 메모리·descriptor 해제를 확인했습니다. 테스트 기대값의 교차 곱 오류 수정 이후 이번 범위의 추가 결함은 발견하지 못했습니다. 포맷·변경 JS 구문·diff 공백과 문서 로컬 링크 2개 검사도 통과했습니다. 전체 문서·ICC·색상 렌더링의 검증 완료를 뜻하지 않습니다.

수정본 `zig build test --summary all`은 종료 코드 0, 5/5 단계·476/476 테스트로 통과했습니다. 포맷·diff 공백 검사도 통과했습니다. WASM 독립 대조·세 모드 전체 감사는 아직 완료 전입니다.

네이티브 검사는 u64 최대 부근의 서로 다른 분모, identity·샘플 혼합, 음수/1 초과 XYZ, 감마 채널 혼합의 approximate 구분, 잘못된 좌표, 비유한 입력·결과를 포함합니다.

최초 네이티브 실행은 475개 통과·1개 crash로 실패했습니다. 최대 분모 테스트의 기대값을 교차 곱으로 확인하는 과정에서 i256보다 큰 중간값을 만든 테스트 코드 오류였습니다. 제품 계산 반환 뒤의 검증식에서 발생했으며, 항등 행렬의 공통 분모를 입력 분모로 먼저 정확히 나눈 뒤 분자를 곱하는 식으로 수정했습니다. 실패한 최초 실행을 전체 통과로 보고하지 않습니다. 수정본 실행·WASM 독립 대조·세 모드 감사는 후속 기록으로 추가합니다.
