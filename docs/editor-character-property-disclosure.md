## 원자 글자 서식과 읽기 전용 참조

g8 글자 창 후보는 기존 문단 창·컨텍스트 메뉴의 선택 소유권 검증을 유지하고, 지원 엔진에서 글자 서식 패치를 한 원자 명령으로 전달합니다. 알 수 없는 필드나 미지원 쓰기를 활성화하지 않습니다. 읽기 전용 HWP5 표시 참조는 이력을 켜지 않고 Native 발급 참조를 연결하며, 문서 교체 후 이전 참조는 거부합니다. 참조 발급은 쓰기 권한을 부여하지 않습니다.

공식 SDK와 d849 엔진의 실제 HWP5/HWPX UI 검증은 굵게·한글 장평·글자색의 한 명령 적용, 이력 1건, undo 원본 바이트·redo 편집 바이트, 저장·재열기, 읽기 전용 query와 쓰기 거부를 확인했습니다. 정규 core 회귀는 참조 발급 6건과 실제 읽기 전용 2건을 포함합니다. 실행 명령은 [개발·검증 명령](development-commands.md#읽기-전용-서식-참조-집중-회귀)을 따릅니다.

이는 전체 41개 필드의 쓰기 행렬, 독립 CFB/XML 저장 oracle, Native 할당 실패 전수, 조판·성능·전체 O(n) 완료를 뜻하지 않습니다. 소스 반영과 운영 번들 반영은 별도이며, 후보 SDK의 d849 결과를 기존 cb48 운영 결과로 소급하지 않습니다.
