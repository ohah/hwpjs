# ICC 색순응 행렬

후속 [고정소수점 행렬 적용](icc-matrix-transform.md)은 정확한 순방향·역방향 계산 계층을 구현하고 세 모드 전체 감사를 통과했습니다. 이 문서의 파싱·비특이 검사와 실제 백색점 검증을 구분합니다.

현재 sf32 원시 배열과 v4_2022 chad의 요소 수·비특이 검사는 구현되었으며 세 모드 전체 감사를 통과했습니다. 실제 색순응 변환과 프로파일 통합은 아래의 미완료 범위로 구분합니다.

## 근거와 책임

[ICC.1:2022](https://www.color.org/specifications/ICC.1-2022-05.pdf) §10.22 Table 76의 sf32 타입은 8바이트 공통 접두사 뒤의 signed 16.16 배열입니다. 원시 배열 파서는 s15_fixed16_array.zig에 분리하며 공통 type_prefix의 시그니처·예약 필드 경계 검사를 재사용합니다. 배열 길이는 남은 바이트 수에서 도출하고 나머지 바이트를 무시하지 않습니다. 입력을 빌리며 요소 조회 전에 인덱스를 검사합니다.

§9.2.15의 chad는 sf32 요소 9개를 행 우선 3×3 행렬로 저장하며 역행렬이 존재해야 합니다. chromatic_adaptation.zig는 태그·판본·요소 수를 검사하고 계수를 값으로 반환합니다. 현재 명시적 v4_2022만 지원하며 v2를 같은 규칙으로 승인하지 않습니다. 미지원 태그는 null이며 유효 판정이 아닙니다.

matrix3_fixed.zig는 행렬식의 정수 분자만 계산합니다. 세 i32의 곱 여섯 개의 절댓값 합은 6×2^93 이하이므로 i128 안에 들어갑니다. 스케일은 65536³이며, 분자 0 여부로 특이행렬을 판정하여 부동소수점 허용 오차 때문에 작은 비영 행렬식을 거부하지 않습니다.

역행렬의 존재는 실제 채택 백색을 PCS 백색으로 옮긴다는 증명이 아닙니다. 결과의 adaptation_deferred는 true입니다. 실제 백색점 대조·행렬 적용·역변환·프로파일 전체 태그 조립·PNG 색상 변환은 남아 있습니다. 원시 sf32 배열은 chad의 9개·비특이 조건을 강제하지 않습니다.

## 검증 진행

명세 본문에서 배열 크기, 행/열 순서와 역행렬 요구를 확인했습니다. PDF 스크린샷 조회는 48쪽 요청에서 timeout이 발생하여 시각적 확인 완료로 기록하지 않습니다. 네이티브 검사는 접두사 손상, 모든 잘림 길이, 인덱스 경계, i32 최솟값·최댓값, 항등/작은 비영/중복 행 행렬을 포함합니다. 실행 결과와 WASM 독립 비교·세 모드 감사는 후속 기록으로 추가합니다.

2026-09-08 `zig build test --summary all`은 종료 코드 0, 5/5 단계·468/468 테스트로 통과했습니다. Zig 포맷과 diff 공백 검사도 통과했습니다. WASM 독립 비교·실프로파일 조사·세 모드 전체 감사는 아직 완료 전입니다.

WASM mode171은 원시 sf32 배열을 little-endian i32로 반환하며 mode172는 판본·태그 이름을 받아 계수·보류 플래그·i128 행렬식 분자를 반환합니다. JS 기대값은 BigInt 순열 합산으로 계산하여 제품의 여인수 전개와 독립적으로 대조합니다. {-1,0,1} 계수의 3^9 조합과 고정 seed의 2,048개 i32 행렬, 위치별 극값·잘림·시그니처 손상·판본·한도·실패 후 복구를 검사합니다.

최초 Debug WASM 직접 실행에서 정상 비교 35,690건·오류 거부 7,951건이 통과했습니다. 이어 큰 곱의 상쇄 뒤 행렬식 분자가 -1만 남는 입력을 네이티브와 WASM 회귀 검사에 추가했습니다. 최초 결과를 추가 입력까지 실행한 결과로 치환하지 않습니다.

읽기 전용 실파일 검사에서는 /System/Library/ColorSync/Profiles의 v4 프로파일 6개에서 chad 6개를 확인했습니다. ACESCG Linear, DCI(P3) RGB, Display P3, ITU-2020, ITU-709, ROMM RGB의 계수와 정확한 행렬식 분자가 독립 기대값과 일치했습니다. 프로파일은 저장소에 복사하지 않았으며 이 6건은 정규 감사 수에 더하지 않습니다. 해당 백색점 변환의 정확성까지 확인한 것은 아닙니다.

상쇄 경계 사례를 추가한 뒤 네이티브 468/468 테스트와 Debug WASM 직접 비교 35,692건·오류 거부 7,951건이 통과했습니다. 네이티브에는 v2 판본 거부 회귀 검사도 추가했습니다. 전체 감사가 끝나기 전 이 직접 실행을 세 모드 회귀 검증 완료로 간주하지 않습니다.

추가 수동 적대적 검사에서는 모든 계수를 i32 최솟값/최댓값 중에서 선택한 512개 행렬을 WASM에서 대조했습니다. 가역 264개·특이 248개가 BigInt 순열 합산 기준과 일치했습니다. 정규 감사 검사 수에는 합산하지 않습니다.

최초 Debug 전체 감사는 `/tmp/hwpjs-icc-adaptation-Debug-first.log`에서 종료 코드 0, 20/20 단계·468/468 네이티브 테스트·WASM 5,079,889개 검사로 통과했습니다. 이 실행은 추가 상쇄 사례 이전의 테스트를 로드해 정상 비교 35,690건을 보고했으므로 최신 테스트 전체 감사의 근거로 사용하지 않습니다. 상쇄 사례를 포함한 최신 Debug 전체 감사를 별도 실행 중입니다.

상쇄 사례를 포함한 최신 Debug 감사는 `/tmp/hwpjs-icc-adaptation-Debug-final.log`에서 종료 코드 0, 20/20 단계·468/468 네이티브 테스트·WASM 5,079,891개 검사로 통과했습니다. 새 주제 결과는 비교 35,692건·거부 7,951건입니다. ReleaseSafe·ReleaseFast 전체 감사는 아직 완료 전입니다.

ReleaseSafe 전체 감사도 `/tmp/hwpjs-icc-adaptation-ReleaseSafe-final.log`에서 종료 코드 0, 20/20 단계·468/468 네이티브 테스트·WASM 5,079,891개 검사로 통과했습니다. 새 주제의 비교 35,692건·거부 7,951건이 일치했습니다. ReleaseFast 전체 감사는 진행 중입니다.

ReleaseFast 전체 감사는 `/tmp/hwpjs-icc-adaptation-ReleaseFast-final.log`에서 종료 코드 0, 20/20 단계·468/468 네이티브 테스트·WASM 5,079,891개 검사로 통과했습니다. 새 주제의 비교 35,692건·거부 7,951건도 일치하여 세 모드 검증을 마쳤습니다. 위의 진행 중 표현은 각 실행 당시 기록입니다.

최종 적대적 리뷰에서 배열 경계·인덱스 곱셈 전 검사·i128 중간값 범위·정적 타입 분기·반환 계수 소유권·오류 시 probe 할당 해제를 확인했습니다. 이번 범위의 추가 결함은 발견하지 못했습니다. 포맷·변경 JS 구문·diff 공백과 로컬 문서 링크 9개 검사도 통과했습니다. 전체 ICC 프로파일·PNG 픽셀 변환·HWP/HWPX 문서 검증의 완료를 뜻하지 않습니다.
