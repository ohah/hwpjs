입력 방법과 현재 지원 범위

표 셀에서는 Tab/Shift+Tab으로 다음/이전 표시 셀로 이동할 수 있습니다. 입력 반영 중에는 이동을 기다려야 합니다. 마지막 셀에서 Tab은 화면의 다음 컨트롤로 이동하며 새 행을 만들지 않습니다. 표 격자는 실험적인 표시 배치이며 원본 한글 조판과 같지는 않습니다.

편집 가능한 HWP5/HWPX 문단을 클릭해 입력하세요. ‘필드 라벨만 편집’ 문단은 하이퍼링크·누름틀의 라벨 범위 안에서만 수정할 수 있습니다. 드래그 선택·방향키·삭제·붙여넣기와 허용된 문단의 Enter 분할을 지원합니다. Ctrl/⌘+Z로 실행 취소, Ctrl/⌘+Shift+Z 또는 Ctrl/⌘+Y로 다시 실행할 수 있습니다. 허용된 HWP5/HWPX 문단 경계의 Backspace/Delete 병합을 지원합니다. 같은 소유권 범위의 여러 문단 선택을 지원하며, 교체·병합 허용 여부는 문서 구조에 따라 검사합니다. 서로 다른 셀·본문 소유권과 미지원 컨트롤은 계속 보호됩니다.

서식 구간을 조회할 수 있는 HWPX 읽기 전용 문단도 선택·복사와 기존 서식 적용을 시도할 수 있습니다. 계산 결과의 직접 입력은 보호되며, 서식 적용 가능 여부는 native 편집기가 최종 검사합니다.

현재 텍스트·글자 서식과 지원되는 표·이미지·페이지 영역을 Canvas에 표시합니다. 미지원 개체와 표시 제한은 별도 진단하며, 원본 한글의 글꼴·줄·페이지 배치와 동일하다고 보장하지 않습니다. 제한적 편집본 다운로드를 지원하며 변경 후 원본 조판 정보는 재계산하지 않습니다.

고급 편집 API 실험 폼

일반 텍스트와 일부 표 셀·글상자·빈 문단, 기존 탭·제어 표식·하이퍼링크를 보존하는 제한적 편집을 지원합니다. 계산식 숫자 라벨은 직접 수정할 수 없으며 허용 여부는 native 파서가 검사합니다. 구역·문단 번호는 0부터, 선택 위치는 UTF-16 단위 [시작, 끝)입니다. 빈 선택은 삽입, 빈 교체 텍스트는 삭제입니다. 원본 파일은 변경하지 않습니다.
