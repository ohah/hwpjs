# Rust 구현 보관본

2026-09-05에 기존 Rust/Node/React Native 프로젝트를 이 디렉터리로 옮겼습니다.
이곳의 README·tech-stack·docs는 **이전 Rust 구현**을 설명합니다. 현행 Zig 구현은 저장소 루트 README를 참고하세요.

GPL/LGPL 기반 `benchmarks/cfb-c-spike`는 과거 검증 기록이며 신규 제품의 의존성이 아닙니다. 해당 라이브러리는 채택 후보에서 제외됐습니다.
